# What if

Speculative essays. Nothing in this folder is shipped, promised, or even
necessarily a good idea; each essay takes one recurring "what would it take"
question, holds it against the engine that actually exists, and tries to name
the smallest real gap between the two. The discipline throughout: an idea only
counts as bridged when it lowers to flat rules over the existing tick, with no
new runtime semantics. Syntax is allowed to be ambitious; the evaluator is not.

1. [Rendering trees](01-rendering-trees.md) — a JSX/hiccup-mood extension for
   emitting HTML (or any nested, ordered output) from flat relations, and why
   the hard part is one ordered aggregate, not the angle brackets.
2. [Escaping stratification](02-escaping-stratification.md) — what to do when
   the stratifier says no: time, lattices, structure, and the semantics
   upgrades deliberately left on the shelf.
3. [The nested DSL spirit](03-the-nested-dsl-spirit.md) — v0's
   `rule(name) { ... }` blocks with nested repo/rev context, what v5's
   flattening traded away, and what a bridge back would cost.
