v4 became graph-backed runtime

The migration moved source wakes, mounted SQL reruns, support retraction, and read continuations into SQLite facts. The queue remains a runner detail, while durable runtime identity lives in graph rows.

runtime_graph source_wake support_retraction read_continuation deterministic_resume

Identity rule

Durable reconciler identity is stored as URI ids and content keys. Queue row ids, pointer identity, insertion order, and local counters are scheduler details.

owner_uri + source_uri + subscribe_edge + event_value
=> runtime_job(owner)
=> rerun owner from stored continuation or mount snapshot
=> replace supports
=> emit downstream wake only if visible rows changed

What changed in code

Before

Dirty events woke parked queue rows. Durable resume depended on queue parking and per-op ad hoc state.

  • bus.dispatch_dirty(domain, key)
  • queue.enqueue_replacing_parked(...)
  • mounted query rerun via queue wake
=>

Runtime graph

Ops declare graph effects through context. SQLite stores owners, sources, edges, values, events, jobs, supports, and continuations.

  • declare_owner(...)
  • subscribe(owner, source)
  • record_continuation(owner, input)
  • dispatch_source_wake(...)
=>

After restart

Replay reads graph jobs, reconstructs owner work from SQLite, reruns, reconciles supports, then commits visible deltas.

  • pending_jobs()
  • continuation_for_owner(...)
  • replace_supports(...)
  • mark_job_done(...)

Save-to-rerun path

01
write_file or ghcache creates a wake

Runtime mode calls dispatch_source_wake and writes a source event.

02
subscribe edges select owners

Incoming owner --subscribe--> source edges become graph jobs.

03
read owners replay from continuation

The replay runner loads pipe hash, instance id, depth, and encoded input cursor.

04
outputs reconcile by support

Rows retract only when final owner support disappears.

SQLite facts now carrying runtime

runtime_node

Owners, sources, output tables, rows, and operator-owned runtime cells.

runtime_edge

Subscriptions, supports, active children, table membership, and graph links.

runtime_value

Dirty markers, source-located values, blobs, state-ish values, and hashes.

runtime_event

Append-only wake emissions from files, tables, ghcache, timers, or future sources.

runtime_job

Durable owner worklist derived from source events and subscribe edges.

Remaining boundaries

Queue still exists

It still runs immediate work, parks no-runtime continuations, and supports older tests. Graph jobs are the durable wake layer for app runtime paths.

Reactive operators are harnesses

combineLatest, merge, switchMap, poll, RSS, and timers have storage mechanics, but no public sprf surface yet.

Impure state needs lowering rules

Future impure ops need to declare source nodes, subscribe edges, edge-local values, active children, support edges, and event rows explicitly.
