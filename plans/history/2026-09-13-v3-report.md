## 1. What v3 was

v3 kept v1's mission and dropped v2's staging. The root README still opened with the loop:
"You touch 30 repos a week... Every captured string lands in a SQLite table. The connections
between repos become SQL joins." v3's own README called it a "Cross-codebase causal-linking
engine" and set the succession: "v3 is the active line; the v2 crate in the sibling `v2/`
directory still runs but new work lands here." Two things changed. Method: v2 built a full
trait stack bottom-up, v3 shipped narrow-but-complete ops first to learn which rules you would
write, which the README calls "use-case-driven mode." Shape: v2's three nesting modes collapsed
into one `flat_map_unordered`, caching became a property of an op rather than a call-site flag,
and the hand-rolled parser gave way to a tree-sitter host grammar with injected sub-grammars.
MAIN.md, four days before the pin, holds the finished model: "A four-layer pattern-flow
language with React-shaped queues, prolog-shaped facts, and tree-shaped data."

## 2. The language

Extension `.sprf`. A program is pipes separated by `;`; a pipe is ops joined by `>`, one
cursor stream flowing left to right. `${X?}` introduces a term, `${X}` reads one, `:atom` is a
literal tag, `op[lang](...)` picks a sub-grammar, `rule(name) { ... }` groups pipes. Spec:
`v3/crates/sprefa_parse/parse.md`, 2,760 lines.

A lint publishing an editor diagnostic, `fixtures/selfcheck.sprf`:

```sprf
fs(glob(crates/**/src/**/*.rs))
  > ast[rust](${V?}.unwrap())
  > lsp[warn](
      message = "unwrap() in shipped path",
      code    = "selfcheck/no-unwrap",
      hint    = "use ? or .context(...) or expect(\"why\")");
```

An audit sweep over your own tree, `fixtures/copy_audit.sprf`:

```sprf
repo(${R?}) > rev(:HEAD) > fs(glob(**/*.rs)) > read > ast[rs](${X?}.to_string());
repo(${R?}) > rev(:HEAD) > fs(glob(**/*.rs)) > ast[rs](${X?}.to_owned());
repo(${R?}) > rev(:HEAD) > fs(glob(**/*.rs)) > ast[rs](String::from_utf8(${X?}));
```

The relational tier, `fixtures/tag_predicate_smoke.sprf`. `tag` writes, `tag?` reads, argument
binding mode picks probe, join or full drain:

```sprf
tag(:rel, "alpha", "A1");
tag(:rel, "beta", "B1");
tag?(:rel, "alpha", "A1") > print(:HIT);
tag?(:rel, "beta", ${V?}) > print(:JOIN);
tag?(:rel, ${X?}, ${V?}) > print(:DRAIN);
```

## 3. The engine

Eight crates, seven in the workspace. Bytes enter through the tree-sitter host grammar,
`lower.rs` walks the CST into a `Pipeline` of boxed ops, `binding_graph.rs` checks term reads
against term introducers before anything runs, then the runner drains cursors through the ops.
Side effects are described, never performed in place: an op calls `ctx.put(...)` and
`effect_runtime` serves it from the pure-effect cache, batches it, or cancels it. Facts land
in `relation_store` bags, readers wake on seal, and at exit every rule's terminal cursors
drain to SQLite: a table per rule, paired `<cap>`/`<cap>_norm` columns, an index per
normalized column, an FTS5 trigram view.

Incremental, partly. A debounced OS watcher, blake3 cache keys and an L2 SQLite op cache meant
a keystroke re-ran only the invalidated domain. Results recomputed on every fire.

Three files carry most of it: `pipeline/src/_2_pipeline.rs` (the Op/Seq/Fork runner),
`pipeline/src/effects.rs` (1,343 lines, every effect kind and batcher), `pipeline/src/lower.rs`.

```d2
direction: down

src: ".sprf source" { shape: document }

parse: "parse layer" {
  ts: "tree-sitter-sprefa\nhost grammar"
  inj: "injected sub-grammars\nglob  re  ast  json"
  ts -> inj: carveout re-entry
}

lower: "lower.rs\nAST to Pipeline" {
  bg: "binding_graph.rs\nterm reads vs term introducers"
}

pipeline: "pipeline crate" {
  cursor: "Cursor\nbytes + captures + byte_range"
  ops: "ops/\nrepo rev fs read comment ast json\nstr sh print render write_cursor lsp"
  cursor -> ops: "stream"
}

rt: "effect_runtime\nPureEffect cache, Batcher, cancellation"
readers: "readers/\nDiskFileSource, GitFileSource, BufferOverlay"
facts: "relation_store\nfact bags + seal wakers"
db: "SQLite drain\n<stem>__<rule>, _norm cols, FTS5 trigram" { shape: cylinder }
watch: "fs_watcher\ndebounced OS events"

cli: "sprefa-run (CLI)"
lspbin: "sprefa-lsp + VS Code extension"

src -> parse
parse -> lower
lower -> pipeline
pipeline -> rt: "effects staged"
rt -> readers: "Read / List"
rt -> facts: "tag / fact writes"
facts -> pipeline: "tag? drain + subscribe"
facts -> db: "end-of-run drain"
rt -> lspbin: "diagnostics, hover"
watch -> rt: "invalidate cache domain"
cli -> src
lspbin -> src
```

## 5. Why it ended

The last fifteen commits are finishing work, then a turn. Ten are LSP and write-path polish:
diagnostics published from rule cursors, deduped, rendering bound captures; `SPRF-LANDMINE`
markers; fs-cache invalidation per splice; a rev-aware file source over git2; the `sh` op.
Then the arg-pipe contract closed, `5c2d5a34a` scaffolded a differential-dataflow bridge
behind a feature flag, and `57064f2a0` renamed `tag` to `fact`.

Two pressures, both written down at the time. Sprawl first: the clearing session of 2026-04-29
archived v1, v2 and the chat log out of tree, wrote MAIN.md from scratch, and recorded why.
Eight months in, several wrong additions shipped (snapshotting, the ArgPipe wrapper,
RulePredicateOp), and your line to the agent: "i'm tired of your fucking opinions jackass."
It ended with a sparring protocol, one topic per session.

Differential dataflow second. The 2026-05-01 session argued for DD as the state backbone and
named the gap: the relation store had set semantics without retraction, and DD's frontier is
the principled version of the hand-built writer-share and seal-waiter mechanism. Your
constraint: "we don't know till we measure."

  (`v6/prolog/compile/registry.pl:250`).

- tree-sitter as the parse layer, now `tree-sitter-dl` at the root.
- The fact and rule tier, direct ancestor of the datalog framing in v5 and v6.
- `effect_runtime` and `FactStore` went into v4 intact. Whether either reaches v5 or v6 is
  unknown from this tree, as is how much of MAIN.md's four-layer cake shaped v5.
- `v3/crates/sprefa` never made it, already out of the workspace at the pin.
