# Reading path

Nine thousand words sit in this folder. Nobody reads them top to bottom. Three passes, stop after any of them.

## Pass 1, five minutes: the shape

Open `2026-09-13-how-i-steered.md` and read only the two tables. Then open each version report and read only its diagram. Five pictures, one table. That is the whole story.

## Pass 2, fifteen minutes: the endings

In each version report read section 1 (one paragraph) and section 5 (why it ended). Skip 2, 3, 4, 6, 7. Order: v0, v1, v2, v3, v4. Every section 5 has your own words from the day it ended, so you are reading yourself.

## Pass 3, one evening: the language you wrote

Section 2 of each report has three real programs copied from the tree. Read them in order, v0 syntax through v4 syntax, side by side with a `.dl7` file. That is the only pass that needs a quiet hour.

## Never

Section 2 of the v0 report is a forty-row table of every reference. It exists so you can `grep` it. Section 7 of each report is a line-count table. Same.
