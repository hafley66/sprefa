# 0.10.0 — text columns intern by default; delete `Type::Sym`

## Decision (Chris, 2026-07-12)
v0 interned every string and exposed auto-joining views so no consumer ever
touched the integer. v5's SQLite-weld regressed to raw TEXT per rel column and
re-added interning one column at a time (`Type::Sym`, 12/102 cols). Reverse it:
**every textish rel column interns by default**, `Type::Sym` is deleted, and a
per-rel decoded view restores the "never give a shit" ergonomics. `raw` opt-out
for freeform bodies (comment text, template text, doc strings): no dedup, no
decode-join cost.

Blast radius (measured): 196 `Type::Text` + 32 `Type::Path` + 1 `Type::File` =
**229 textish columns** flip to interned; 12 `Type::Sym` fold into the default;
2 `sym(` decode sites in `.dl` become no-ops; 12 `Type::Sym` touch points in
`src/lower.rs` are the bridge to widen.

## Layer 1 — type signatures

```rust
// src/ast.rs — Type loses Sym; textish() unchanged (non-Int is textish).
pub enum Type { Text, Int, Path, File, Dir, Repo, Rev }   // Sym DELETED

// Col gains an opt-out. interned() is the single predicate the whole engine asks.
pub struct Col { pub name: String, pub ty: Type, pub brand: Option<String>, pub raw: bool }
impl Col {
    pub fn raw(name: &str, ty: Type) -> Col;   // freeform-body opt-out: stores TEXT
    pub fn interned(&self) -> bool { self.ty.textish() && !self.raw }
}

// src/spine.rs — Sym/SymSink STAY (they are the intern mechanism, not the type).
// StringId::of, SymSink::sym, Db::flush_syms unchanged.

// src/lower.rs — generalize the sym bridge from `ty == Sym` to `meta.interned(pos)`.
fn col_interned(meta: &RelMeta, pos: usize) -> bool;        // replaces `cols[pos].ty == Sym`
fn var_interned(tys: &TyEnv, v: &str) -> bool;              // replaces `tys[v] == Some(Sym)`
// decode-at-text-position and hash-literal-at-filter already exist; widen predicate only.

// src/db.rs — per-rel decoded view (the v0 auto-join, restored).
impl Db {
    // CREATE VIEW rel_<name>_txt AS SELECT <int cols as-is>,
    //   sprf_sym(<interned col>) AS <col> ... FROM rel_<name>;
    fn create_rel_view(&self, meta: &RelMeta) -> Result<()>;
}
```

## Layer 2 — pseudo-code (write path, per refresh)

```
refresh_rel(rel, cols, rows):
    sink = SymSink::new()
    for row in rows:
        for (pos, cell) in row:
            if meta.interned(pos):  cell = Value::Int(sink.sym(text).cell())
            else:                   cell = cell            // raw / Int untouched
    db.flush_syms(sink)            // ONE batched _strings insert (N+1 law)
    db.reload_rel(table, cols, int_rows)
```

Read path needs no per-call work: `?`-query lowering decodes interned vars at
text positions (already wired for Sym); hand SQL / MCP / dbstat read
`rel_<name>_txt`.

## Layer 3 — lifetimes / state
- `SymSink`: one per refresh pass, drained by `flush_syms`, dropped (debug-panics
  if pending un-flushed). No change.
- `_strings(id, content, norm)`: process-lifetime table, append-only intern map.
  Grows by distinct interned text; `raw` columns never touch it.
- decoded views: schema objects, created at table-ensure time next to the base
  table, rebuilt if the rel's col set changes.

## Layer 4 — storage / sequence / uniqueness
- **Storage**: base table `rel_<name>` stores INTEGER for every interned col,
  TEXT for `raw`, INTEGER for `Int`. Companion `rel_<name>_txt` view decodes.
- **Sequence per tick**: intern (fill sink) -> flush_syms (one _strings insert)
  -> reload_rel (int rows). Unchanged order; the fixpoint recursion joins ints.
- **Uniqueness**: `_strings.id` PK = `hash64(text) as i64`. Collision domain is
  64-bit; same as today's Sym. `raw` cols carry no uniqueness claim.
- **PK/index shrink** (the payoff): a full-row PK autoindex over interned cols
  stores 8-byte ints instead of 54-byte fn / 21-byte file text. Measure the
  df_node drop via `Db::rel_stats` dbstat before/after.

## Migration / compat
- `sym(col)` builtin: keep as identity (decode is automatic now) or lint to
  remove; do NOT hard-error (2 call sites). Decide in step 6.
- Branded enum cols (`Col::branded`, e.g. `type_edge.kind`): interned like any
  textish col; the enum-variant typecheck runs on the literal BEFORE hashing, so
  `"new"` still pins. Low cardinality => cheap either way; keep uniform.
- Existing `.dl` joins are variable-unification — unchanged in source. Only the
  STORAGE flips; joins that were text=text become int=int transparently.
- DB is a rebuildable cache (`.dl/.state/cache.db`): no data migration, next
  tick reintern. Bump the schema epoch so a stale cache is dropped, not read.

## Parity gate (non-negotiable, wider than the fn/file arc)
Before/after, the `?`-query row sets of EVERY rel that a test or example queries
must be byte-identical (decoded through the view / lowering). Anchor rels:
`port_reach, entry_reach_node, op_reach_node, entry_reach, op_reach_fn,
flow_edge, member_edge, panel_node, panel_edge, mark_df` + the full `it` suite
(787 baseline) must stay green. Any drift = a broken decode/hash bridge = STOP.

## Order of work (one commit each)
1. `Col.raw` + `interned()` + `Type` drops `Sym`; mechanical decl updates
   (the 12 ex-Sym cols keep interning by falling into the default).
2. `src/lower.rs`: widen the 12 Sym predicates to `interned()`; typecheck: an
   interned col vs a `raw`/text col is the existing sym-vs-text bridge.
3. Write path: `refresh_rel` interns every `interned()` col via SymSink.
4. `create_rel_view` + call at table-ensure; MCP/hand-SQL point at `_txt`.
5. Mark the freeform-body cols `raw` (audit: comment_node text, template/df_lit
   text, doc-ish columns). Grep candidates, decide per column, note in summary.
6. `sym(` builtin disposition + README/book updates + `dl --check` rails.
7. Version bump 0.10.0; schema-epoch bump so stale caches drop.

## Laws
- N+1: intern is collect-then-flush through the one SymSink; no per-row SQL.
- No `provenance`/`substrate`/`load-bearing`/`regime` identifiers.
- Descriptive dl var names in any rule touched.
- Hermetic runs: `SPREFA_CONFIG=/nonexistent/x.toml DL_NO_DAEMON=1`, scratch `--db`.
