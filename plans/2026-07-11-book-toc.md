# Book TOC restructure (sol brief, written 2026-07-11)

The dl book grew as concept essays (book/00-08) + a hands-on tutorial
(book/tutorial/00-08) while the ENGINE grew three arcs past it (flow layer,
sym/perf, scip tiers, hooks/MCP, rails culture). Even the maintainer lost
track of shipped flow ops — the book is the discoverability organ and it
lagged. This TOC structures EXISTING material (mostly keep, some retitle/
move) and names the NEW chapters with their source-of-truth pointers.

Authoring laws: every code block runs (outputs captured from real runs, the
existing tutorial discipline); descriptive dl variable names; each chapter
ends with "the rails that guard this" where applicable; regen-not-hand-edit
for any generated table (doc indexes already dogfood this).
