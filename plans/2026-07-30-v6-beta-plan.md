# v6 beta plan (2026-07-30)

User: "get us to beta?" Alpha = works for us (golden plan P0-P4 done, release
gate satisfied). Beta = a stranger can install it, write a program, read the
errors, and learn from the docs. Smallest correct set, per the turbo-mid
directive.

## Beta exit receipts

1. **Cold-author errors** (review B4, "worst part of the experience"):
   every named refusal prints `file:line: plain-english message`; parse
   errors print line/col of the failure point, never char-code dumps.
   Receipt: refusal-message battery over all refusal fixtures, checked text.
2. **Numbers complete** (phase 5, already RULED): float = finite SQLite
   REAL/binary64, exact compare/join, shortest round-trip output, no
   epsilon; `avg()` lands; bool = INTEGER NOT NULL CHECK(value IN (0,1)).
   Wide-int RangeError (19 matrix cells) becomes a named refusal or bigint,
   never a crash.
3. **Zero known-wrong emitted modules**: fork_join_malformed_json fixed
   (real defect hiding in the run_error bucket); pairwise_single_tick_wrong
   fixed or refused by name.
4. **Docs dogfood**: GETTING-STARTED.md — install, first program, watch +
   extract, query, read an error. Generated from registry/fixtures where
   possible (devlog/self-map precedent).
5. **Install story**: one command to a working `bop`. Packaging/publish =
   user call (outward-facing).
6. **Battery green throughout**: conformance, sweep 0-wrong both modes,
   endurance + soak + extraction + lsp receipts, staleness gate.

## Explicitly NOT beta-gating

- Ingest perf parity with v5 (own arc, measured backlog exists).
- struct-as-rows / file-span / rel-value-unification deep arcs (labbing on
  this branch, continue in parallel; LSP line numbers ride them).
- @parcel/watcher swap (ruled: only on measured bench regression).
