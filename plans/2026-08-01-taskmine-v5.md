# Task-mining: v5 (rust) recurring work shapes

Read-only survey of `git log` on `src/ tests/ examples/ .dl/` plus the
`docs/failure-modes.md` incident taxonomy, to find which agent/skill files
would pay for themselves. Single output file. Method mirrors the v6 twin
brief. Counts are computed by the miner script (bottom) from the same git log
that produced the taxonomy; every shape carries shas.

The failure-modes headers are themselves the hardest recurring-task catalog
(38 classes, many with a `half`/`missing` rail in the gap table at
`docs/failure-modes.md:1462`). The commit stream confirms the gap table: the
classes that still say `half` or `missing` are exactly the classes whose
rail-birth commits recur.

## 5. Miner script (fenced bash, <10s)

```bash
#!/bin/bash
# Recompute the v5 task-shape taxonomy + successor edges from git log. <10s.
cd /Users/chrishafley/projects/sprefa
LOG=$(git log --format='%h %s' -- src/ tests/ examples/ .dl/)
declare -A cnt edge
match() { echo "$2" | grep -qiE "$1"; }
shape_of() {
  local s="$1"
  match '^release:' "$s" && { SHAPE=x_release; return; }
  match '(^|[ ])[Mm]erge' "$s" && { SHAPE=x_merge; return; }
  match 'rail|--?check|embargo|waiver' "$s" && { SHAPE=rail; return; }
  match 'daemon|exe-swap|launchd|supervise|spawn|restart|kill-respawn|budget|tick' "$s" && { SHAPE=daemon; return; }
  match 'storage-diet|index|WITHOUT ROWID|sym-dict|intern|dense|NodeIdx|auto-index|dedup|1NF' "$s" && { SHAPE=storage; return; }
  match 'perf:|perf\(|slow-rule|cache-db|N\+1|write budget|WAL|quiet-tick' "$s" && { SHAPE=perf; return; }
  match 'feat\(rels\)|builtin|want-tier|rel_add' "$s" && { SHAPE=builtin_rel; return; }
  match 'scip|oracle|parity' "$s" && { SHAPE=scip; return; }
  match 'extract|terminal|TypeLang|datapath' "$s" && { SHAPE=extract; return; }
  match 'seam-migrate|db-seam|family|router|sole-writer|seam' "$s" && { SHAPE=seam; return; }
  match '^test|it-test|witness' "$s" && { SHAPE=test; return; }
  match 'lsp|locate|hover|hookEvent|goto|diag|documentSymbol|workspaceSymbol|call hierarch' "$s" && { SHAPE=lsp; return; }
  match 'refactor|split|promote|rename|migrate|mod\.rs|reconcile' "$s" && { SHAPE=refactor; return; }
  SHAPE=other
}
total=0; prev=
while IFS= read -r line; do
  total=$((total+1)); sha=${line%% *}; rest=${line#* }
  shape_of "$rest"; cur=$SHAPE
  cnt[$cur]=$(( ${cnt[$cur]:-0} + 1 ))
  if [[ -n "$prev" && "$cur" != "$prev" ]]; then
    edge[$prev/$cur]=$(( ${edge[$prev/$cur]:-0} + 1 ))
  fi
  prev=$cur
done <<< "$LOG"
echo "== shape counts (total $total) =="
for k in "${!cnt[@]}"; do echo "$k ${cnt[$k]}"; done | sort -k2 -rn
echo "== successor edges A B n =="
for k in "${!edge[@]}"; do echo "$k ${edge[$k]}"; done | sort -k3 -rn
```

Runtime on this tree: ~8.4s (`git log` over the four paths dominates; the
grep pass adds ~0.1s). Under the 10s budget by a margin; drop the body join
and count subjects only for a ~1s leaner check.

## 6. Residual honesty

- **Residual 135/472 = 28.6%.** The `other` bucket holds one-off fixes, docs,
  chore, obs, plan, and standalone feat commits that do not fit a named v5
  shape. That is high; the taxonomy trades recall for precision by giving
  `daemon` a wide net (`tick|budget|spawn` catches subjects that land in other
  classes). The honest statement: daemon work is a plurality, not a measured
  majority, and roughly a quarter of commits are unclassifiable one-offs.
- **Classifiers overlap.** `daemon` (99) double-counts subjects that are
  really rail (daemon class rail) or perf (daemon quit-tick budget). The edges
  `daemon→rail` and `daemon→other` show the bleed. Considered but rejected: a
  strict-DAG classifier would shrink `other` at the cost of reproducibility.
- **`scip` kept separate** (35) from `extract` (43) because the two arcs
  recur on different cadences; merging gives 43 total extractor-adjacent
  commits, the number used in the taxonomy row.
- **Merge-traffic skew.** 39 subjects are `worktree-agent-*`/`merge ... into
  next` branches from co-located extraction agents. They are structural (the
  repo runs parallel worktrees) and excluded from the content corpus; the
  orphan/co-location cleanup class the brief anticipated is real but is
  mostly merge plumbing, not a distinct fix shape.
- **No surviving skill gap in the three existing agents' lanes.** Their
  shapes (builtin 8, op-op 3, magic-rel ~2) are the rarest; the proposals
  above target the four under-covered high-count shapes instead of
  re-proposing those lanes.
