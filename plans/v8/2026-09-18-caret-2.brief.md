## Goal

`^x` reads as the form `(^ x)`. A macro in `macrotime/1_caret.dl7` rewrites
the three shapes below to plain `:` forms. Lower learns two things: a 4-item
`:` bind, and arity counts only the edges inside `(* ...)`.

## Before / after

Reparent. Source:

```
(^User: (* (: name str))): (
  (: greet (<- (greet ?User ?Out) (User ?User ?Name) (str.cons "hi " ?Name ?Out)))
)
```

Reader output (`dl8 read`):

```
(: (: (^ User) (* (: name str)))
   ((: greet (<- ...))))
```

`dl8 expand`:

```
(: User (* (: name str)))
(: User greet (<- (greet ?User ?Out) (User ?User ?Name) (str.cons "hi " ?Name ?Out)))
```

Return collect. Source `(: Pick (* (: source type) (: names any) (: ^result type)))`;
reader `(: Pick (* ... (: (^ result) type)))`; expand
`(: Pick (* (: source type) (: names any) (: result type) (: return result)))`.

Two carets at one level. Source `(: Bad (* (: ^a int) (: ^b int)))`; expand
emits no rewrite and one macrotime diagnostic row `ambiguous_return(<form>)`.

Marked product. Source `(User: ^(* (: name str)))`; reader
`(: User (^ (* (: name str))))`; expand `(: User (* (: name str)))` (the form
evaluates to the product; today that is the same rows, the mark is dropped).

`^a.b` reads `(^ (. a b))`: the dot arm runs first, the caret wraps it.
