## 4. Design (decided)
| item | value |
|---|---|
| name | `term_lt`, `(term_lt ?Left ?Right)` |
| holds when | `u.cmp(left, right) == Ordering::Less` |
| both args | must be bound; unbound = no row, same as `int_lt` via `int_pair` |
| any term kinds | Int, Float, Bool, Str, Atom, Compound; no coercion, order by kind then value |
| negative_holds | mirror `Kernel::Int(cmp)` at `_4_kernel.rs:160` |
Write `term_pair(args) -> Option<(TermId, TermId)>` beside `int_pair` (`:71`).
