## Goal

1. Output text is a minted Doc tree, rendered once. `fs.file` takes a `Doc`; the sink renders it
   with `pretty` (already used by `doc.layout`, `_9_runtime/_3_executors/doc_layout.rs`). The
   ordered join mints one `Doc.concat` over item ids sorted by key: no `str.cons` accumulator, no
   intermediate strings. `std/doc.dl7` `join` fold, `std/tsi_registry_emit.dl7`,
   `std/str_ops_emit.dl7` move to it. Outputs stay byte-identical.
2. dl8 `Universe` (`src/_6_eval/_0_term.rs:29`, `syms: IndexSet<String>`) interns through `lasso`
   (`Rodeo`; one arena, `Spur` keys). Identifiers and text values both.
3. ivm `Interner` (`sqlite_ivm/crates/ivm-ir/src/1_terms.rs`): each string stored once (today
   `by_text` key + `by_id` copy). Use `lasso` or one `Arc<str>` shared by both maps.
4. Source text: values read from files keep `(blob, start, end)` spans over the loaded bytes where
   the value is a slice of the source; materialize a string only at a kernel string op.
