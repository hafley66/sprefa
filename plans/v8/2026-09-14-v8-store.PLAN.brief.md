## 4. Questions the plan must answer, in this order (the planning protocol)
1. **Type signatures first.** A `Persist` seam the evaluator talks to. Candidate shape to critique, not to accept:
   ```rust
   pub trait RowStore {
       fn load(&mut self, u: &mut Universe) -> Result<Store, StoreError>;
       fn commit(&mut self, u: &Universe, delta: &[(TermId, Box<[TermId]>)]) -> Result<(), StoreError>;
   }
   ```
   Say what the arena does across restarts: persist `terms` as a table keyed by dense id, or re-intern on load and re-key rows.
2. **Pseudo-code body** under each signature.
3. **Instance lifetimes** for every type holding state: connection, arena, Store, per-tick transaction.
4. **Storage layout, then the sequence of reads and writes per tick, then uniqueness conditions.** Table per relation with the program prefix, or one `row` table keyed `(rel_id, row_id)` with a `cell` table, or one table per arity. Cost each with the skill numbers (TEXT key 1.7 to 2.0x slower; every index copies the key).
5. **Delta.** How `Table.frontier` maps onto a persisted tick: the rows a restart must replay, and what a `want` row looks like at rest (pending, settled, retracted).
6. **Retraction at rest.** Delete-rederive (`v6/prolog/lower.pl:4517`) versus signed rows: which one the schema can support without a rewrite. This is task 3 of the pending list; the plan states the schema consequence of each, it does not decide.
7. **Measured claims only.** Any number in the plan comes from a command you ran (`sqlite3`, `cargo test`, `wc`) and is quoted with the command. No estimates.

## 5. Decisions already made
- One server, one db: `~/.agent/dl8.db` is the only file; tables carry the program name prefix; goldens use in-memory.
- Integer surrogate keys everywhere; natural TEXT keys live once in a dictionary table with UNIQUE; composite TEXT PRIMARY KEY is a defect.
- No per-row writes: collect the delta, one multi-row insert.
- Zero shell in the engine.
- The datalog kernel is bespoke; everything around it is bought.
- Term kinds: Int, Float (`ordered-float`), Bool, Atom, Str, Compound (PR #737).
- null never enters storage; absence is no row.
