## 1. What comptime is

`compile_dl7/4` (`2_compiler.pl:758`) is read, expand, lower, check, comptime.
Comptime is the second call of the same Datalog evaluator the macrotime lane
calls: `compile_after_check/5` (`:710`) runs `evaluate_checked/4` (`:718`),
which runs the checked program to a fixpoint, assembles the rows it derived
back into a new Datalog program, and repeats until nothing changes.

Two nested fixpoints:

| loop | driver | limit | source |
|---|---|---|---|
| inner, "compiler round" | `evaluate_compiler_rounds/11` | 16 | `:1173`, `compiler_round_limit/1` `:1467` |
| outer, "source refreeze" | `continue_source_refreeze/8` | 16 | `:769`, same limit at `:829` |

The inner loop closes a round, freezes its `:/4` edges and `intern/2` requests,
and re-seeds the next round with them as `edge_snapshot/4` and
`intern_snapshot/2` (`compiler_round_seeds/4` `:1505`, `snapshot_edge/2`
`:1514`, `snapshot_intern/2` `:1517`). A round is stable when its four frozen
lists compare `==` to the previous round's (`:1420-1423`); at that point the
inner loop returns the closure with `intern/2` rows stripped
(`finish_stable_round/9` `:1457`, `strip_intern_rows/2` `:1530`).

The outer loop lowers the source AGAIN with the generated declarations bound
into an expression environment (`final_checked_program/5` `:929`), and only
repeats when `derived_bind_diagnostics/3` (`:1469`) still reports an unbound
`var(derived_bind(_))` slot (`:776-788`).

## 2. The term the lane produces

`finish_runtime_program/10` (`:910`):

```
compiled_unit(TypeGraphFacts,
              checked_datalog(Graph,
                              datalog_program(Relations, Seeds, Rules),
                              Depends, Strata),
              CompilerFacts)
```

Rust, `_4_comptime/_1_api.rs`:

```rust
pub struct Compiled {
    pub type_graph_facts: Vec<TermId>,   // type_graph_facts/2, :1572
    pub runtime: Checked,                // crate::_3_check::Checked
    pub compiler_facts: Vec<TermId>,     // the stable round closure
}
```

`Checked` is reused verbatim from the check lane (`_3_check/_0_api.rs:24`), so
comptime output and reify input are the same struct with no adapter.

`TypeGraphFacts` is the `node/1`, `module/1`, `product/1`, `sum/1` and `:/4`
subset of the closure, relabelled through `semantic_label/2` (`:1590`) so a
`const(Name)` label loses its wrapper and a `ref(Id)` label becomes the bare
id.

## 4. The round loop as a slice

The redux shape from the brief, one struct of state, effects out through a sink:

```rust
pub struct RoundState {
    pub frozen_edges: Vec<TermId>,
    pub frozen_requests: Vec<TermId>,
    pub frozen_generated_relations: Vec<TermId>,
    pub frozen_generated_rules: Vec<TermId>,
    pub round: i64,
}

pub enum Round {
    Evaluate { outer: i64, round: i64, rules: usize, seeds: usize, closure: usize },
    Assemble { outer: i64, round: i64, relations: usize, rules: usize },
    Decision { outer: i64, round: i64, outcome: Outcome },   // stable | continue | limit
    Refreeze { outer: i64, mode: Mode },                      // final | deferred
}
```

`Outcome` mirrors `debug_round_decision/2` (`:1376`), which prints exactly
`stable`, `continue`, `limit_exhausted`. No trait: one impl only, per the
brief's "no trait unless two impls exist".

The pause point is `_2_rounds.rs` `rounds`' `loop`: everything before the
`Decision` event is pure over `RoundState`; a caller that wants to step the
fixpoint one round at a time breaks there.

## 5. The replay seam

`final_checked_program/5` (`:929`) and `deferred_checked_program/5` (`:949`)
call `lower_final_units/5` (`:970`), which calls
`0a_module_lowerer.pl`'s `lower_units_with_exporter_and_environment/6`. That
predicate belongs to the DRIVER lane, not this one, and the landed Rust lower
(`_2_lower/_0_api.rs:77` `lower_datalog`) is per-unit with no module basement
merge, no exporter, no project graph install.

So the outer loop takes its refreeze result through a sink:

```rust
pub enum Refreeze { Final, Deferred }
pub trait Sources {
    fn refreeze(&mut self, u: &mut Universe, mode: Refreeze,
                compiler_facts: &[TermId], generated_relations: &[TermId])
        -> Result<(Option<Checked>, Vec<TermId>), Stop>;
}
```

Two impls exist, so this one IS a trait: `Replay` (oracle, `_6_json.rs`) and,
once the driver lane lands, the real lowering. `Replay` holds the v7 outputs in
call order and checks each call's ordinal, mode, `compiler_facts.len()` and
`generated_relations.len()` against the frozen entry. A mismatch is a hard
`Err`, exit 3, never a silent pass. The key is lengths rather than a digest
because no hash crate is in `Cargo.toml` and `Cargo.toml` is not this lane's
file; a wrong-content-same-length replay is still caught, one step later, by
the byte compare of `expected.compiled`.

`generated_expression_environment/4` (`:1062`) and its helpers
(`generated_callable_reservation/7` `:1117`, `generated_environment_relation/3`
`:1125`, `generated_return_key_sets/5` `:1132`, `generated_positions_except/4`
`:1149`, `merge_expression_environments/3` `:1106`) ARE ported in
`_5_finish.rs` even though replay does not call them, because they are in this
lane's subject and the driver lane needs them the day it wires the real
lowering.
