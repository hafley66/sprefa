## 4. Design (decided)

### Term store, `_0_term.rs:18`
```rust
pub enum Term {
    Int(i64),
    Float(OrderedFloat<f64>),   // ordered-float 3.9, total order, Eq + Hash
    Bool(bool),
    Atom(Sym),
    Str(Sym),
    Compound(Sym, Vec<TermId>),
}
pub fn float(&mut self, f: f64) -> TermId   // beside `int` at :72
pub fn boolean(&mut self, b: bool) -> TermId
```
Build-vs-buy for the float key, decided: `ordered-float = "3"`.
| candidate | why not |
|---|---|
| raw `f64::to_bits()` | `0.0 != -0.0`, hand-written Ord |
| `float-ord` | Ord only, no Hash |
| `decorum` | larger API than needed |
| `ordered-float` | Eq, Hash, Ord, `2.10` and `3.9` already in `~/.cargo/registry/cache` |

Standard order in `cmp` (`_0_term.rs:164`): numbers first, compared by value,
Int before Float when equal; then Bool (`false < true`); then Str; then Atom
(nil first); then Compound. Add the arms, keep every existing arm.

### Reader, `_1_tokens.rs`, `_2_reader.rs:373`
```rust
pub fn float_token(token: &str) -> bool
// -?digits '.' digits, both sides non-empty, nothing else
pub fn bool_token(token: &str) -> bool
// exactly "true" or "false"
```
`read_bare` order: `integer_token`, then `float_token`, then `bool_token`,
then `valid_atom`. Payload for all three is `compound("literal", [term])`,
same as the integer branch. `1.` and `.5` stay `invalid_atom`.
Zero fixtures or prelude files spell `true` or `false` today (grep count 0),
so the atom door loses nothing.

### JSON, `_6_json.rs`
`term_to_json`: `Float` writes `json!(f)`; `Bool` writes `json!(b)`.
`term_from_json`: `Value::Number` with a fraction becomes `Float`,
`Value::Bool` becomes `Bool`. Integers keep the existing path.

### Kernel `int_add`, `_4_kernel.rs`, `_9_kernel.rs`
| item | value |
|---|---|
| name | `int_add` |
| arity | 3, `(int_add ?Left ?Right ?Sum)` |

| slot labels | 0 `left`, 1 `right`, 2 `return` |

Floats do not enter `int_add`. `Kernel::of` at `:52` gets one arm.
