# Brief: the dl8 language book (mdbook), every claim a fixture

## 1. Job
Write `v8/book/`, an mdbook, that documents the dl8 language as it is built on
`origin/main` at the base sha. One chapter per construct family. Every chapter
has the same five headings in this order: **What**, **Why**, **When to use**,
**Example**, **What proves it**. Nothing in the book is invented: every
semantic claim cites a fixture path, an oracle file, or a source `path:line`,
and every `.dl7` code block is a byte-copy of a committed fixture, marked so a
test can diff it. The book builds with `mdbook build` and the test passes
through the real `dl8` binary.

The reader is Chris, the language's owner, who is tired of assistants adding
semantics he did not decide. A sentence the code cannot back is a defect.
Where the code contradicts a plan doc, the code wins and the chapter says so
in one line with both paths.

## 6. Block marking and the test
Every `.dl7` block in the book opens with a marker line inside the fence:
```
```dl7
; fixture: v8/fixtures/aggregates/2_grouped.dl7
(: Score (* (: player text) (: points int)))
...
```
```
`check_blocks.sh` walks `src/*.md`, extracts each `dl7` block, strips the
marker line, diffs against the named file, exits nonzero on the first
mismatch and prints the chapter and the path. A block that intentionally
shows a fragment names the file and a line range, `; fixture: <path>:12-20`,
and the script diffs that range.

`tests/_22_book.rs`, through the real binary: for every marked block, run
`dl8 compile <path>` and assert exit 0 for fixtures outside
`oracle/check/cases`, and exit nonzero with the named diagnostic for those
inside. Then run `check_blocks.sh` and assert exit 0. Then `mdbook build
book` and assert exit 0 and that `book/book/index.html` exists. 10 s cap per
test.

## 7. Style laws
No em dashes. Banned words in prose and identifiers: provenance, substrate,
load-bearing, regime, ground truth, refusal, support (say refCount), honest,
grounded, distill, "here is", "below is", "the following". "Not built yet"
for anything the compiler rejects as unbuilt. Vocabulary is rxjs, prolog,
SQL words only. dl variables are descriptive, never single letters, in every
example you write in prose; fixture copies stay as they are. No praise, no
hedging, no history narrative. Comment budget in the test: constraints only.
Interfaces carry `I`. Follow `tests/_20_hosts.rs` style for the test.
