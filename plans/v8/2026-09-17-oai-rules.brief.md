## 3. Before / after

Before: Rust walks `serde_json::Value` (`_9_openapi.rs:251-548`) and mints
nodes and rows.

After, `std/oai.dl7` (shape; the lane writes the full set):

```dl7
(: document (* (: path text)))
(: route    (* (: path text) (: method any) (: operation_id text) (: request type) (: response type)))
(: param    (* (: operation_id text) (: name text) (: location any) (: type type) (: required any)))

; one root per document seed
(<- (doc_root ?Path ?Root) (document ?Path) (fs.json ?Path ?Root))

; paths.<path>.<method> -> route
(<- (route ?Path ?Method ?OperationId ?Request ?Response)
    (doc_root ?_ ?Root)
    (: ?Root paths ?Paths ?_) (: ?Paths ?Path ?Item ?_) (: ?Item ?Method ?Operation ?_)
    (http_method ?Method)
    (text_field ?Operation operationId ?OperationId)
    (request_type ?Operation ?Request)
    (response_type ?Operation ?Response))

; components.schemas.<Name> -> a named type node; object -> product, oneOf -> sum,
; $ref -> the named node, nullable -> (Option T), array -> list of items
(<- (schema_type ?Schema ?Type) ...)
```

The type nodes the old walk minted (`tsi.type`, `tsi.product`, `tsi.edge`)
are the same `:` rows a product declaration lowers to; a schema object IS a
product body once its `properties` level is read as edges.

## 4. The one Rust fork this lane must close

The old loader ran before the fixpoint, so `document` needed a literal path
(import lane commit `a9e6ee0e9`). With rules, `document` is an ordinary seed
and `fs.json` is served inside the comptime round. Verify: `dl8 compile`
(no `--serve`) must still produce the rows, so the compile driver serves
`fs.json` during comptime rounds (`src/_4_comptime/_2_rounds.rs`,
`_8_driver/_4_project.rs`). If the round loop cannot host an executor today,
stop and report the line; do not add a second loader path.
