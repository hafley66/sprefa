Why any of this

Weights (the "rings")

Every row carries a weight. The weight type says what the row means. v6 called these rings and named them B, Z and N; this page uses present, change and count.

One mistake, many languages

Live edges: CSP, backpressure, AsyncAPI

Only the live corner needs any of this. Each formalism covers one part:

CSP

Every live input is a channel. A sender blocks when the channel is full. In Rust: tokio::sync::mpsc::channel(64), bounded.

Backpressure

DD takes one batch per frontier. The producer waits on send().await, so nothing piles up in memory.

Rx vocabulary

combineLatest (join, one clock), withLatestFrom (latest), pairwise (pre), expand (recursion).

AsyncAPI

The contract per channel: name, message schema (the row type), direction, capacity. Generated from dl8's live declarations.
