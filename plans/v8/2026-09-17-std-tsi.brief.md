## Defect

`prelude/5_tsi_primitives.dl7` declares `(: bool (* ))` and `(: str (* ))` at
the prelude top level. Both shadow a kernel primitive, so
`(: title (str "untitled"))` lowers to a zero-column relation call and
diagnoses `expression_without_return`. PR #789 dodged it by editing the probe
(`plans/v8/probes/2026-09-17-defaults.dl7`, `(int 5)`).

## Before / after

Before: prelude, top level, every program sees `string`, `bool`, `str`, ...

After: `std/tsi.dl7`, the same declarations byte for byte; the prelude file is
deleted. `std/oai.dl7` opens with `(tsi: (import "@std/tsi"))`; the extract
loader's program (`tests/_16_extract_tsi.rs`, `_20_hosts.rs` fixtures) imports
it the same way. The binding `tsi.primitive(Id, Class)` resolves `Class` under
the imported `@std/tsi` module node.

```
; std/oai.dl7
(tsi: (import "@std/tsi"))
(: document (* (: path str)))
...
```
