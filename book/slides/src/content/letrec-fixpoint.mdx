```sql !
-- !focus(1)

```

## !!steps Iterate

```sql !
-- !focus(2)
reach₁ = reach₀
       ∪ { (x,z) | reach₀(x,y), edge(y,z) }
```

## !!steps Stable

```sql !
-- !focus(1)
Δreach₂ = ∅
```
