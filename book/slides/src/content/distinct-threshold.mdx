## !!steps No crossing

```sql !
-- !focus(1:2)
weight: 3 + 1 = 4
Δ distinct: 1 - 1 = 0
```

```sql !
-- !focus(1:2)

```

## !!steps Boundary rule

```sql !
-- !focus(1)
```
