## !!steps Inputs

```sql !
-- !focus(1:2)
orders = {(7, 'ada'), (8, 'bea')}
customers = {('ada', 'gold'), ('cy', 'silver')}
```

## !!steps Match the key

```sql !
-- !focus(3)
SELECT orders.id, customers.tier
FROM orders JOIN customers
  ON orders.name = customers.name;
```

## !!steps Emit the pair

```sql !
-- !focus(1)
(7, 'ada') JOIN ('ada', 'gold') = (7, 'ada', 'gold')
```

## !!steps Missing key

```sql !
-- !focus(1)
(8, 'bea') JOIN customers = {}
```

## !!steps Multiply weights

```sql !
-- !focus(1)
weight(7, 'gold') = 2 * 3 = 6
```
