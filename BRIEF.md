One object is described in two languages today. `v6/prolog/lower.pl` names a
catalog column `h_id`; the emitted TypeScript names the same field `hId`. So
`grep h_id` finds the SQL half and misses the TypeScript half. Every field of
the emitted program contract has this shape: `final_select` in the Prolog that
writes it, `finalSelect` in the TypeScript that reads it.

The rule, Rust's own rule: **fields, parameters, locals and functions are
`snake_case`. Types, interfaces and classes stay `PascalCase` with the `I`
prefix on interfaces.** Rust spells structs `PascalCase` and their fields
`snake_case`, so this is the shape a future port transliterates with no thought.
