Chris (2026-05-21): "what is e5 can we not use code names, we can parenthesis them when repeating them but maybe dont casually drop them, i dont have a jira board open to correlate."

**Why:** he doesn't hold a label→meaning table in his head across turns; a bare "E5" forces him to go correlate it. The shorthand is for my bookkeeping, not his reading.

**How to apply:**
- Lead with the plain description of the thing ("resolve the call graph from parsing instead of file co-occurrence"), not the label.
- Only attach the shorthand in parens on later mentions in the same message, e.g. "the resolved-call-graph work (E5)".
- Same goes for any internal taxonomy (experiment numbers, phase names, L1-L7 style codes): expand on first use every time.
