⏺ Shape in Rust terms:

  // one sum per direction
  enum Effect {
      ReadBytes   { key: (RepoId, RevId, FilePath) },
      ReadParsed  { key: (RepoId, RevId, FilePath, ParserKind) },
      ListFiles   { repo: RepoId, rev: RevId, pat: Pattern },
      QueryStore  { w: Where },
      WriteEdit   (FileEdit),
      Shell       (ShellCall),
      ApproveMut  (Arc<dyn MutationEffect>),
  }

  enum Response {
      Bytes(Arc<Bytes>),
      Parsed(Arc<ParsedTree>),
      Files(Arc<[FilePath]>),
      Rows(Arc<[Row]>),
      EditOk, ShellOk(ShellReply), Approve(Approve),
  }

  // what an op writes — no reader/store touched directly
  async fn pipe(input, ctx: RtCtx) -> Stream<Batch> {
      input.then(|batch| async move {
          let bytes_futs = batch.iter()
              .map(|c| ctx.put(Effect::ReadBytes { key: c.key() }));
          // each put returns a oneshot future; runtime coalesces across all
          // puts made within the same time/batch window
          let got = join_all(bytes_futs).await;
          ...
      })
  }

  Runtime piece per effect kind = a coalescer task:

  // throttleTime(16ms, {leading, trailing}) shape
  struct Coalescer<E, R> {
      inbox:    mpsc::Receiver<(E, oneshot::Sender<R>)>,
      window:   Duration,          // 16ms
      max_size: usize,             // batch budget
      dispatch: fn(Vec<E>) -> BoxFuture<Vec<R>>,   // the one backend call
  }
  // loop:
  //   leading — first msg fires a 0-delay batch + starts window
  //   during  — enqueue, send-count toward max_size
  //   on window close OR max_size reached — dispatch(collected),
  //     fan replies back via stored oneshots in order
  //   trailing = same as above; the window-close drain

  One coalescer per hot-path effect variant. reader.bytes_many becomes the backend call; ListFiles is its own
  coalescer keyed by (repo, rev, pattern); parse cache probes coalesce by oid; mutation approvals keep the
  existing MutationHandler path.

  Per-op batching-hint extension:

  trait Op {
      fn coalesce_hint(&self) -> CoalesceHint {
          CoalesceHint::default()   // e.g. window=16ms, max=1024, group_by=(repo,rev)
      }
      // rest as today but pipe() writes Effect puts only
  }

  What this buys given today's pain points:

  ast prefetch 1067 reader.bytes futures  ->  1 ReadBytes coalescer batch
  json / md / line / marker inner loops   ->  same, no per-op join_all
  parse_cache oid probe per file          ->  1 blob_oid coalescer
  mutex<git2::Repository> contention       ->  held once per coalesced dispatch

  Rust shape notes:

  - Effect and Response stay enums (closed set) — dispatch is a match, no dyn.
  - RtCtx.put :: Effect -> BoxFuture<Response>   // one API surface for all effects
  - Backpressure is the coalescer inbox capacity, not per-op.
  - Cancellation: coalescer select!s on CancellationToken; pending oneshots drop = Err(Cancelled).
  - Time source: tokio::time::sleep_until on window deadline; leading/trailing is a small state machine.
