**THE EXPERIMENT TO RUN NEXT (nested-set ancestry):** a CST is forest + acyclic + properly-nested
spans (child [lo,hi] ⊆ parent's) = the nested-set encoding. So ancestry/containment is a span RANGE
JOIN, no closure/SCC:
    anc(a,b) <- node(a,_,f,alo,ahi,_), node(b,_,f,blo,bhi,_), alo<=blo, bhi<=ahi, a!=b.
vs the current `anc(a,b) <- closure(child).` (closure ALWAYS SCC-condenses: engine.rs `dedup_edges`,
"one condensation per graph"; wasted on an acyclic 136K-node graph). Measure wall-clock + verify
identical result set over v5/src on the held branch. If range-join wins: retire the closure-incremental
follow-up, add a `node(file,lo,hi)` index (the `_where_bytes_file_span_idx ON (file_id,lo,hi)` already
exists), maybe ship a built-in `contains`/`ancestor`. Caveat to verify not assert: naive all-pairs anc
is O(k^2)/file without per-file scoping + index; the single-node "what contains my cursor" query is a
clean range scan (the LSP-common case). Build the experiment like the NODE_PROG `#[ignore]` benches in
cst_node_perf.rs, run with `cargo test --release ... -- --ignored --nocapture`.

## Key Insights
- **CST = forest + acyclic + nested spans => nested-set encoding => ancestry/containment is a span
  RANGE JOIN, not closure(child)/SCC.** Same trick as browser `compareDocumentPosition` pre/post numbering.
  Likely RETIRES the planned closure-incremental / dynamic-SCC follow-up for `node`.
- Browser/Chromium analogies that transfer: hit-testing = 1D innermost-containment; relayout-boundary /
  dirty-subtree invalidation = the path-scoped incremental tick. What does NOT transfer: layout
  constraint-solving (we never compute positions; the parser hands us byte spans).
- General fully-dynamic SCC is hard (delete-splits ~ research-grade); don't build it. For the genuinely
  cyclic graphs (type_edge/module_edge/call_edge) full recompute is cheap (they're far smaller than 136K).
- node id = kind-salted WhereBytesId; _where_bytes row carries salted id + RAW StringId so ref->string
  resolves to source bytes. closure() ALWAYS SCC-condenses (engine.rs dedup_edges).
- "16s" was DEBUG; always profile node/child perf in RELEASE.
- _where_bytes 1.3s insert = 4-way index maintenance (PK + string_id + file_span + path), not batching.
- Coordinator discipline: RETIRE agents before they balloon (one hit 223k ctx -> stopped mid-rewrite,
  discarded its uncommitted edit, fresh tightly-scoped agent finished from clean tip). Stale-base
  worktree gotcha: agent worktrees fork from an OLDER base; commit-in-worktree then `git rebase --onto
  main <base>` before merging; resolve the ast-arm conflict (opt_var vs var_of) keeping main's opt_var.
- LSP dogfooding was BROKEN: extension wants `sprefa-server --lsp-stdio`, v5 reality is `dl --lsp`,
  running server is the v4 May-20 fossil. sprefa-dl ext fixes the wiring.
