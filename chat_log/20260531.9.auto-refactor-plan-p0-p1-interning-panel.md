## Problem/Context
The ref-spine (`ref(string,file,lo,hi)` over `_where_bytes` + `_strings`) is already the
rewrite-coordinate table. Gap: the module resolver (modgraph.rs) never feeds it —
`module_import` rows carry `line` only, and the module arm runs separately from the
`push_span` arm. User flagged that v4 had "massive N+1" from string interning and asked a
3-Sonnet + 1-Opus panel to judge whether assimilating v4's interning idea is sound.

PANEL VERDICT (decisive):
- v4's N+1 was IMPLEMENTATION, not interning-the-concept. Two bugs: (a) `SqliteFactStore::insert`
  fired 63k× unbatched; (b) multi-KB `_memo` hex blobs interned as string columns → ~1M interns.
  v4 numbers (linux fixture): store_insert_calls 63,483→0, string_intern_calls 253,983→63,534
  once batched. `intern_output_cursors` (the route-B ancestor) was ALREADY batched — not the offender.
- v5 already does interning right (pure blake3 id-compute + collect-then-flush `insert_rows`
  256-chunks, one bump/tick). Safe to add output-interning iff it goes through insert_rows.
- CRITICAL BUG FOUND (b): `WhereBytesId::of` excluded `path` from identity + `FileId` is
  content-addressed → two byte-identical files (mod.rs re-export stubs, generated shims =
  exactly what a crate-move targets) collapse to ONE id, INSERT OR IGNORE keeps first path,
  second lost. ALSO corrupts retract_paths both ways under --changed. = P0.
- Latent incremental N+1: engine.rs:606-616 called insert_spine_where_bytes per-rule-per-file
  in the --changed loop; adding use-spans makes it cross N1_THRESHOLD=64 sooner. = P1.

## Key Insights
- strip_noise (modgraph.rs:105) preserves byte offsets (pushes 1 byte/input byte, \n kept,
  comments/strings blanked in place) → a regex match start IS a real file coordinate.
- expand_use SYNTHESIZES paths (a::{b,c}→[a::b,a::c]); a brace-expanded specifier is NOT a
  contiguous substring → only spans for what the resolver treated as contiguous get a clean
  (lo,hi). F1 = thread base offset so each LEAF gets its own span.
- WhereBytesId::of_located folds path ON TOP of of(w) — keeps WhereBytes a pure coordinate,
  sentinel preserved, single chokepoint, ref(string,file,lo,hi) query relation unaffected.
- Drain MUST group/key on span/ref_id, never resolved-path text (same path string can map to
  multiple spans, e.g. use a::{b, c::b}).
- v4 ref code lives at v4/src/store.rs (intern_*), memo.rs:340-460 (N+1 confessions),
  mounted_query.rs:118 intern_output_cursors. Archive rewrite math: sprefa-archive-20260428/
  crates/watch/src/rs_path.rs.
- Style: of_located doc avoids banned words; ledger note kept terse.
