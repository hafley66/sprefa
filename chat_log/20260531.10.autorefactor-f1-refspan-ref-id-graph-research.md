## Solution/Approach
F1 (DONE):
- ModuleRef gains `span: Option<(u32,u32)>` = byte range in raw content of the contiguous
  rewrite text (use leaf / brace leaf / TS specifier-literal). None for mod/#[path]/dynamic.
- `expand_use` now returns `Vec<(String,u32,u32)>`; `split_top_commas` returns
  `(item, start_off)`; offsets threaded through brace recursion (raw_off + lead trim).
  Brace leaf span = leaf segment only (head prefix is shared, non-contiguous); bare use =
  whole contiguous path.
- Rust `use` site adds `body_start` (= c.get(1).start()) to each leaf span. TS gets the
  specifier-literal span (c.get(1)), dynamic ${} → None.
- ModuleRows gains `spans: Vec<(String,String,WhereBytes)>` = (path, leaf_text, wb).
  module_rows_for_rev computes `where_file` = FileId::from_content_address(hash, content.len)
  same as parse_file, pushes span+text. New helper `insert_module_spans` interns text into
  `_strings` AND span into `_where_bytes` (both batched chokepoints). Called from BOTH
  refresh_module_rels (full scan) AND insert_module_rows (incremental).

ref.id (DONE):
- spine_rel_decls "ref" cols now [id, string, file, lo, hi]; refresh_spine_rels SELECTs id
  too and projects 5 cols; doc comment updated. Test queries `ref(s,_,lo,hi)` → `ref(_,s,_,lo,hi)`.

KEY BUG FOUND+FIXED mid-build: import path interned StringId into _where_bytes but never
inserted the text into _strings (parse_file does both via separate paths). string⋈ref
returned 0 rows. Fix = insert_module_spans interns into _strings too.
KEY GOTCHA: ref.file is the content-addressed FileId, NOT the path string. Test asserts on
(text, lo, hi) span, not path.

## Key Insights
- v4 HAD the full span spine (_strings/_files/_where_bytes/_refs/Coord); ref-spine C recovers
  it. v4 normalization = the target; v4 N+1 = impl debt left behind. data-model.md is pinned.
- expand_use synthesizes paths (a::{b,c}→[a::b,a::c]); brace leaf is NOT contiguous so its
  span = leaf segment only, head prefix shared across siblings. Bare use IS contiguous.
- import refs must intern text into BOTH _strings and _where_bytes or string⋈ref is empty.
- ref.file = FileId (content hash), not path; to get path you join through file/_files.
- module refresh has TWO write paths: refresh_module_rels (full, uses refresh_rel) and
  insert_module_rows (incremental). Any new emit must hit both — missed it first pass.
- Type-system-as-graph: spectral layout (Koren) = deterministic graph→3D; SBSE clustering
  (Harman MQ / Mancoridis Bunch) = the optimize half; CodeCity/Layered-Software-City = the
  render half; the wired-together + type-grain version is the under-researched seam.
