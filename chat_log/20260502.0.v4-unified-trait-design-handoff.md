## Problem/Context
User pivoted multiple times during this session; the through-line: don't expose substrate-internal concepts (gen, SubjectRegistry shape, Time) on op-author APIs. Earlier I was building avl.2's RtCtx::current_gen surface, which user correctly identified as vestigial — gen belongs *inside* the substrate (DD's frontier OR a per-rule layer-2 journal HWM), never on a public ctx method that ops read.

Larger reframe: user wants every op to be a redux-slice (state + reducer + saga catalog), composed via stream operators (RxJS-shaped), where the runtime owns time/determinism/caching/durability invariants and ops never see them. "Routed coroutines" — `path → request → response` — is the universal abstraction shared across HTTP, effect dispatch, sprfpath dispatch, fact storage, LSP method dispatch, sh, and yield/next. Tower's Service/Layer is the closest Rust prior art and is already in the dep tree via tower-lsp.

User confirmed: rules and facts are NOT privileged runtime concepts. `rule(:a, X?, Y?)` is just an op invocation with hoisting. Both rules and facts are slices: rule = Slice + Callable wrapper (lower-time naming); fact = Slice + substrate-delegated state. Layer 2 caches every slice uniformly by structural hash, not just rules.

User also wants resumable .sprf scripts (full re-entry across process restart). Architecture for that: serializable slice State + journaled Mutation effects + durable pending_yield rows. Combined with structural-hash rule identity (layer 2), this gives "edit one rule, only that re-runs" property without needing DD.

End of session: user honest check-in — "is this too much?" I gave honest pushback that the 6-layer trait architecture is overkill for the two real use cases (1: bulk string extraction → 1GB SQLite a la v0; 2: cross-repo pattern tagging) but user confirmed they want the full architectural ambition because they value time-travel + flow-state + declarative capture as language design goals, and explicitly accept the technique-practice value over a quick speed-goal ship.

## Solution/Approach
Six-layer trait architecture, locked in this session:

```
LAYER 0  Source                          .sprf bytes on disk
LAYER 1  Parse + Lower                   tree-sitter + lowerer → RuleIR + Slice instances
LAYER 2  Rule Store (script-time)        rule scheduler; identity by structural hash; persist+restore per-slice state
LAYER 3  Slice Runtime (gen-time)        slice runner; Vec<Cursor> → Vec<Cursor> per pipe-gen; per-rule monotonic gen
LAYER 4  Saga Dispatcher                 saga middleware; typed Query / Mutation; cache, journal, dedupe, retry
LAYER 5  Substrate                       tokio / rayon / DD / sqlite; row-granularity retraction
LAYER 6  OS / external                   fs, net, processes, LSP wire
```

Trait surfaces (six total + one cross-layer unifier):

```rust
// Layer 3 — universal op shape
trait Slice {
  type State: Serialize + DeserializeOwned + Default;
  type Sagas: SagaCatalog;
  async fn step(
    &self,
    state: Self::State,
    batch: Vec<Cursor>,            // CONTRACT: Vec<Cursor> → Vec<Cursor> per pipe-gen
    ctx:   &SagaCtx<Self::Sagas>,
  ) -> (Self::State, Vec<Cursor>);
  fn structural_hash(&self) -> u64;
  fn path(&self) -> &SprfPath;
}

// Layer 2 — per-slice persistence keyed by structural hash
trait RuleStore {
  fn rule_id(&self, slice: &dyn Slice) -> u64;
  fn load(&self, id: u64) -> Option<RuleSnapshot>;
  fn save(&self, id: u64, snap: &RuleSnapshot);
}

// Layer 4 — CQRS effect split
trait Effect: 'static + Send { type Response: Send; }
trait Query: Effect    { type Key: Hash + Eq; const DOMAIN: &'static str; }
trait Mutation: Effect { fn invalidates(&self) -> &'static [&'static str]; }
trait Saga { type Args; type Out; type Effect: Effect; async fn body(...); }

// Layer 5
trait FactSubstrate {
  type Time;
  fn push(&self, fact: FactName, row: Row, diff: Diff);
  fn advance(&self) -> Self::Time;
  fn query(&self, fact: FactName, key: Row) -> impl Stream<Item=(Row,Diff)>;
}

// Cross-layer unifier
trait Routed { type Path; type Request; type Response; async fn dispatch(...); }
```

Key invariants:
- Time domain stays internal: per-rule gen at layer 3 (drives state threading), journal HWM at layer 2 (drives replay). Never exposed on RtCtx or any op-author API.
- Yield is a Mutation (mutates dispatch table, not idempotent).
- Resumable .sprf falls out of (serializable State + Mutation journal + yield-as-mutation).
- Cross-rule joins are sagas, not a special mechanism.
- Layer 1 rule-granularity incrementality is independent of layer 5 row-granularity (DD).

## Key Insights
1. **Slice = redux slice + RxJS scan, not a new abstraction.** Every op is `(State, Vec<Cursor>) -> (State, Vec<Cursor>)` with saga yields. Composes by stream chaining.

2. **Routed coroutines (path→request→response) is the universal pattern.** HTTP, effect dispatch, sprfpath dispatch, fact query, LSP method dispatch, sh exec, yield/next — all the same trait. Tower's Service is idiomatic Rust prior art.

3. **Rules/facts are not runtime privileges.** Rule = Slice + Callable wrapper (lower-time naming sugar). Fact = Slice + substrate-delegated state. Layer 2 caches every slice uniformly by structural hash. "Edit one rule re-runs only that" property falls out of structural hashing, not a special-case rule cache.

4. **Time domain is internal, per-layer.** Layer 3 has per-rule gen (drives state threading). Layer 2 has journal HWM (drives replay-from-snapshot). Layer 5 (DD) has its own frontier T. None exposed on op-author API. Earlier RtCtx::current_gen was the wrong surface.

5. **Yield is a Mutation (CQRS framing).** Mutates dispatch table, not idempotent, journaled by middleware. Falls in same effect category as writes. Combined with serializable slice State, gives full .sprf resumability "for free."

6. **Layer 1 (rule incrementality) is orthogonal to layer 5 (row retraction).** "Edit one rule, only that re-runs" can land without DD via SQLite-backed mutation journal + structural-hash cache. avl.4 lands first; avl.3 (DD) is row-engine swap when measured perf demands it.

7. **SubjectRegistry is rx-flavored and shrinks under unified model.** Today it's a hashmap routing live tokio futures. Under unified: an in-process wakeup demux layered over a durable `pending_yield` Collection. Eventually deletable if Regime C (state-machine rules) wins; useful as in-process fast path until then.

8. **AI sycophancy was costing cycles.** Should have flagged avl.2 gen surface as speculative before writing 100 lines. Should have asked "what's the smallest stack that does the two use cases" before drawing 6 layers. Hybrid plan accepted: design ambitious (B), but be honest about which layers earn their keep when.

9. **The ast-grep op shrinks to ~3 lines under Slice trait.** All the cache/reader plumbing moves into the AstParseEffect saga middleware. Pattern compile is captured at lower-time as a closure constant. Op author reads pattern, walks matches, emits narrowed cursors. const/let-golf reached.

10. **LSP is "just a list of effects to respond to."** Inbound JSON-RPC methods → typed inbound effects (HoverEffect, DidChangeEffect, ExecuteCommandEffect). Outbound sends → typed outbound effects (PublishDiagsEffect, ApplyEditEffect). tower-lsp is the Routed adapter at the wire boundary. Backend itself is a slice with state = HashMap<Uri, DocSession>.
