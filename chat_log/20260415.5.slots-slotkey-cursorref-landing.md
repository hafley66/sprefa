## Problem/Context
The dual-tree realization: SprfPath + captures form a runtime
pipeline tree; AnyDataNode / MdTree / AstGrepTree form content trees.
Captures on pipeline-tree leaves point into content-tree nodes. Byte
spans recurse as unions of children unless a walker emits an anchor
span. The true-anchor debt from commit 4b94025 (capture-union proxy)
falls out of this framing as a walker touch: MatchResult gains
match_span.

CursorRef `&.$X` idea: input-redirection directive owned by the
framework but opted into per-op. Example: `json({code:$C}) >
ast-grep(&.$C, pat)` — ast-grep parses the bytes at $C's span as TS.
Composes with JSON_TREE slot reuse so nested tree ops don't re-parse.

Runtime SprfPath addressing: `$ROOT.fs[0].json[1].$NAME` as a query
syntax that subsumes the planned `@label:` named-arm idea. Unlocks
hover/goto, precise diag locations, reactive re-eval, stream seeding
from capture lists, assumption-check edges.

## Key Insights

- **Two trees, stacked.** Pipeline tree (SprfPath as address) vs
  content tree (AnyDataNode, MdTree, AstGrepTree). Captures are
  leaves in the pipeline tree that point into nodes in the content
  tree. Byte spans live in the content tree; SprfPath addresses the
  pipeline tree.
- **Span recursion rule.** `span(node) = anchor_span when walker-
  emitted with anchor, else union(iter_children.*), else union(
  captures.*)`. The "true anchor" case is the walker touch.
- **SlotKey typed-handle neutralizes the "Rust casting pain"
  concern.** Call sites read like `c.get_slot(JSON_TREE)` — no
  TypeId magic at the call site, no unsafe. `'static + Send + Sync`
  bound forces owned tree backends, which all candidates
  (tree-sitter, ast-grep, OXC, AnyDataNode) satisfy.
- **Newtype discipline is a rule, not a type.** Memo §1.8:
  `SlotKey<AnyDataNode>` collisions are silent; `SlotKey<JsonTree>`
  where `JsonTree(Arc<AnyDataNode>)` are distinct. Ecosystem
  convention, not framework enforcement.
- **`..Default::default()` kills field-addition shotgun surgery.**
  9 Cursor construction sites collapsed. Next field = 0 call-site
  edits. User was explicit about this ergonomics cost.
- **v1 had no analog.** v1 is extract-then-query (rules → SQLite);
  parsed trees are stack-local inside matchers, never composed.
  v2's streaming-cursor-with-slots is clean-slate.
- **CursorRef is one feature, N unlocks.** Cross-op back-references,
  hover/goto, switch via labels, reactive re-eval, stream seeding,
  LSP completion expansion, assumption-check edges all ride on the
  same primitive.
