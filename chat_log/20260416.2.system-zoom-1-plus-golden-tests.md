# System zoom 1 + golden tests

Persistent artifact so post-compaction reload has a complete picture of what sprefa v2 IS and what "it works" means. Paired with `v2/CLAUDE.md` (tight coherence) and `v2/README.md` (language surface).

## What sprefa is

A cursor-stream evaluator over a multi-repo × multi-rev × filesystem graph. A `.sprf` file declares a list of `CursorExpr` delimited by `;`. Each expr is a pipeline tree of ops joined by `>` (sequence) and `;` (fork). Ops pipe `Arc<[Cursor]>` streams. A `Cursor` is `(repo, rev, fs, byte_range, content_ref, captures, slots)`. Ops narrow the byte range, parse content inside it, bind captures, and emit fanned-out children.

Three layers of state live outside the stream:

- **Reader** (file-IO, 3-layer blob / worktree / buffer) reads bytes
- **Store** (sqlite) persists per-expr rows, scanner_hash skip-set, effect cache for mutations
- **MutationHandler** (spawned task, cancel-aware TaskGuard) approves write effects; respawns on reparse

The language experiment: glob + datalog + ast-grep + markdown/JSON/marker extraction in one. Ops narrow in, captures flow out, cross-rule unification is the join operator. Write ops exist but go through deferred approval so the evaluator stays pure.

## Outer shape (zoom 1)

```
.sprf source
  │
  │ host_parse() (tolerant for LSP, strict for CLI)       _8_parse.rs
  ▼
Vec<CursorExpr>    # ; delimited; named when rule(N) at head
  │
  │ init_cursors(InitInputs)                               _7_init_cursors.rs   (Phase 2)
  │   - topo sort by ${other.$VAR} xref deps
  │   - for each expr: Pipeline::run(empty, OpCtx) → Cursor stream
  │   - ResultStore collects captures per named expr
  │   - Store::flush_batch after all exprs drain
  ▼
BoxStream<RunEvent>
  ├─ Cursor         { expr_name, cursor }          → print / inlay / row insert
  ├─ ExprDone       { expr_name }                  → seal per-expr rows
  ├─ Diag           { diag }                       → diagnostics sink
  ├─ MutationPrompt { effect, ack: oneshot }       → handler answers Approve::Yes|No
  └─ Done                                          → flush + exit
  │
  ▼
consumers:
  bin/sprefa_v2   CLI; AutoApprove; stdout per cursor
  DocSession      LSP; RunReport collect; MutationPrompt → client code-action
  tests/stress.rs task count + RSS budget across 1000 reparses
```

Reparse discipline:

```
DocSession::on_source_change(new_src)
  cancel.cancel()                          # all op tasks bail; oneshots resolve Err(Cancelled)
  drop old TaskGuard                       # handler task aborted
  cancel = CancellationToken::new()        # fresh token
  (mtx, mrx) = mpsc::channel(buffer_size)  # fresh channel
  guard = spawn_handler(handler, mrx, cancel)
  reparse(new_src)
```

Bounded channels (`cfg.runtime.buffer_size`). Sequential repo processing. Cursors carrying content are never buffered across op boundaries. 16GB target for 500 repos.

## Golden tests (acceptance set)

Ten scenarios that define "the language works end to end". Each pairs a `.sprf` program with observable outcome. The 8-session roadmap is sized by which golden tests it unlocks.

### G1. Structural match fans out

```sprf
rule(hooks) > repo($R) > rev(main) > fs(**/*.tsx) > ast-grep(use$H($$$ARGS));
```

One row per hook call across every tsx file in every repo. `$H` captures the hook suffix (`State`, `Effect`, ...), `$ARGS` the arglist. Proves ast-grep op + fs fan-out + multi-capture row merging.

### G2. Markdown + marker doc tags

```sprf
rule(todos) > repo($R) > rev(main) > fs(**/*.md) > marker(TODO:, $MSG);
rule(fence) > repo($R) > rev(main) > fs(**/*.md) > md(```$LANG\n$BODY\n```);
```

Extracts comment-bounded TODO markers and fenced code blocks with language tag. Proves marker op (comment-bounded extraction) and md op (commonmark walker).

### G3. JSON extraction, scalar + nested fan-out

```sprf
rule(pkgs) > repo($R) > rev(main) > fs(**/package.json)
           > json({ name: $N, version: $V, dependencies: { $DEP: $VER } });
```

One row per `(package, dep)` pair. Proves scalar + object walker, `{$K: $V}` key iteration, nested descent.

### G4. Cross-rule unification within a repo

```sprf
rule(def) > repo(lib) > rev(main) > fs(src/api.ts) > ast-grep(export const $NAME = $$$);
rule(use) > repo(app) > rev(main) > fs(**/*.ts)    > ast-grep(${def.$NAME}($$$));
```

`use` only emits rows for call sites where `$NAME` was bound by `def`. Proves `${other.$VAR}` xref join: topo order, ResultStore read of upstream captures, `Leaf` constraint matching.

### G5. Cross-repo causal link

Same shape as G4 but with repos `lib` and `app` distinct. Proves Store's `repo_id` FK works end-to-end and the scan-pointer columns (`$NAME_repo_id`, `$NAME_rev_id`, `$NAME_file_id`) get populated and joined at query time.

### G6. Write op with approval

```sprf
rule(rename) > repo($R) > rev(main) > fs(**/*.ts)
             > ast-grep(oldName($$$A)){fix: newName($$$A)}
             > write();
```

- CLI (`AutoApprove`): edits land, outcome recorded.
- Interactive (`InteractiveCli`): prompt per fingerprint, `y/N` per call site.
- LSP (`LspPromptBridge`): `RunEvent::MutationPrompt` fires, client code-action invokes the oneshot.

Proves `MutationEffect` trait dispatch, `await_approval` biased select, handler trifecta.

### G7. Reparse isolation (stress)

1000 iterations of `session.on_source_change(new_rule_text)` → `session.ensure_run()`. Invariants:

- `tokio_metrics::active_tasks()` stays under a small constant
- RSS growth bounded (< 50 MB over 1000 iterations)
- No dangling mpsc senders, no orphaned TaskGuards

Proves cancel + TaskGuard + respawn discipline.

### G8. Schema evolution on rule edit

Start with `rule(pkgs) { > json({name: $N}) }`. Run. Edit to `{name: $N, version: $V}`. Rerun. Store detects `schema_hash` change → DROP VIEW/TABLE → rebuild DDL → insert new rows. Rename rule → `extract_hash` change → clear rows, keep schema.

Proves `ExprChange::{New,Unchanged,SchemaChanged,ExtractChanged}` classifier in `register_expr_schema`.

### G9. Mutation cache idempotence

Run G6 twice with same source and file state. First: prompt + apply + `record_effect`. Second: `effect_status → Skip`, zero prompts, `record_effect` logs idempotent outcome. Manually mutate target file. Third: `Stale(outcome)`, prompt reappears with stale badge.

Proves `fingerprint` + `content_stable_since` + `effect_status` three-way switch (Skip / Stale / Emit).

### G10. LSP hover surfaces captures and effect preview

- Cursor over `$NAME` in `rule(use)` → hover shows bound value(s) + source site link
- Cursor over `&.$X` → `DocSession` delegates to binding op's `hover_capture($X, cursors)`
- Cursor over `&.fs` / `&.repo` / `&.rev` → delegates to field hover_match
- Cursor over `write()` paren → `effect.preview_markdown()` renders

Proves span_ix op_path dispatch, hover delegation mechanics already shipped in Phase 1 groundwork.

## Why this frame survives

sprefa lives inside a reactive runtime shaped by five invariants:

1. **Ops own everything** — diagnostics, patterns, hover, fix, effect type. Framework holds `Arc<dyn Op>`, never switches on op kind.
2. **Cursor is the unit of flow** — not rows, not paths, not AST nodes. Ops transform cursor streams.
3. **Content contract** — every byte-reading op tries `cursor.content[byte_range]` before `reader.bytes()`. Makes `&.$X` rebase work.
4. **Reads are pipe, writes are deferred effects** — mutations never block the stream; they queue on an mpsc and the handler awaits approval.
5. **Reparse is cheap, cancellation is real** — `on_source_change` cancels the token and all tasks unwind. TaskGuard drop aborts.

Any plan that violates these five should pause and rethink; they are the coherent spine.
