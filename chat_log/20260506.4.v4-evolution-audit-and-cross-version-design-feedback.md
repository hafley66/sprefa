## Key Insights
- **v4 = v2 architecture + v3 substrate.** Each version's deltas are recorded in the jump table; v4 is the recovery of v2's structural clarity (thin shells, daemon, stdio↔WS proxy) while keeping v3's effect_runtime/FactStore gains. Server-fat (5425 LoC backend.rs) was the v3→v4 trigger.
- **Two-libs decohesion floor is the load-bearing rule of v4 partition.** cst + effect_runtime generic; everything else sprf-specific. "Would another project want this without sprf?" is the explicit gate.
- **Four-slot model now formally specified by three memory entries**: `op[source-pipe](positional + atoms)\`dsl with ${...} pipe holes\`{sub-pipe}`. No kwargs ever; wide surfaces split into multiple ops. `${...}` = host-owned pipe hole inherited by every DSL; `${X}/${X?}` sugar over `${term(:X)}/${term?(:X)}`. Lang for ast goes in paren args as `:rs` atom, not in bracket.
- **Min-files rule** (`pipeline.rs`, `lower/ops.rs` each one file) trades search/skim cost for porting-churn savings. Acceptable while files stay <2k LoC.
- **The user's relationship to effect_runtime is signature-by-design**: collapses are personal (MutationStore→FactStore, three doors→two, slots→byte_range), metaphor stack is welded from four communities (RxJS, redux-saga, React, Laplace), decohesion test is intent-driven.
- **${X} sugar collides with ast-grep's $NAME metavar inside ast bodies.** Resolvable via brace carveout but LSP/highlighter must disambiguate at sub-grammar parse time.
- **Cross-language type drift detection**: per-lang `canon(:rust|:ts|:py)` op emits canonical record-shape blob; `shape_eq?` generic predicate; `bridge` fact table holds cross-lang correspondence assertions; `.sprf` config file is the truth source. Deliberately lossy canonicalizer covers ~80% (primitives, optional, array, record, ref). Reference resolution by qualified name with per-bridge mapping; recursive unfold deferred. Strictness modes via separate ops (`shape_eq?` + `shape_strict_eq?`), not flags.
- **Zig comptime relevance is one slice only**: "compile-time values flow as inputs to compile-time logic." sprefa already has this via lower-phase fact-store reads. Component/expand model is comptime-shaped without comptime-machinery cost. The cross-language part is purely a sprf design problem, nothing Zig-specific applies.
- **Cross-repo fact-database direction (claim/verify/reconcile)**: AI claims observed graph links via `claim(:kind, :verifier=rule_id, ...fields, :author=ai, :rev_id=...)`; human authors verifier rules; `reconcile(:claim_table, :verifier)` antijoin emits `claim/violated|confirmed|new` diags. Origin column (`:asserted|:derived|:verified`) on one physical fact table, not parallel tables. Replay across (repo, rev) coordinates via `:replay_target` fact table. Schema_hash on claims to catch verifier rule rot. Verifier separation between AI and human prevents circular validation. **User said this got off the rails; needs one-sentence restate before continuing.**
- **`.sprf` as exploration log**: AI explores, writes claims into a `.sprf`, commits to repo. Future runs replay it. Unifies AI/human/rule-derived facts under one file format. The discipline is human writes verifiers, AI writes claims that reference existing verifiers.
- **Comment-driven SPEC was sketched then explicitly shelved**: user said "no don't make a memory, doing it another way." Five-sigil set proposed (`///`, `//!`, `// sprf:`, `// sprf?`, `// sprf!`) and parked.
- **User's session shape**: research-mode, parallel-chat-aware, single-feedback-iteration. Treats chat_log as deliverable. Strong preference for tight technical prose; cuts off long responses ("got off the rails").
- **The five new memories are a v4 spec spread across files**. Worth consolidating into `v4/SPEC.md` with pointers; not done yet (and user said don't make new memories without explicit ask).
- **Updated audit estimate**: chat_log/20260506.0 shows v4 is much further than the audit assumed. Lower-module is unblocked, editor lane shipped, ghcache integration reframed as sprf-native (not a Rust integration), cross-repo crawler designed but not built.
