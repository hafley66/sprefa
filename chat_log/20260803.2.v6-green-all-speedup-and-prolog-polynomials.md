## Key Insights
- **golden-flex.dl6 exists and was green the whole time.** 468 lines, 62 registry
  constructs (49 exercised + 13 named refusals), graded six ways, SELF-GATING:
  compile/scripts/golden_coverage.pl reads registry.pl's live rows and fails BY
  NAME if a construct is not exercised. That is the shape a golden should have.
- **The 79 in 4_hosts.test.ts was never "all rows".** It was exactly the spine
  4_ingest.ts reads: node 41 + edge 36 + sig 0 + site 1 + const 1. The 3 new aux
  rows sit above it and nothing consumes them. Grading per record kind lets the
  aux layer move; a bare total cannot.
- **refusal_inventory/1 walked every clause of twelve modules on EVERY rendered
  refusal.** 340ms per refusal, and diag.pl renders both channels, so one
  diagnostic in the editor path cost ~0.7s to produce one line of text. The 131
  seconds off plunit was the side effect, not the point.
- **library(prolog_wrap) is how you decorate in Prolog.** wrap_predicate/4 gives
  you the original as a Closure; counting on both sides yields calls AND
  solutions, and solutions-minus-calls is the backtracking yield no profiler
  shows. It found group_key/3 (667,216 calls / 24,404 solutions) in ONE run after
  I had spent three rounds bisecting by hand. Harness: scratchpad/instrument.pl.
- **157s of the 257s serial battery was a script sitting still.** 64 sleeps: 48
  are correct readiness polls, a handful are stability polls costing N x interval
  regardless of machine speed, the rest are proving-an-absence. All three trace
  to one gap: the engine never publishes "I have quiesced", so every gate spells
  "done" as a duration.
- **Longest-job-first matters on a bounded pool.** multirepo-golden is 5.7s alone
  and 50s under contention; starting it first took the battery 211s -> 177s.
- **A gate must not build.** Eight scripts ran `cargo build --release` on a
  missing binary. staleness-gate already exists for that and already prints the
  command.
- Deepseek flash lane settled "soak test": not LLM jargon. Documented 1950 (paint
  catalog, water immersion), hardware-first, in software by 1984 (BBC Micro disk
  guide). I relayed a Google Ngram "first non-zero year 1940" row as VERIFIED and
  the owner correctly rejected it: an Ngram frequency series is not an
  attestation, and the lane itself admitted it could not pin 1940 to a title.
