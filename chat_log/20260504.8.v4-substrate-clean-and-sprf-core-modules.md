## Key Insights
- **Term as mapBy**: ALL-CAPS bare ident = string-scoped accessor. TERM (Read) pulls cursor.get(name) into &.value; TERM? (Bind) writes &.value into cursor.terms[name]. Shadowing fine. Brace `${...}` syntax retired in favor of bare form.
- **DSL holes = Pipe**: not tokens. CST grammar's hole resolves to a Pipe value that operators can consume as an inner pipe (e.g., `fs(<Pipe>)`).
- **NextQ resume via cursor mark**: park-state lives on the cursor itself (`:nextq:<chan>="1"`) so wake-up survives sqlite restart. No external state needed for resumability.
- **Bus is fire-and-forget by design**: synchronous listeners, no replay value on restart, no persistence wanted. Bus = invalidation channel, queue = truth.
- **Park-as-row, not park-as-listener**: 10k parked rows = 10k sqlite rows + B-tree pages, not 10k closure listeners. dispatch_park = indexed UPDATE.
- **HybridQueue knob**: `park_flush_interval` is the durability SLO. T=0 = always sql (no hot tier). T=∞ + cap = mostly mem.
- **Fact declare-time indexing**: fact's columns are known upfront from declaration syntax (`fact(:name, X?, Y?)`); rule's body terms aren't (parse-time graph). So fact-side indexing unblocks today; rule-side waits for lowerer.
- **Reactivity decomposition**: cascade_delete + Memoize source_row tracking + content_hash reconciliation is the React-key-reconcile shape. Three layers: (a) substrate provides cascade_delete primitive, (b) Memoize knows which row to cascade, (c) reconcile diffs old vs new children by content_hash.
- **Pipe definition itself NOT serialized**: host rebuilds from compiled .sprf on startup. That's fine until reactivity grain demands per-pipe identity for fine invalidation.

## Open Questions
- Should FactStore index on `(value)` only, or `(col, value)`? Composite (col, value) is more selective per query but may bloat the index. Single-col query is the common pattern — go composite.

- Reconcile slice: needed for fine invalidation but is bigger than a single commit. Probably (a) cascade_delete first, (b) Memoize source_row_id second, (c) content_hash diff reconcile third.
- v4 legacy Op trait + drive_with: kept for now (the existing v4-bench --substrate doesn't use them — it builds on substrate Components directly via substrate_ops.rs). Retire in a separate slice.
