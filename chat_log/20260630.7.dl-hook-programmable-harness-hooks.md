## Problem/Context
- LSP can't force-load: CC has no native LSP client; rust-analyzer reaches CC only via an open IDE (built-in IDE MCP getDiagnostics). Hooks are the only editor-independent, tool-use-triggered, context-injecting channel. MCP is pull-only. (Headless rust-analyzer MCP servers exist e.g. zeenix/rust-analyzer-mcp but still pull-only.)
- No mature Rust CC-hooks SDK (conclaude/claude-hook-advisor are generic CLIs). Official PostToolUse schema: tool_name, tool_input.file_path, session_id; output hookSpecificOutput.{hookEventName,additionalContext} or decision:block.
- User flagged the sidecar-marker-file load-once as "backwards" -> rebuilt declaratively as skill_loaded rel (option 1).

## Solution/Approach
- Condition = dl rule (mirrors diag/rails). Daemon=brain, --hook=thin pipe.
- The user's actual rule (covers reads, not just edits) uses `changed` not `agent_touch`:
  `inject_skill("testing") <- changed(p), p =~ /\.(test|spec)(\.|$)/, !skill_loaded(_, _, "testing").`

## Key Insights
- match(p,rev,/(?<desc>.+)/,_) named capture binds captured TEXT straight to a var (no ref/string spine needed). split(p,"/",-2) gets path segment; nested split works in head position. `var = split()` FAILS as a constraint ("unbound") — put split() directly in head.
- Dynamic regex: `=~ re:${x}` and bare `/${x}/` FAIL; use GLOB `~~ "*${x}*"` (string interpolation works in "..." and typed-literal bodies, lexer StrPart::Var).
- scan does hidden(false) (engine.rs:4757) so .claude IS walkable; earlier empty was the `var=split` error + glob, not hidden-skip.
- skill-router REVERSAL PROVEN: scan skills/**/SKILL.md -> skill name(dir)+keyword -> `inject_skill(skill) <- skill_kw(skill,kw), changed(c), c ~~ "*${kw}*", !skill_loaded(_,_,skill)` routed egui-dnd on a changed egui file with ZERO hardcoded names.
- examples docs auto-gen: gen-reference.dl scans v5/examples/*.dl, first `#` line -> docs/reference/examples.md. CLI/rel/op/fn tables auto from clap+engine inside <!-- BEGIN --> markers. Only refresh when gen-reference RUNS (daemon on source edit, or manual).
- changed() includes untracked (git status -uall). db::open(None)=in-memory so default --hook can't fight daemon cache.db lock. tbl(name)="rel_{name}". daemon serves multiple requests per connection (handle_connection loops).
