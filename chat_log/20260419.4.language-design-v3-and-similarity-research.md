## Problem/Context
Term language `${...}` semantics beyond identity-bind. Iterated through four framings, each shrinking surface while growing expressive power:
1. Constraint chain (predicate-only, retracted)
2. Recursive pipeline at expansion site (`${...}` body = host expr grammar)
3. Expression-as-matcher (first expr IS match condition; walker delegates leaf eval; `&` = current cursor; `;` Fork carries through)
4. Three realms collapse (op chains + capture chains + var/let are one realm; bind = name a stream-producing expression; lowercase ops vs UPPERCASE binds via prolog convention)

Five load-bearing decisions surfaced for collapse to hold: casing-as-syntax, `&` semantics per host, `&{}` vs `${}` access stay distinct, named pipelines as compiled values not macros, core ops mutate slots never auto-bind. None decided.

## Key Insights
- **Unification muscle pattern**: when a feature feels like it needs new syntax/realm, sit longer. Existing primitives usually absorb it. Four iterations of the term-language question converged to one realm.
- **Three realms collapse**: op pipelines, capture chains, var/let bindings are one mechanism if "bind = name a stream-producing expression."
- **Lowercase/UPPERCASE prolog convention**: parser disambiguates verb (op) vs noun (bind) by first character. Polarizing taste choice.
- **sh[] is a cut**: shell ops have asymmetric binding semantics vs ast[lang] — host values flow IN via `${X}` interpolation, no structured bindings flow OUT. Output is bytes, re-parsed downstream by explicit op.
- **Cursor as universal currency**: `(fs, repo, rev) + content + byte_range + slots + captures` lets one expression cover main↔main CI, branch↔tag spot-checks, working-tree↔deployed loops without GitHub Actions matrix fan-out.
- **`.sprf` is the source artifact**: human-readable expectation document; SQLite is the materialized view. The query language IS the file format.
- **Cross-codebase typed edges thesis**: declarations durable across renames and repo boundaries because the `.sprf` file owns the edge, not the code.
- **Prior art net read**: sprf = Glean variant + Racket grammar layering + Salsa reader incrementality + CUE bind algebra + SQL terminal CodeQL would never adopt. None covers full surface.
- **Market-fit is wrong loss function**: sprf is personal research per existing memory, not adoption-targeted. Cobbled `ast-grep + Soufflé + python` solves symptoms; sprf solves the unified mental model.
