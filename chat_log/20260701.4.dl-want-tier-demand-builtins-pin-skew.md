## Key Insights
- Adding a builtin family = unit struct + impl RelKind (src/rels/mod.rs:60) +
  one line in rel_kinds() (:89); five call sites pick it up free. Skill now
  documents this correctly.
- Demand rels read by CONVENTION (eng.rels.get("rev_cmp_want") + SELECT over
  last tick's table) = the org-allowlist precedent; want rows this tick are
  LAST tick's derivations, same as data-driven scan.
- Shallow clones make ancestry counts WRONG (not incomplete) — grafted HEAD
  means every tag counts as ahead. Loud per-repo skip; blobless
  (--filter=blob:none) is the right corpus steady state: full DAG ~64KB/repo,
  lazy blob fetch serves scan-at-rev.
- scip_import drops a ref whose symbol has no def in the loaded index — an
  unresolved cross-repo ref is ABSENT, which is why scip_want's merged single
  load matters (def map spans merged docs).
- Engine::rel_rows read int columns as String → rusqlite per-row type error →
  silent row drop; fixed via ValueRef stringify.
- spine::normalize (strip non-alnum + lowercase, in _strings.norm) IS the
  cross-lang casing bridge: GetProduct/get_product/getProduct → getproduct;
  route templates /users/{id} vs /users/:id join today.
- gh api in this env does not decrement rate limit (existing memory,
  reconfirmed useful for fixture verification).
