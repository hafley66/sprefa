## Solution/Approach
**Core design:**
- Operators are pipe transforms: Stream<Cursor> -> Stream<Cursor>
- Store provides FREE READS, operators return EFFECTS only for mutations
- Pure operators have Effect = ()
- Diagnostics have EXACT byte ranges
- Box<dyn> everywhere - optimize later

**Key insight - Rules ARE operators:**
- `rule(dep) { ... }` = defines operator + creates store table
- `dep(name: $DEP) { ... }` = invokes dep operator, binding outputs
- Cross-refs are just operator calls reading from Store
- Built-in and user-defined rules unified under Operator trait

**Foundation operators:**
- repo("myorg/*") - filter by repo pattern
- rev("main") - filter by rev pattern  
- fs("**/*.json") - driver, lists files, expands 1->N
- json({ name: $NAME }) - extract with exact path error locations

## Key Insights
1. **Rules ARE operators** - both built-in and user-defined implement Operator trait
2. **Cross-refs are operator calls** - `dep(name: $DEP)` invokes dep, binds outputs
3. **Store is the glue** - rules write to store, cross-refs read from store
4. **Exact diagnostics** - operators own byte range calculation, not analyzer guessing
5. **Effect system** - pure ops have Effect=(), mutations return Effect enum
6. **Chaining is Vec<Operator>** - framework handles > pipe, not operators
