## Self-xray loop WORKS (the headline)
sprefa ingests rust-analyzer's own SCIP index of itself and queries it from a dl
program. `just oracle-index` runs `rust-analyzer scip . --output index.scip`
(~48s; the earlier "hang" was build-lock contention, not scip). `scip_import.rs`
parses it into `scip_edge(src,dst)` (file→file), `scip_def`, `scip_ref`.
`oracle-check.dl` antijoins `scip_edge` vs sprefa's `call_edge`-projected file graph.

## Experiment 1 — diet recall (subagent; full writeup `v5/research/recall-ratchet.md`)
**The "41% recall" was a scan-scope artifact, not an extraction deficit.** RA
indexes the whole crate (src + tests/it + build.rs + bins); the diet eval scan
was `src/**/*.rs` only. On comparable scope (both endpoints under src/), diet
recall is **79/81 = 97.5%** — only 2 genuine misses (both `crate::`-qualified
paths: `daemon→tray`, `engine→config`). The module diet parsing IS close to
standard Rust.

| lever | recall |
|---|---|
| current (src/ scan only) | 40.9% |
| widen scan to tests/build.rs/bins (measured) | 76.7% |
| + cross-crate name→lib-root resolver | ~82% |
| + `crate::`/`super::` path resolver | ~83% ceiling |

Residual 32 RA edges = noise (20 `→build.rs` cfg-extern, 11 reverse test-crate
artifacts) + 1 external crate. Past ~83% you're replicating RA build-script
linkage or multi-repo; use SCIP. My `recall-lever.dl` was BROKEN (the ref spine
carries `use` path specs, not identifier tokens — structurally false join);
subagent caught it.

## Critical context / gotchas
- **Stale-binary trap:** use `v5/target/debug/dl`, not `~/.cargo/bin/dl`.
- **Daemon interception:** one-shot `dl <file>` runs get absorbed by a running
  daemon even with `--db`; it serves stale cache. MUST isolate with fresh `--db`
  AND ideally `--no-daemon` (not yet built). This caused the phantom cycle.
- **Path parity:** RA scip paths are v5-relative (`src/X`); run sprefa with
  `--root v5` (not repo root) so call_def paths also become `src/X` and join.
  `SPREFA_SCIP_INDEX=<repo>/index.scip` since index lives outside `--root v5`.
- **Build lock:** `cargo` blocks while another session holds it; the other
  session did the 58-test-crate→1 collapse + lld wiring (commits 135baa9 etc.).
- **dl has no `like`.** Filter by equality/negation. `!=` works. Aggregate is a
  head arg: `c(count(x)) <- rel(x,_)`. Parenthesized `(x = y)` body atoms fail.
- **Build levers landed (other session):** lld linker, `debug=1` profile,
  58→1 test binary. Workspace test compile dropped from minutes to ~one link.
