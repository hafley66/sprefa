## Key Insights
- A tracked .cargo/config.toml with nightly/lld rustflags silently breaks ALL
  stable consumers (CI, release runners, end-user cargo install). Keep such
  perf tweaks LOCAL/untracked.
- dl is macOS-first: tray-icon/tao unconditional -> CI + dist macOS-only until
  cfg-gated. Linux needs GTK.
- curl|sh installers are blocked by Claude Code auto-mode policy regardless of
  chat authorization; compile the tool via cargo install instead.
- @next etag carry lags resp by a tick; latest-wins needs a monotone order
  (clock bucket), can't key on the live etag alone (lag re-fires old prev).
- Perf/git-fixture tests are CI-fragile; scope them out of the gate or harden.
