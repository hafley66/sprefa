## Key Insights
- The store's algorithms never crossed because tsv2 imports ONLY open_db/
  SqlRunner/types from sprefa-store (scratchStore.ts:14-15). Ideas crossed as
  emitted SQL (refcount, delta tables); the frontier-retirement property
  crossed only as a comment, so e3997cec could violate it unseen.
- PK-constraint rejection (INSERT OR IGNORE into a big keyed table) costs FAR
  more than a NOT EXISTS pre-filter at high duplication (D variant 4.4x loss).
- DRed pass 2 needs the head SHRUNKEN first; deferring the delete looks like a
  saving and is a 4.4x loss. Up-front delete = store's weight=0 mark.
- Two-pass DRed cost is algorithmic (store G2 reproduced); guard = mid-walk
  bail on the free cone count, never a seed-count pre-guess.
- WITH-clause name shadowing lets the emitted recursive arm text be reused
  verbatim for the loop hop: WITH "<head>"(cols) AS (SELECT cols FROM wave).
- Byte-identity across algorithm swaps comes from WITHOUT ROWID PK scan order;
  that is what let the CTE->loop swap grade 420/420 identical untouched.
- Statement-count rails must pin the FORMULA (affine, slope 3/round), not
  flatness, once a loop is the intended shape.
- chain vs grid: the loop beats the CTE on wide frontiers (~1.3x) and loses on
  deep-thin chains (round-trip overhead); shape-dependence is inherent.
- 30s = 7 writes/row x 10M rows; layer split: 2 problem, 3 SQLite fan-out tax,
  2 oracle scaffolding. Deleting a copy requires deleting the QUESTION it
  answers, not renaming it (index = copy; one-table probe proved the wash).
- gen_emitted regenerates via sweep stage 3; door-handwritten.ts via
  compile_dl6.sh; typecheck covers gen_emitted so stale modules = red wall.
- d2: md soft-breaks collapse (blank-line paragraphs to wrap); grid stretches
  every band to the widest; `name: |||md` fences need substring detection;
  sequence_diagram + nested containers = phase frames; shape vocabulary now in
  _house.d2 (receipt/db/scratch/stream/sqlstep/decide/rival/world/you).
