## Key Insights
1. **Yields = HITL coroutines** (locked 2026-04-26). Parked writes, tag-subscribe, Pending capture all collapse to one primitive. Redux-saga state separation is what makes pause/resume possible — Op::pipe must stay free of internal state. State lives in effect runtime / TagStore / pending queue.
2. **Writes are durable-by-default-parked**. WriteRangeEffect / WriteFileEffect / future SqlWriteEffect auto-park awaiting user approval; cancellable on upstream-cursor-invalidation. Eventually serializable to SQLite for cross-session resume (sprefa-azm future).
3. **Per-arg mode classification > op-level mode**. Tag dispatches per call by examining arg Value::Term modes; bound/unbound mix is normal (filtered read).
4. **Dynamic-schema yolo**. Tag tables widen by adding nullable columns. Rules currently fixed-schema (binding graph derives). May converge later.
5. **`&` op surface lives without a paren slot**. cursor_ref node in CST has only leader+'.'+path; lower_pipe sets name="&", from_paren_node parses the cursor_ref node (not op_invocation) directly.
6. **Render rebases cursor; format is metadata-only**. cursor.content becomes rendered bytes, byte_range = 0..len. Downstream write_cursor reads cursor.active() for new_bytes. fs/repo/rev preserved through rebase.
7. **WriteRangeEffect is the universal write primitive**. Same effect powers write_cursor today; future write_file(range), LSP code-action edits will reuse it. Modes :replace/:append/:prepend/:wrap.
8. **lsp[severity] split from render[lsp]**. Diagnostics carry richer kwargs (message/code/hint) than render's literal-bytes-with-carveouts shape.
