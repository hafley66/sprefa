## Problem/Context

### 1. Grammar fixes (5 issues → 0 errors)
- `~~` operator missing from cmp_op (glean.dl)
- scheme_body bare form `/[^ \t\r\n,)]+/` consumed the closing period on `` fs:`path`. `` because tree-sitter longest-match picked bare (12 chars) over fenced (11 chars). Fix: excluded backtick from bare regex.
- `label: value` named arguments in body atom calls (gen-doc-index.dl, lint-docs.dl). Moved `named_arg` from `term` choice to `arg_list` `commaSep(choice($.term, $.named_arg))` — GLR resolves the ambiguity at the arg_list level.
- `use`/`rel`/`gen` as rule names — tree-sitter 0.26 keyword extraction broken without `word` token (and `word` rejected for non-terminal symbols). Fix: removed `use_decl` from `_item` choice. `use "path".` syntax deferred.
- Added `def_template`/`rule` and `use_decl`/`rule` conflict declarations (latter marked unnecessary by ts).

### 2. Tray icon
Added `make_tray_icon()` → `tray_icon::Icon::from_rgba(32x32)` generating a blue (#3b82f6) ring with antialiased edges, transparent center. No external asset file.

### 3. Daemon RPC extensions
- `schema` — returns all `eng.rels` (relation name + columns/types) plus built-in SQLite tables (_file, _files, _where_bytes, module_import, module_edge_rev, crate_edge). Made `rels` and `db` `pub(crate)` on Engine.
- `query_sql` — runs arbitrary parameterized SELECT via `eng.db.conn()`, returns JSON rows. Engine method `query_sql(&self, sql, params) -> Result<Vec<Vec<Value>>>`.

Six trigger labels: `program edit`, `.dl discovery change`, `config change`, `git change`, `source change`, `empty event`.

## Key Insights
- tree-sitter longest-match lexing causes scheme_body bare form to beat fenced form when bare consumes the trailing period. Adding backtick to bare exclusion set fixes it.
- `named_arg` must be at arg_list level (not term level) for GLR to resolve the ambiguity between `identifier:expr` and bare `identifier` followed by unexpected `:`.
- tree-sitter 0.26 keyword extraction is broken without `word: $ => $.identifier`, and `word` rejects non-terminal symbols. Removing keyword-based rules from `_item` is the only workaround.
- `tray_icon::Icon::from_rgba()` takes raw RGBA Vec — no external asset file needed for a programmatic icon.
- Instant's dockview-react + panel pool + observable store is a near-complete micro-VSCode shell. Only missing monaco-editor.
