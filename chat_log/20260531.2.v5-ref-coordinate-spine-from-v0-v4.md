## Problem/Context
v5 has NO normalized coordinate. Strings inline as TEXT everywhere; spans ad-hoc per-relation
(sg=4 cols, module_import=line, module_edge=nothing); keys are raw rev-string/content-hash/path text.
The recurring problems ARE the absence of the ref primitive:
- specifier↔edge won't join: module_import(specifier,line) and module_edge(src,dst) share no ref id.
- line/col sprawl: every extractor re-derives its own span columns.
- file identity: conflated until Stage 1's repo/rev/content/file split.

## Solution/Approach — RECOVERED v0→v4 COORDINATE TYPES (verbatim, for re-port)
The convergence: every era = a string occurrence at a byte span in a file.

## Key Insights
- THE primitive every version reinvents = `ref` = (string_id, file_id, lo, hi) [+ repo,rev]. v5 is the only version WITHOUT it.
- v4's one advance over v0: content-derived ids (blake3(canonical fields)[0..N]) REPLACE autoincrement ⇒ no allocator,
  stable across runs/machines, restart-safe, SQLite=cold truth + LRU=hot cache, id 0 = SYNTHETIC sentinel. The FD becomes an EQUATION not a lookup.
- FileId=blake3(content) gives the cross-repo file-identity collapse the data-model "never re-collapse" invariant needs — for free.
- normalize() (strip punct + lowercase) + FTS5 trigram = the OG cross-repo fuzzy-join axis (AuthService==auth_service). This is literally the v0 use case.
- value/id lattice (P4): a capture's TYPE picks its storage id-column (path→PathId INTEGER, not TEXT). v5 already has Type::File/Path/Dir — extend them.
- The refactor (auto module/import rewrite) and the module graph are the SAME table: refs = import graph AND rewrite coordinate. An edit = a ref + a new string_id. v0's "reverse refs" demo IS the refactor query.
- Port the COORDINATE types (pure normalization, the part Chris loves); DO NOT port FactStore/runtime_graph/support (DD machinery to exorcise).
- Module-graph status this session: ALL Rust+TS levers ✓ (incl multi-crate namespace, cross-crate use, #[path], nested braces, raw idents, comment/string strip, per-package tsconfig, workspace package.json fallback, dynamic import, Cargo package= rename); RA SCIP oracle precision 1.00; broken-import linter via --check/--lsp. 30 tests.
