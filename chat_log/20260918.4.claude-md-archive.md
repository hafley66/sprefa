## Standing laws (user-set, non-negotiable, every agent at every level)

- **Doubt yourself before asserting.** You are a compression algorithm, not an
  oracle. Verify against the code. If you lack the info, say so and go read it.
- **A refusal is a hypothesis, never an edict.** Most named refusals in this
  repo were decided by an agent with nothing measured. None is the user's word
  unless a `rulings.pl` row says so. Never report a refusal as a language limit.
  Trace it to the throw site, say whether it encodes a real impossibility or
  unfinished work, and fight it. "The language does not support X" needs the
  throw site cited.
- **Comments are not the language.** An agent that reads a comment and reports a
  language limit has not checked. Grep the manifest.
- **Build-vs-buy.** Never assert "write our own" for a common-shaped problem
  (queue, server, scheduler, parser, telemetry, retry, cache) without library
  research and a written candidate-by-candidate analysis first. No one-line
  dismissals.
- **Infra is bought, never built.** Scheduling, job queue, HTTP, daemon
  lifecycle, logging run on established libraries or the OS. The datalog engine
  core is the one legitimately bespoke layer.
- **boop never reinvents SQLite or SQL.** The store is plain SQLite at
  `~/.agent/boop.db`; `boop db "<sql>"` is the query surface. No bespoke
  query-flag DSLs. Canned reports are named SQL, visible and deletable.
- **Self-diagnosis before execution.** The system answers "why is it slow, what
  was it doing" from its own on-disk trail, including after SIGKILL.
- **Nothing seizes the machine.** CPU/IO/thread budgets capped
  (`apply_daemon_budget`). A change that can beachball the machine is a blocking
  defect.
- **The 10-second law.** Any single operation over 10s is a defect to
  investigate now, never a budget to normalize. Named exception: SCIP indexing.
  A multi-fixture battery is not a single operation. WAITING POSTURE (user
  2026-08-20): no agent foreground-waits more than 10s on one operation.
  Batteries run in background with a 10s per-test cap; anything that exceeds
  its cap is killed and investigated, never waited out.
- **Failure ledger.** Every incident that bites gets a `docs/failure-modes.md`
  entry: incident, RCA, fail-pre-fix test, rail, entry. No incident closes
  without one.
- **eprintln never comes back.** No `eprintln!` in `src/**` or `v5/src/**`; `tracing` only.
  Rare CLI-UX lines carry `@eprintln-ok`. `.dl/no-new-eprintln.dl` ratchets to
  zero.
- **Lang design happens with Chris in the room.** No lane, lab, or coordinator
  settles language or type-system design without the user. Findings come back as
  cited forks with throw sites. Implementation of an already-decided design is
  dispatchable.

## Style laws

- **Comment budget.** Comments state only constraints the code cannot show. No
  change-log narrative, dates, arc references, or restating the next line.
  Sabotage and fail-first receipts in TEST headers, and scanner-backed
  `@`-waivers, stay. History belongs in git and `plans/`.
- **Language vocabulary.** Construct names and design discussion use ONLY rxjs,
  prolog, or SQL words. "support" is banned; use refCount.
- **Surrogate keys.** Stored rels key on INTEGER ids. Natural or composite TEXT
  keys live ONCE in a dictionary table with UNIQUE on the natural key. A
  composite TEXT PRIMARY KEY in emitted or hand DDL is a DEFECT. TEXT keys
  measured 1.7-2.0x slower on identical tables; every index copies the full key.
  `.claude/skills/sql-relational-design` and `.claude/skills/sqlite-costs` are
  mandatory reads before any schema, DDL, or lowering design.
- **Every `.dl` snippet shown to the user carries its intended pure-rxjs
  lowering.** A construct whose rx lowering cannot be written is a design defect.
- **Formerly-quadratic paths get COUNT tests**: statement counts, or EXPLAIN
  showing SEARCH rather than SCAN. Never end-state equality alone. Additive only.
- N+1: never a per-row write. Collect the set, one `Db::insert_rows`.
- dl variable names are descriptive, never single-letter, in every snippet.
- **Every new class declares its interface in the package's header `types.ts`**
  (`sprefa-store/js/src/{engine,lower}/types.ts`, `dl/src/0_types.ts`).
  Important functions are interface-bound, never bare `export function`.
  Interfaces carry the `I` prefix. Type names say what the thing is on first
  reading.
- **Exactly ONE manual `.subscribe()` per app.** No Subscription fields, no
  Subject request/response bridges.
- **Async becomes rxjs; sync stays sync.** Promise/async banned above the
  SqlRunner seam. In-memory list work is plain array code returning arrays. SQL
  building sync, running Observable. TRAP: `await someObservable` silently never
  subscribes.
- Recompute guard: any from-scratch re-derive on a reactive rule needs a digest
  early-out or `// @recompute unguarded: <reason>`. Rail:
  `v5/examples/recompute-guard.dl --check`.
- Colocated consistency: inside a file, follow that file's existing style.
- Banned words, prose AND identifiers: provenance, substrate, load-bearing,
  regime. Use source, base, critical, mode.
- **"refusal" is banned in prose.** A compiler error for an unbuilt construct is
  "TODO" or "not built yet". The word stays only in literal code identifiers and

## RxJS: `.subscribe()` is `ReactDOM.render` (2026-09-11)
One per application, at its boundary. A library calls it NEVER; it returns the Observable.
A docs example, demo, or README snippet calls it NEVER; showing it teaches the defect.
A test may, because the test is the boundary. Effects go in the stream as `tap`, and the
stream is returned. A function taking a callback is the same defect wearing a hat: the
caller puts effects in the callback instead of the pipeline, which means the pipeline was
built forwards from its input rather than backwards from its output. Expected count of
`.subscribe(` in a library package, `examples/`, `docs/`, `demo/`: zero. Never write that
some number is acceptable. Full rule: the `rxjs` skill.

## Build-vs-buy (all projects, all agents)
Never claim "write our own" is right for a common-shaped problem (queue, server, scheduler,
parser, telemetry, retry, cache) without first researching libraries and presenting a written
candidate-by-candidate analysis. No one-line dismissals of libraries. Research before bespoke
code, every time, at every agent level.

## ANSI color in chat output (2026-09-09)
This machine runs `claude-color` (`~/.local/bin/claude-color`): patched binary plus a
localhost proxy (`~/projects/claude-ansi/ansi-proxy.js`) that inserts the ESC byte the API
strips. Assistant text can carry real SGR color.

Author as a **bare bracket sequence**: `[38;5;114mgreen[0m`. Nothing before the `[`. The
proxy's `CSI` regex matches `\[(\d{1,3};){0,5}\d{1,3}m` and prepends `\x1b`.

Displaying a code is the opposite of applying one. A bare `[32m` in a table cell, doc example,
or code fence is still converted, so the terminal eats it and the cell renders empty. Prefix
a code shown as text with `\e` (or any `DOCUMENTED` marker): `\e[32m` displays, `[32m` applies.

Never write the escape yourself when applying color. `␛`, `\e`, `\x1b`, `\033`, `ESC`, `CSI`,
`^[` and a trailing `\` sit in the proxy's `DOCUMENTED` guard: the sequence stays literal text,
or the glyph renders as a visible ESC box beside working color.

Palette: 114 green, 203 red, 179 amber, 80 cyan, 68 blue, 176 magenta, 240 dim, 253 white,
`[1m` bold, `[0m` reset. Reset after every run; never leave color open across a newline.
Colored ASCII boards beat plain tables for status, pipelines, sparkline mockups. Bash stdout
is the fallback when a board needs computing rather than typing.
