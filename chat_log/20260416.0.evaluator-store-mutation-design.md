## Key decisions (locked this session)

### 1. Single fn, not a trait with 5 methods

User banned the name "runner" and the duplicate method surface. One
function:

```rust
pub fn evaluate(
    config:       Arc<RwLock<Config>>,
    source:       watch::Receiver<Arc<str>>,
    store:        Arc<dyn Store>,
    mutations_tx: mpsc::Sender<MutationRequest>,
    cancel:       CancellationToken,
) -> BoxStream<'static, RunEvent>;
```

File: `src/_7_evaluator.rs`. Single callsite for LSP + CLI + tests. Re-invokes
on `source`/`config` change. No `Evaluator` struct initially — if state needs
capturing later (metrics, handle for stop), wrap the fn; don't preemptively.

### 2. Scan pointers: dormant but reachable

User clarified: scan_pointers$ WAS meant to drive the loop for the v1
"parse every string const / import / export / folder path" indexing pass,
back when there was no pattern language. Pattern language exhausts the
closed set statically, so today scan_pointers don't drive anything.

Outcome:

- `src/_13_scan_check.rs` + `src/_14_scan_loop.rs` stay untouched and
  unwired. No ops populate claims today.
- When string-index extractor lands (future session) and/or lazy-eval op
  flag lands, they re-enter via these files. Mechanism stays intact.
- Current role: scan-check annotates `Tri::Verified` on captures whose
  value matches `Config.repos`/`Config.revs`/`files`. That annotation
  populates FK columns on flush_batch. Everything else is dormant.

### 3. scan_pointers become SQLite FK columns

For captures carrying `scan_pointer: Some(...)`:

- `"repo"` → `{col}_repo_id` FK → `repos.id`
- `"rev"`  → `{col}_rev_id`  FK → `repo_revs.id`
- `"fs"`   → `{col}_file_id` FK → `files.id`

Populated on insert via `Tri::Verified` resolution. Enables cross-rule
joins and mermaid diagrams of repos pointing to repos. Zero evaluator
change — pure schema + flush_batch extension.

### 4. Store trait owns persistence AND mutation cache

User said "cursor cache full agree, but is part of Store trait just fyi
since i want mutator to be interfaced that way". Locked:

```rust
#[async_trait]
pub trait Store: Send + Sync {
    async fn flush_batch(&self, batch: Batch) -> Result<()>;
    async fn query_rule(&self, rule: &str, where_: Where) -> Vec<Row>;
    async fn files_scanned(&self, repo: &str, rev: &str)
        -> HashSet<(FilePath, ContentHash)>;

    async fn effect_status(&self, e: &Mutation) -> EffectStatus;
    async fn record_effect(&self, e: &Mutation, o: EffectOutcome) -> Result<()>;
}

pub enum EffectStatus { Skip, Emit, Stale { prev_outcome: EffectOutcome } }
```

`MutationSideEffector` is a thin Store client, not a peer. Single sqlite
pool, one source of truth. `mutations` table stores pending + resolved
prompts for later hover-history.

### 5. MutationSideEffector = coroutining via mpsc + oneshot

Rename from WriteEffector. User: "WriteEffector is really the
MutationSideEffector". Writes are FS/shell/render mutations with approval
gate. Ops emit `MutationRequest` on a side channel, await approval on a
oneshot.

```rust
pub struct MutationRequest {
    pub effect: Mutation,
    pub ack:    oneshot::Sender<Approve>,
    pub cancel: CancellationToken,    // clone of evaluator token
    pub rule:   Arc<str>,
    pub site:   Arc<ParseSite>,
}

async fn await_approval(ctx: &OpCtx, effect: Mutation)
    -> Result<Approve, Cancelled>
{
    let (tx, rx) = oneshot::channel();
    ctx.mutations.send(MutationRequest {
        effect, ack: tx, cancel: ctx.cancel.clone(),
        rule: ctx.rule.clone(), site: ctx.current_site.clone(),
    }).map_err(|_| Cancelled)?;

    tokio::select! {
        biased;
        _   = ctx.cancel.cancelled() => Err(Cancelled),
        ack = rx                     => ack.map_err(|_| Cancelled),
    }
}
```

Async-rust IS coroutining. No new scheduler or primitive. Back-pressure
falls out of the stream shape.

### 6. Mutation prompts = diagnostics

User: "for approval, its just like diagnostics for lsp/cli, dont over
fit". `RunEvent::MutationPrompt { ... }` alongside `Diag`. LSP renders as
hover with diff preview. CLI as y/n. Daemon as auto-approve or queued.

```rust
pub enum RunEvent {
    Cursor         { rule: Arc<str>, cursor: Cursor },
    RuleDone       { rule: Arc<str> },
    Diag           { diag: Box<dyn Diagnostic> },

```

Store records prompts in `mutations` table with outcome. Hover over a
warning later can show historical y/n.

### 7. Drop / cancel / memory safeguards (load-bearing)

User past-bug: v1 LSP processes took all CPU in the background. Design
for Drop from day one.

- `TaskGuard(Option<JoinHandle<()>>)` wraps every `tokio::spawn`. Drop
  impl calls `handle.abort()`. No detached tasks, ever.
- `OpCtx.cancel: CancellationToken` threaded everywhere. Evaluator owns
  the root token; Drop fires `cancel.cancel()`.
- All channels bounded. `mpsc::channel(cfg.runtime.buffer_size)`, never
  `unbounded_channel`. Producers back-pressure on slow consumers;
  leaks are bounded.
- `await_approval` double-belt: `select! { biased; cancel | rx }`. Either
  cancel fires OR ack sender drops; op bails in one poll tick.
- `DocSession::on_source_change` drops the prior evaluator guard BEFORE
  starting a new one. No zombie evaluations.

### 9. LSP + daemon = one process

User: "lsp + daemon are 1 and same with locality of ram even tho we
introduce sqlite". Locked.

- One tokio runtime, one `Arc<dyn Store>`, one evaluator, one watcher.
- SQLite is durability + query substrate, not an IPC boundary.
- Hot path reads live in RAM caches (ResultStore for xrefs, DocSession
  `last_run` for LSP). SQLite is cold path / persistence.
- CLI is a separate binary that opens sqlite read-only when daemon is
  down, or speaks JSON-RPC over unix socket to the daemon when it's up.
  Zero cache-coherence problem because there's one writer.

## Refinements (supersede specific decisions above)

### R1. Mutation is a dyn trait, not a closed enum

User: "i dont want every op having to add its own mutation effects
branch/arm, might go SlotKey route". Every op owns its own effect
struct; framework holds `Arc<dyn MutationEffect>`.

```
pub trait MutationEffect: Send + Sync + Debug + 'static
  fn kind_sigil(&self)         -> &'static str   # stable routing key, e.g. "fs.write"
  fn preview_markdown(&self)   -> String         # hover body / prompt diff
  fn fingerprint(&self)        -> Arc<str>       # cache key for effect_status
  fn content_stable_since(&self, DateTime<Utc>) -> bool { false }
  async fn apply(&self, MutationScope) -> Result<EffectOutcome, EffectErr>
```

Store persists by kind_sigil + fingerprint + preview_md + outcome.
New effect kinds are new impls; zero framework change. Matches the
"ops own everything" mandate already applied to diagnostics, patterns,
hover.

### R2. `render` is a pure cursor op, not a mutation

Render stamps rendered text into the cursor (evidence slot or content),
does not touch external state, does not traverse MutationSideEffector.
Console dump is the pipeline driver's choice (CLI prints cursors by
default), not the op's side effect. `write(path){...}` and
`marker_write(...){...}` ARE mutations and do traverse it.

### R3. Entry point is `init_cursors`, not "evaluator"

User: "we start by init_cursors(cursor_exprs, config, store)". No
`Evaluator` struct or trait. One fn. Callers own the reparse loop.

```
pub fn init_cursors(inp: InitInputs) -> BoxStream<'static, RunEvent>

pub struct InitInputs
  exprs:        Vec<CursorExpr>
  config:       Arc<Config>
  store:        Arc<dyn Store>
  reader:       Arc<dyn Reader>
  writer:       Arc<dyn Writer>
  registry:     Arc<OperatorRegistry>
  mutations_tx: mpsc::Sender<MutationRequest>
  cancel:       CancellationToken
  run_id:       RunId
  scanner_hash: Arc<str>
```

File: `src/_7_init_cursors.rs`.

### R4. Ops are cursor → cursor; `rule` is just one of them

Not a rename. A reframe. Root scope of a `.sprf` file is
`Vec<CursorExpr>` delimited by `;`. Each `CursorExpr` is a Pipeline
tree. The `rule(R)` op, when present at the head, binds the expression
a name for cross-ref lookup. Anonymous cursor_exprs are legal —
they run and emit cursors, they just aren't addressable via
`${other.$VAR}`.

```
pub struct CursorExpr
  pub name:     Option<Arc<str>>   # Some(R) when rule(R) op at head
  pub pipeline: Pipeline

pub struct LowerOutcome
  pub cursor_exprs: Vec<CursorExpr>   # was: pipelines: Vec<(Arc<str>, Pipeline)>
  pub diags:        Vec<Box<dyn Diagnostic>>
```

### R5. RunEvent renames

```
pub enum RunEvent
  Cursor         { expr_name: Option<Arc<str>>, cursor: Cursor }
  ExprDone       { expr_name: Option<Arc<str>> }            # was: RuleDone
  Diag           { diag: Box<dyn Diagnostic> }
  MutationPrompt { effect: Arc<dyn MutationEffect>, ack: oneshot::Sender<Approve> }
  Done
```

### R6. Store trait uses `expr_name`, not `rule`

On-disk SQL table names stay `{ns}__{rule}_data` for v1 schema
continuity — the string identifier is still called `rule` in DDL.
Rust-side API surface switches to `expr`:

```
Store::register_expr_schema(ExprTableSpec)    # was: RuleTableSpec
Store::query_expr(expr_name, Where)           # was: query_rule
```

The sqlite table name literal still says `_data`; only the Rust
parameter names move to `expr`.

### R7. Mutation cache check is inlined into `await_approval`

```
async fn await_approval(ctx, effect) -> Result<Approve, Cancelled>
  match ctx.store.effect_status(&*effect).await
    Skip         → return Ok(Yes)     # cache hit: proceed as approved; op still calls record_effect for idempotency
    Stale(_)     → /* show prompt with "stale" badge */
    Emit         → /* show prompt fresh */
  # ... oneshot + biased select as before
```

### R8. Handler respawns on reparse

`DocSession::on_source_change` cancels the old token, creates a new
one, respawns the mutation handler on a fresh mpsc. Prevents the old
handler task from lingering on old prompts. TaskGuard drop on the old
handler aborts any pending `handle()` call.

  async fn register_expr_schema(&self, spec: ExprTableSpec) -> Result<(), StoreErr>
    prior = sqlx::query_as::<_, (String, String)>
      "SELECT schema_hash, extract_hash FROM sprf_meta WHERE expr_name = ?"
      .bind(&*spec.expr_name)
      .fetch_optional(&self.pool).await?

      ExprChange::New             → ()

      build_view_ddl(&spec),
      build_refs_view_ddl(&spec),

      spec = specs.get(&eb.expr_name).ok_or(StoreErr::UnknownExpr)?
      insert_expr_rows(&mut tx, spec, &eb.rows, &string_ids, &file_ids, &ref_ids).await?

         JOIN rev_files rf ON rf.file_id = f.id
         JOIN repo_revs rr ON rr.id = rf.rev_id
         JOIN repos     r  ON r.id  = rr.repo_id

      .bind(repo).bind(rev).bind(scanner_hash)
      .fetch_all(&self.pool).await?

      .map(|(p, h)| (FilePath(Arc::from(Path::new(&p))), ContentHash(Arc::from(h))))
      .collect())

  async fn effect_status(&self, e: &dyn MutationEffect) -> Result<EffectStatus, StoreErr>
    fp  = e.fingerprint()
    sig = e.kind_sigil()
    row = sqlx::query_as::<_, (String, i64, String)>
      "SELECT outcome, when_, effect_hash FROM mutations
        WHERE kind_sigil = ? AND fingerprint = ? AND superseded_at IS NULL
        ORDER BY when_ DESC LIMIT 1"
      .bind(sig).bind(&*fp)
      .fetch_optional(&self.pool).await?
    match row
      None                                  → Ok(EffectStatus::Emit)
      Some((outcome, ts, hash))             →
        dt     = DateTime::<Utc>::from_timestamp(ts, 0).unwrap()
        result = EffectResult::from_str(&outcome)
        eo     = EffectOutcome { result, when: dt, effect_hash: Arc::from(hash) }
        match result
          EffectResult::Applied
            if e.content_stable_since(dt) → Ok(EffectStatus::Skip)
            else                          → Ok(EffectStatus::Stale(eo))
          EffectResult::Rejected          → Ok(EffectStatus::Emit)
          EffectResult::Superseded        → Ok(EffectStatus::Emit)

      .bind(e.preview_markdown())
      .bind(o.result.as_sql_str())
      .bind(&*o.effect_hash)
      .bind(o.when.timestamp())
      .execute(&self.pool).await?
    Ok(())

    Some(_)                                                             → ExprChange::ExtractChanged

  match &s.namespace
    Some(ns) → format!("{ns}__{}_data", s.expr_name)
    None     → format!("{}_data",       s.expr_name)

pub fn view_name(s: &ExprTableSpec) -> String
  data_table_name(s).trim_end_matches("_data").to_string() + "_view"

pub fn refs_view_name(s: &ExprTableSpec) -> String
  data_table_name(s).trim_end_matches("_data").to_string() + "_refs_view"

pub fn build_data_table_ddl(s: &ExprTableSpec) -> String
  cols = vec
    "id INTEGER PRIMARY KEY AUTOINCREMENT"
    "repo_id INTEGER NOT NULL REFERENCES repos(id)"
    "rev     TEXT    NOT NULL"
    "file_id INTEGER NOT NULL REFERENCES files(id)"
  for c in &s.captures
    cols.push(format!("{}_ref INTEGER REFERENCES refs(id)",     c.name))
    cols.push(format!("{}_str INTEGER REFERENCES strings(rowid)", c.name))
    match c.scan_pointer.as_deref()
      Some("repo") → cols.push(format!("{}_repo_id INTEGER REFERENCES repos(id)",     c.name))
      Some("rev")  → cols.push(format!("{}_rev_id  INTEGER REFERENCES repo_revs(id)", c.name))
      Some("fs")   → cols.push(format!("{}_file_id INTEGER REFERENCES files(id)",     c.name))
      _            → ()
  format!("CREATE TABLE IF NOT EXISTS {} ({})", data_table_name(s), cols.join(", "))

pub fn build_view_ddl(s: &ExprTableSpec) -> String
  # SELECT data.id, r.name AS repo, data.rev, f.path AS file,
  #        s_X.value AS X, s_Y.value AS Y, ...
  # FROM <data> d
  #   JOIN repos r ON r.id = d.repo_id
  #   JOIN files f ON f.id = d.file_id
  #   LEFT JOIN strings s_X ON s_X.rowid = d.X_str
  #   LEFT JOIN strings s_Y ON s_Y.rowid = d.Y_str
  cols = vec!["d.id", "r.name AS repo", "d.rev", "f.path AS file"]
  joins = Vec::new()
  for c in &s.captures
    cols.push(format!("s_{}.value AS {}", c.name, c.name))
    joins.push(format!("LEFT JOIN strings s_{} ON s_{}.rowid = d.{}_str",
                       c.name, c.name, c.name))
  format!
    "CREATE VIEW IF NOT EXISTS {} AS
     SELECT {}
     FROM {} d
       JOIN repos r ON r.id = d.repo_id
       JOIN files f ON f.id = d.file_id
       {}"
    view_name(s), cols.join(", "), data_table_name(s), joins.join("\n    ")

pub async fn await_approval(ctx: &OpCtx, effect: Arc<dyn MutationEffect>) -> Result<Approve, Cancelled>
  # cache check first; skip prompt when Store says Skip
  status = ctx.store.effect_status(&*effect).await.unwrap_or(EffectStatus::Emit)
  match status
    EffectStatus::Skip     → return Ok(Approve::Yes)
    EffectStatus::Stale(_) → ()                                 # fall through with "stale" implied
    EffectStatus::Emit     → ()
  (ack_tx, ack_rx) = oneshot::channel()
  req = MutationRequest
    effect: effect.clone()
    ack:    ack_tx
    cancel: ctx.cancel.clone()
    expr:   ctx.expr_name.clone()
    site:   ctx.current_site.clone()
  if ctx.mutations.send(req).await.is_err()
    return Err(Cancelled)
  tokio::select!
    biased
    _   = ctx.cancel.cancelled() → Err(Cancelled)
    ack = ack_rx                 → ack.map_err(|_| Cancelled)

use futures_util::stream::{StreamExt, BoxStream}
use tokio::sync::{mpsc, Mutex}
use tokio_util::sync::CancellationToken
use std::sync::Arc
use std::collections::HashMap
use crate::_0_types::{Cursor, CursorExpr, ParseSite, RunEvent, RunId, OpId, Capture}
use crate::_1_diagnostic::Diagnostic

use crate::store::{Store, Batch, ExprBatch, RowInsert, ExprTableSpec, CaptureColumn}

pub struct InitInputs
  pub exprs:        Vec<CursorExpr>
  pub config:       Arc<Config>
  pub store:        Arc<dyn Store>
  pub reader:       Arc<dyn Reader>
  pub writer:       Arc<dyn Writer>
  pub registry:     Arc<OperatorRegistry>
  pub mutations_tx: mpsc::Sender<MutationRequest>
  pub cancel:       CancellationToken
  pub run_id:       RunId
  pub scanner_hash: Arc<str>

pub fn init_cursors(inp: InitInputs) -> BoxStream<'static, RunEvent>
  stream! {
    result_store = Arc::new(ResultStore::new())
    # 1. Register schema for every named expr; diagnoses hash drift by
    #    dropping / clearing rows as needed.
    for expr in &inp.exprs
      if let Some(n) = &expr.name
        spec = build_expr_table_spec(expr)
        match inp.store.register_expr_schema(spec).await
          Ok(_)  → ()
          Err(e) → yield RunEvent::Diag { diag: Box::new(e) }
    # 2. Run exprs in topo order (so xref producers drain before consumers).
    ordered = topo_sort_exprs(&inp.exprs)
    for expr in ordered
      if inp.cancel.is_cancelled() then break
      ctx = build_op_ctx(&inp, expr, result_store.clone())
      empty = futures_util::stream::iter(Vec::<Arc<[Cursor]>>::new()).boxed()
      mut s = expr.pipeline.run(empty, ctx)
      loop
        tokio::select!
          biased
          _ = inp.cancel.cancelled() → break
          next = s.next() →
            match next
              None        → break
              Some(batch) →
                for c in batch.iter()
                  if inp.cancel.is_cancelled() then break
                  yield RunEvent::Cursor
                    expr_name: expr.name.clone()
                    cursor:    c.clone()
                  if let Some(n) = &expr.name
                    result_store.append(n, c.captures.clone())
      if let Some(n) = &expr.name
        result_store.mark_complete(n)
      yield RunEvent::ExprDone { expr_name: expr.name.clone() }
    # 3. Flush all named-expr rows into the Store.
    if inp.cancel.is_cancelled()
      yield RunEvent::Done
      return
    batch = build_batch_from_result_store(&result_store, &inp.exprs, &inp.scanner_hash)
    if let Err(e) = inp.store.flush_batch(batch).await
      yield RunEvent::Diag { diag: Box::new(e) }
    yield RunEvent::Done
  }.boxed()

fn build_op_ctx(inp: &InitInputs, expr: &CursorExpr, rs: Arc<ResultStore>) -> OpCtx
  OpCtx
    run_id:       inp.run_id
    op_id:        OpId(0)
    reader:       inp.reader.clone()
    writer:       inp.writer.clone()
    config:       inp.config.clone()
    diags:        DiagSink(Arc::new(|_d| { /* collected at a higher layer */ }))
    events:       EventSink(Arc::new(|_| {}))
    result_store: rs
    xref_seen:    Arc::new(Mutex::new(HashSet::new()))
    store:        inp.store.clone()
    mutations:    inp.mutations_tx.clone()
    cancel:       inp.cancel.clone()
    expr_name:    expr.name.clone()
    current_site: expr.pipeline.head_parse_site()

fn topo_sort_exprs(exprs: &[CursorExpr]) -> Vec<&CursorExpr>
  # Dep edges: expr A depends on expr B if A's pipeline contains
  # `${B.$VAR}` xref. Use existing xref graph builder.
  deps = build_xref_graph(exprs)
  kahn_sort(exprs, deps)

fn build_expr_table_spec(expr: &CursorExpr) -> ExprTableSpec
  bound = collect_bound_captures(&expr.pipeline)            # walk pipeline, union binds_captures()
  captures = bound.into_iter()
    .map |(name, scan_pointer)|
      CaptureColumn { name, scan_pointer }
    .collect::<Vec<_>>()
  schema_hash  = crate::store::_3_ddl::schema_hash_of(/* spec in progress */)
  extract_hash = crate::store::_3_ddl::extract_hash_of(expr)
  ExprTableSpec
    expr_name:    expr.name.clone().expect("named expr")
    namespace:    namespace_for(&expr.pipeline)              # from .sprf file stem via ParseSite
    captures
    schema_hash
    extract_hash

fn build_batch_from_result_store(
  rs: &ResultStore,
  exprs: &[CursorExpr],
  scanner_hash: &Arc<str>,
) -> Batch
  mut per_expr = Vec::new()
  for expr in exprs
    if let Some(n) = &expr.name
      rows = rs.rows_of(n).unwrap_or_default()
      inserts = rows.into_iter()
        .map |cap_map| row_insert_from_captures(cap_map)
        .collect::<Vec<_>>()
      per_expr.push(ExprBatch { expr_name: n.clone(), rows: inserts })
  Batch { scanner_hash: scanner_hash.clone(), per_expr }

fn row_insert_from_captures(cm: HashMap<Arc<str>, Capture>) -> RowInsert
  # Every cursor's captures also carry repo/rev/fs refs via synthesized
  # well-known keys populated by repo/rev/fs ops. Pull those out, the
  # rest land as capture columns.
  repo     = cm.get("__repo").map(|c| c.value.clone()).unwrap_or_default()
  rev      = cm.get("__rev").map(|c| c.value.clone()).unwrap_or_default()
  file     = cm.get("__fs").and_then(|c| extract_filepath(c)).unwrap_or_default()
  evidence = cm.get("__evidence").and_then(|c| extract_evidence(c)).unwrap_or_default()
  captures = cm.into_iter()
    .filter |(k, _)| !k.starts_with("__")
    .collect()
  RowInsert { repo, rev, file, captures, evidence }

  pub fn on_source_change(&mut self, new_source: String)
    # 1. Cancel the current run. All in-flight op tasks bail; mutation
    #    handler exits; the awaiting oneshots resolve with Err(Cancelled).
    self.cancel.cancel()
    drop(std::mem::replace(&mut self._handler_guard, TaskGuard::noop()))  # abort old
    # 2. Fresh cancel token; fresh mutation channel + handler.
    self.cancel = CancellationToken::new()
    (mtx, mrx)  = mpsc::channel(self.reader.config.runtime.buffer_size)
    self.mutations_tx   = mtx
    self._handler_guard = crate::mutations::spawn_handler(
      self.mutations_handler.clone(), mrx, self.cancel.clone()
    )
    self.last_run = None
    self.reparse(new_source)

  pub fn ensure_run(&mut self)
    if !self.stale then return
    inputs = InitInputs
      exprs:        self.exprs.clone()
      config:       Arc::new(self.config_for_run())          # cloned, immutable for this pass
      store:        self.store.clone()
      reader:       self.reader.clone()
      writer:       self.writer.clone()
      registry:     self.factory_registry.clone()
      mutations_tx: self.mutations_tx.clone()
      cancel:       self.cancel.clone()
      run_id:       RunId(next_run_id())
      scanner_hash: crate::BINARY_HASH.into()
    self.last_run = Some(collect_run_report(init_cursors(inputs)))

fn collect_run_report(mut s: BoxStream<'static, RunEvent>) -> RunReport
  futures::executor::block_on(async
    mut by_expr = HashMap::new()
    mut diags   = Vec::new()
    while let Some(ev) = s.next().await
      match ev
        RunEvent::Cursor         { expr_name: Some(n), cursor } → by_expr.entry(n).or_insert_with(Vec::new).push(cursor)
        RunEvent::Cursor         { expr_name: None, .. }        → ()
        RunEvent::ExprDone       { .. }                         → ()
        RunEvent::Diag           { diag }                       → diags.push(diag)
        RunEvent::MutationPrompt { .. }                         → ()   # DocSession uses AutoApprove for tests
        RunEvent::Done                                          → break
    RunReport { cursors_by_expr: by_expr, diags }
  )

    .collect::<Vec<_>>()
    .join(", ")
