## Measurement/tracing — what we HAVE
- **Rust side**: rss (getrusage ru_maxrss), page faults (ru_majflt), disk r/w
  (proc_pid_rusage), timing — emitted as `target:"measure"` tracing events.
- **collector** = PROCESS-GLOBAL subscriber (`measure::collect`), swappable
  lock-serialized sink. MUST be global: sqlx runs SQLite on a worker thread, so a
  thread-local subscriber MISSED the SQLite trace. `collect(body) -> (T, Vec<Record>)`.
- **SQLite x-ray WORKS**: `sqlite3_trace_v2` PROFILE gives per-statement expanded
  SQL + nanosecond runtime; `sqlite3_db_status` gives cache hit/miss. Emitted as
  `target:"sqlite"` events. Handle chain (all PUBLIC, the "wall" was fabricated):
  `db.get_sqlite_connection_pool() -> .acquire().await -> .lock_handle().await ->
  .as_raw_handle() -> *mut sqlite3` (sea-orm 2.0 db_connection.rs:854 / sqlx 0.9
  connection/mod.rs:371). libsqlite3-sys 0.37 pinned = same type sqlx links.
