### Architectural decisions (saved as project memory project_v2_daemon_shape.md)
- Daemon, LSP, and fs watcher collapse into one process. LSP is the daemon.
- CLI is a thin SQLite-serialized client: warm from store → run → serialize → exit. Pure-run mode skips cache-read but still writes.

## Key Insights
1. **Brace-metavar hover bug had silent impact.** The span indexer routed `${...}` only into cross-ref parsing; on failure the whole token was swallowed. No test caught it because op-level `hover_capture` was tested in isolation, not through DocSession dispatch. Lesson: tests at the unit boundary and tests at the dispatch boundary are not the same coverage.
2. **No-isolation rule is now comprehensive.** stash, worktree, detached HEAD all equally banned. Diagnose in place, read diffs, reason from code.
3. **"Just do the thing" means ship and test.** Spend less time reading, more time building and running. User explicitly said "yolo" on the golden walk.
4. **Invariants > stress.** If the guard works per cycle, induction handles scale. N=3 reparses with task-count probe is enough; 1000 is drama.
5. **Daemon/LSP/watcher collapse is real.** Architecture memory saved; future S3/S7 slices inherit this constraint.
6. **CLI autopopulates cfg from discovery.** The empty-cfg bug during golden walk showed that discover_repos alone is not enough — `cfg.repos` / `cfg.revs` seed the pipeline's walker; leave them empty and everything returns zero rows.
