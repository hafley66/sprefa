# Session: sprf-block-cons-container-op-application-design

## Goal
Pure language-design brainstorm (no code): nail down sprefa's block/brace
syntax+semantics so braces never get "fucked" later, and unify it with
container literals, cons, ADTs, labels, and op-argument passing. Anchor
thesis: everything is a pipe (Cursor* -> Cursor*); if it looks like a
thing it's just a pipe doing something to a cursor.

## Current State
Design converged on a small, frozen core. NO implementation done. main
unchanged this session. Parallel chats own (a) path/dot-access syntax and
(b) dot-access; this chat scoped to block/container/op-application only.

## Problem/Context
Braces are historically overloaded (JS labeled-stmt vs object, TS
type-vs-value `{}`, Rust/Go struct-literal-in-condition tax). Need one
production so adding types/blocks/match later can't fork the grammar. User
also wants seq, op args, rule kwargs, match, ADTs all to be the SAME
structure, with ops owning composition.

## Solution/Approach
Collapsed core (5 things; everything else is an op, library not grammar):
- `cons(k, v)` — the cell. k = name | index. `K: V` = cons(:K, V); bare
  positional = cons(index, V). `label(:n,P)` IS `cons(:n,P)`.
- container literal = cons-list + one flag: `()` ordered, `{}` merge.
- `>` — primitive forward stream-wire (only native composition).
- op-application: `name(list)` hands cons-list+flag to op; op returns a
  pipe and owns its effect subtree. Args are LAZY/by-structure.
- seq/if/match/else/race/fanout/block/label/rule/types = ops over
  cons-lists.

Container roles (frozen): `{}` = merge/fanout, also the sprf file (root,
unlabeled, fanout — incoming cursor reaches every top-level label).
`()` = ordered cons-list = product/struct/seq/match(route-table,
first-match-wins, stop). Single-match=`()`, multi-match=`{}` — difference
is which bracket typed, decided on ONE token; braces carry no δ.

ADTs derived (not primitive): `()` = product/struct; `{}` = sum via
tag-selection (cursor carries a tag; sending into labeled container
selects arm whose label name == tag). Match = `()` first-match.
empty `()` = unit `1`; empty `{}` = never `0` (forced by algebra).

Labels = pure names = DOM id/class; dispatch/back-edge = selector/
ancestor query (`Element.closest()` model) — spelling owned by path chat.
NO RHS `?`-guard symbol (dropped). Discriminator is structural
(tag==label name) + how cursor is sent, never a mark in braces.

`else`/zero-fallback = `( A, expect_zero > B )` — barrier is FREE because
`()` is ordered (cell N completes before N+1); `expect_zero` is an op,
not a `?`. Sequential is already `>`; never add `;;`/`>>` (re-introduces
statement/expr split = invariant 4).

Op trait = runtime twin of compile-daemon's proposed `RustOpEmitter`:
one trait, `compose(args,container,ctx)->Pipe` + `emit_rust(...)->Rust`.
Per-op ownership of composition AND lowering.

## Key Insights
- One brace production forever = braces unfuckable. The 5-language tax
  table (JS/TS/Rust/Go/Python) all from two productions starting with
  `{` at one position.
- `cons` is bottom. label/kwarg/match-arm/object/block all = cons-lists.
  "damn it there's cons" — user's own realization.
- Container picks composition, decided on ONE opening token (invariant 3),
  never lookahead-inside or context (invariant 2). `;` vs `,` must NOT
  carry δ (invariant 5) — separator pairs with bracket conventionally.
- No statement/expr split (invariant 4) — that's why `;;`/`>>` banned.
- ADTs fall out free; empty-container meaning FORCED (1/0), closes a
  long-open decision.
- Barrier/zero-knowability law: absence only observable at completion;
  becomes structurally free once `()` = ordered sequence.
- No built-in control flow — if/match/seq are ops; adding control = new
  op, never grammar. Args lazy ⇒ every op is a special form ⇒ no
  macro/function split.
- `block(label…)` was never special — just the first op that interprets
  a cons-list; now every op does.
- This op-trait direction matches the compile-daemon PR's per-op
  `RustOpEmitter` ownership — one trait, compose + emit_rust.
