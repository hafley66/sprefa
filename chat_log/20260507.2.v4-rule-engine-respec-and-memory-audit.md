## Key Insights
- "substrate" banned; the layer is "effects runtime" (in `effect_runtime` crate)
- rule = sprf-language idea; fact = effects-runtime store row; one rule emits N facts
- bracket `[X]` = implicit first source arg; default = current cursor (no `&` sigil; & was redundant)
- caps are ops: ${X} → term(:X), ${X?} → term?(:X); everything in DSL bodies is sub-pipes
- ${...} is DSL-tick-only; in host language, captures are bare caps with `?` suffix for Bind
- one FactStore per session; trait + impls; extension hook; never multi-instance, never copied
- effects runtime stays coord-agnostic; (repo, rev, fs, lo, hi) is sprf-side, not effect_runtime-side
- no enum-flag args; split into ops or namespace via dot-access (`write_cursor` over `write(:cursor)`)
- matcher purification: only `read` opens files (or git blobs); matchers operate on cursor.value
- universal subpipe: one shared renderer; SubPipe-bearing bodies recompile per cursor
- shaman trio (Prolog/rxjs/Ruby ergonomics) converged on mid-pipe-all-bound = predicate, ! = exactly-one — USER REJECTED in favor of "no sigils, mode dispatched by ? on args, the call IS the query"
- engine model: body is cache-fill thunk keyed by input-args; query SELECT shape determined by ? positions; watcher registry handles live update; retract chain on source-change. This IS differential dataflow with Datalog surface.
- "engine = language semantics" was the unblocker — language-design-from-above kept failing because the right shape only emerges from execution semantics
