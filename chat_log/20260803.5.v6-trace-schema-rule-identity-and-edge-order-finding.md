## Key Insights
- **The DL_PERF_LOG contract already existed in two languages and had drifted.**
  6_profile.pl:7-9 states it (lower snake case, elapsed in *_ms) and
  ARCH.pl:819 says why ("matching the runtime shape so numbers survive the rust
  flip"), while runtime/types.ts wrote `ms` and `witnessDigest`. A rust emitter
  told to follow the same bytes would have followed whichever file it opened
  first. Prose conventions drift; rows do not.
- **"The same bytes" across sinks is not achievable, and claiming it was the
  mistake.** pino prepends a numeric `level`; a `tracing` json layer adds
  `target` and `fields`. Suppressing pino's level with
  `formatters.level: () => ({})` emits `{,"tick":...`, MALFORMED JSON, because
  the formatter's object is spliced in as a prefix chunk. Tried, reverted,
  recorded at the call site. The receipt grades the line's PROJECTION onto the
  declared fields, which is what a second emitter can actually satisfy.
- **A level head's clauses are NOT separately nameable.** They fold into one
  UNION'd insert by construction (level_statement_group/3 hands the emitter a
  LIST under one head), so a level head is always #1 and only EDGE arms get
  their own ordinals. This plan claimed otherwise; the receipt went red against
  the coalesce fixture and that is how it was found.
- **The SWI profiler's self-time for built-ins is off by ~70x** (last session's
  finding, re-confirmed): it charged is/2 0.54s for 26,303 calls that run
  standalone in 0.0077s. Wall-clock stubbing is the instrument. Two whole-store
  scans that looked like the session's polynomial priced at 0.07s combined, so
  the keyed assoc index designed for them was NOT written.
- **The occurrence loop's cost was the VIEW, not the frames.** Visible and
  PreState (each a sort of the whole store) were rebuilt per occurrence, 4,355
  times, though only 851 occurrences write anything. A memo guarded by ==/2 on
  the store TERM (O(1) on identical pointers, no drift risk, no invalidation
  protocol) took the oracle 5.63s -> 3.76s. Reach for that shape before an index.
- **Two experiments that cost nothing and are recorded so nobody retries them:**
  an open-tail accumulator to make the occurrence loop last-call (no change),
  and a trigger-ref prefilter that cut copy_term/2 from 56,615 to 1,234 and
  bought nothing, because copy_term shares ground subterms.
- one-subscribe.sh excludes diagnostics_channel handles BY NAME and never by
  wildcard, because a wildcard once let an rxjs subscribe on any variable ending
  in "Channel" through (audit 2026-07-28, probe 2). Adding a channel means
  adding its name there, on purpose.
- Regenerating gen/scale_generated.ts retired a staleness finding
  7_scale-floor.sh:53 had been carrying in a comment since 2026-07-30. A
  required interface field forced what a comment had been deferring.
