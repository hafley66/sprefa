## 03 / Queue Row Refit

```text
┌─ HOT / COLD VALUE SLOT ──────────────────────────────────────────────────────┐
│                                                                              │
│  QueueRow                                                                    │
│  ├─ id                                                                       │
│  ├─ parent_id                                                                │
│  ├─ batch_idx                                                                │
│  ├─ path_blob                                                                │
│  ├─ pipe_hash                                                                │
│  ├─ instance_id                                                              │
│  ├─ depth                                                                    │
│  ├─ wake                                                                     │
│  └─ value                                                                    │
│     ├─ Hot(Arc<Cursor>)                                                      │
│     └─ Cold(SpillId)                                                         │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

```text
enqueue(row)
   │
   ├─ estimate bytes
   │
   ├─ if hot_budget has room
   │      row.value = Hot(cursor)
   │      push runnable
   │
   └─ else
          encode cursor
          insert runtime_cursor_spill
          row.value = Cold(spill_id)
          push runnable handle
```

```text
pull(batch)
   │
   ├─ collect runnable handles
   ├─ decode until dispatch_batch_bytes is full
   ├─ dispatch component
   └─ drop decoded cursors
```

## 06 / Streaming Delivery

Current output contract:

```rust
render_batch(ctx, &[&Cursor]) -> Vec<Node<Cursor>>
```

Problem shape:

```text
Node::Many(Vec<Node<Cursor>>)
```

Large fanout makes a large return value before downstream can run.

Target contract:

```rust
trait EmitSink<N> {
    fn emit(&mut self, value: Arc<N>);
    fn yield_on(&mut self, value: Arc<N>, wake: Wake);
}
```

```text
component ──emit──► sink
                    │
                    ├─ run next component now
                    ├─ enqueue hot
                    ├─ spill cold
                    └─ write terminal fact
```


## 08 / Depth-First Tail

```text
CURRENT
───────

sql chunk
   └─ emits N outputs into queue
         └─ FactWrite later drains N outputs


DEPTH-FIRST TAIL
────────────────

sql chunk
   └─ output row 0 ─► FactWrite buffer
   └─ output row 1 ─► FactWrite buffer
   └─ output row 2 ─► FactWrite buffer
   └─ ...
          └─ insert_batch every 8192 rows
          └─ clear buffer
```

Deterministic child paths:

```text
parent path [12]

child outputs:
  [12, 0]
  [12, 1]
  [12, 2]
```

Execution order can become depth-first without changing path identity.

## 09 / First Tactical Cut

```text
┌─ FUSED TERMINAL MATERIALIZATION ─────────────────────────────────────────────┐
│                                                                              │
│  Recognize:                                                                  │
│                                                                              │
│    sql`...` > fact(:hit_pairs)                                               │
│                                                                              │
│  Lower to:                                                                   │
│                                                                              │
│    SqlWriteComponent {                                                       │
│      sql,                                                                    │
│      table: hit_pairs,                                                       │
│      assignments                                                             │
│    }                                                                         │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

Execution:

```text
for input chunk:
  materialize input temp table
  run SQL
  for output row:
    build Cursor
    push into fact buffer
    if buffer == 8192:
      store.insert_batch(table, buffer)
      clear
  flush final buffer
```

Deletes:

```text
706k SQL output queue rows
huge Node::Many trees
downstream FactWrite queue pull
some terminal row churn
```
