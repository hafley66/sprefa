3. SCIP importer tier:
- Moved `protobuf` and `scip` from dev-dependencies into dependencies in `v5/Cargo.toml`.
- Added `v5/src/scip_import.rs` with `ScipRows`, `index_path`, `load`, and `rows`.
- Added built-in relations in `engine.rs`: `scip_def(symbol,file)`, `scip_ref(file,symbol,def_file)`, and `scip_edge(src,dst)`.
- Engine imports an existing SCIP index from `SPREFA_SCIP_INDEX` or `<root>/index.scip`; missing index yields empty relations and no hard rust-analyzer runtime dependency.
- `tick_paths` refreshes SCIP facts when `index.scip` is the changed path.

- Marked SCIP importer done in `CLAUDE.md` and `plans/v5-architecture.md`.

Important implementation nuance: for missing SCIP index, `refresh_scip_rels` returns `Ok(true)` after clearing relations so a vanished index can propagate and rebuild dependent derived relations.
