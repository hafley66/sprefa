## Problem/Context
`reaches?(N?, N)` in an imperative rule-read failed at SQL time with
`no such column: input.N`: the second `N` (Term-Read) lowered to
`__rule.DST = input.N`, but `N` is born in this very read (projected from
`__rule` by the first `N?`), so there is no prior cursor column to correlate
against. The cycle example had to use a `> where`${SRC} = ${DST}`` step as a
workaround.

## Solution/Approach
Single site: `rule_table_call_pipe` in `v4/src/sql.rs`. After the
`modes: Vec<ArgMode>` classification, forward-scan in arg order:
- `ArgMode::Project { col, term }` records `term -> col` in a local map.
- `ArgMode::BoundTerm { col, term }`: if `term` is in the map, emit
  `__rule.col = __rule.{bound_col}` (intra-row) and `continue`; else fall
  through to the legacy `__rule.col = input.term`.
Map filled ONLY by `Project` (Term-Bind subset); literals (`BoundLiteral`),
`&.value`, pipe values never touch it. Order-honoring: ref-before-`?` keeps
the legacy outer-cursor correlation. Keyed on resolved TERM name (post-kwarg,
so `r?(X: A?, Y: A)` keys on `A`). Strictly additive (rewritten case was a
hard SQL error, so no existing program changes behavior).

2 hunks: insert `projected_term_col` map + the intra-row branch before the
`input.` push; change the `ArgMode::Project => {}` no-op arm to insert into
the map.

## Key Insights
- The classification surface is `ArgMode` in `rule_table_call_pipe` (sql.rs),
  NOT op_def.rs (that's the OperatorDef/DSL-hole surface) and NOT the fuser's
  `classify_rule_arg` (that's the braced rule-body path; the same-capture JOIN
  there already handles its own case at fuser.rs:507-528).
- Imperative rule-read = `FROM input JOIN <rule>_facts AS __rule ON 1=1`;
  Term-Bind => `Project` (SELECT __rule.col AS term), Term-Read => `BoundTerm`
  (WHERE __rule.col = input.term). Intra-row is the same-read self-equality
  between the two.
- Background `cargo run`/`cargo test` sharing one CARGO_TARGET_DIR will kill
  each other on the build lock; the loser dies silently with 0 output. Run
  gate as a single invocation, nothing else touching target.
- `| tail -N` on a backgrounded command truncates the captured file to N
  lines — re-run to a full file when a tally is needed.
