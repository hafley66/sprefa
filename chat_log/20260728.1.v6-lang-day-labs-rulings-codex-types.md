- THE ONE MOVE: every feature = find the rel + policy words + desugar +
  tick-log grade. Ta, clock, share, cascade, channel, queue all dissolved.
- Match-frontier lab: Ta primitive is unspecifiable (log depends on engine
  delivery choice); pending-rel encoding byte-identical with zero knobs.
- Types: entity vs value = Rust's Rc-vs-arena dichotomy rediscovered; value
  cycle crack IS the Rc cycle leak; support GC complete only on value DAG.
- FK ON DELETE CASCADE is semantically wrong for shared children (kills row
  with live second parent) and has no rx lowering; we never emit it.
- Rust borrow checking = Polonius datalog over MIR facts = our exact shape;
  Q8 checker-as-rules is the same modernization rustc made.
- Enum storage: N variant rels + derived tag view beats rust-style
  single-table nullable (NULLs poison content keys, hash goes conditional).
- Registry insight: conformance side is table-driven, compiler is the last
  hand-coded holdout; surface/5 collapses 5-way duplication.
- Codex models: luna (default workhorse), terra (open decisions), sol (top,
  config default). OpenAI limits effectively free, spam reasonably.
