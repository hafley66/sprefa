## Key Insights
1. **Daemon/LSP/watcher collapse into one process.** Recorded in project_v2_daemon_shape.md. LSP is the daemon. CLI is a thin client that warms from SQLite, runs, serializes back, exits. Pure-run mode skips cache-read but still writes.
2. **Watcher scope is `.git/objects/pack/**` only.** Fetch/refs/ghcacher concerns are upstream. GitBlobReader reading straight from ODB means blob-arrival is the only signal the engine needs.
3. **ast-grep mid-token capture** uses `${VAR}` brace sugar layered on ast-grep (not native to ast-grep). Pattern `fn get_${SUFFIX}()` binds SUFFIX to the identifier tail.
4. **"No stash" rule extends to all isolation mechanisms.** Stash, worktree, detached HEAD — none. Diagnose in place by reading diffs, not by running parallel trees.
5. **Phase 2e pre-existing failures are not blockers.** scan_loop/rule_json regressions predate Phase 2 and bypass init_cursors. Tagged #[ignore] with rationale; a future slice can unbreak them in place.
6. **Invariant-style testing preferred over stress.** Small N proves the guard per cycle. If N=3 reparses reap cleanly, N=1000 follows from cancel discipline. No feature gate needed.
