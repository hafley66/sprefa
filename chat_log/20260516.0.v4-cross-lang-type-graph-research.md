## Problem/Context
- SCIP precise indexers need compilers; we cannot run them. Only adopt SCIP symbol-string descriptor scheme as cross-repo join key (synthesized from CST, no compiler).
- Verdict: nobody but GitHub shipped polyglot tree-sitter + stack/scope-graph resolver. github/stack-graphs archived 2025-09-09, never had Rust/Go/Kotlin/C/C++ rules. metaborg/rust-scopegraphs is closest living engine. Per-language tree-sitter rules are the unavoidable hard work and the moat.
- stack-graphs checked out at ext/stack-graphs: stack-graphs/src 11,779 LOC, tree-sitter-stack-graphs/src 8,858. Most is product (arena, FFI, own SQLite, DSL interpreter), not algorithm. Smallest resolver = ~100-150 line single-stack DFS.
- Coupling: no separate graph engine. effect_runtime v2 FactRuntimeGraph already has the stitch fixpoint (sweep_to_quiescence DFS), incremental (mark_dirty/dirty_owners), retraction (replace_supports -> VisibleDelta), SQLite spill (SqliteFactStore). One graph abstraction, not many.
- replace_supports (runtime_graph.rs:870) = refcount-by-edge: owner declares full keep-alive set, diff old/new, row with 0 refs -> retracted. It IS reference counting. "ref" lexeme is taken by binding graph RefNode.
- User rejected "support"->"keep" rename as unbeautiful. Naming OPEN. NOTE: a global sed is wrong, "support" has two meanings (keep-alive concept vs feature-support like SupportLang/unsupported). 214 hits / 46 files for the word, only some are the concept.

## Solution/Approach
Tiered: T1 grep (v0), T2 tree-sitter symbol+name-equality (aider-repomap-style tags.scm feeder + PageRank ranking signal), T3 scope/stack-graph stitch from CST (the real layer), T4 compiler (out of scope, opt-in only). L0-L4 amendment stack with an `origin` column (auto|user|guess|userast) so recompute only deletes its own auto rows; hand edits survive. Dotted-path projection requires Tarjan SCC first to cut cycles, Johnson only to report circuits. Reuse from ext/stack-graphs: lift cycles.rs+paths.rs, use partial.rs/graph.rs as spec, port assert.rs test format; drop FFI/arena/storage/stitching/tsg-crate.
