## Solution/Approach
- `?`/`!` are NOT primitive sigils: they're shorthand for read/write (query/command,
  coeffect/effect, CQRS). All properties (replay/fire-once, reversible/irreversible,
  switchable/not) derive from reversibility. Proposal (theory only): desugar to
  effect<Mode,Card>, illegal combos (switchMap over write, retry over write) = type errors.
- rxjs core = pattern matching over the Notification ADT (materialize) + carried state
  (scan); the `{ }` arm block IS that match = algebraic-effect handler. Sigils dissolve at
  the bridge; lowerSql never sees them (they become __req/__resp rels).
- Minset re-centered: Notification ADT + keyed upsert (retention-1) + reversibility tag +
  effect-edge-teardown. Two parked primitives remain: temporal negation (Dedalus @next; for
  retry loops) and consuming-read (CHR; for blocking channels/backpressure). rel(N) =
  ReplaySubject/buffer (replay mode) vs blocking channel (consuming+unicast+gate) are two
  orthogonal modes; backpressure = occupancy-gate fixpoint (dl CAN express it, I was wrong
  it "structurally cannot"); chan gap is really the BACKPRESSURE/blocking gap, not buffering.

## Key Insights
- `?`/`!` = read/write, one axis (reversibility); cache/replay/retry/switchable all derived.
- The `{ }` arm block = an rxjs `tap` observer, mimicked verbatim: subscribe -> next* ->
  (complete|error|unsub) -> finalize; terminals mutually exclusive; finalize always;
  peek-before-forward = stratification order. unsub = unmount = switchMap's cancel = a ROW.
- Teardown is NOT a new primitive to ADD; it's an EVENT to RECORD (materialize). That keeps
  the accumulate-only model and makes switchMap expressible.
- switchMap = mount/unmount/render (React), = keyed upsert (rel(1)) + teardown-on-retract;
  near-core, not a frontier. Supersession in HostRunner (1_hosts.ts:462-497) already does
  the data-level latest-wins.
- Two clocks: outer tick (EDB/macrotask/C++ world) vs inner fixpoint rounds
  (microtask-drain, run-to-completion). = Timely Dataflow (epoch, iteration) lexicographic
  timestamps; progress-tracking = quiescence detection. Marbles were "too clean" hiding this.
- Design-as-fixpoint: "can I express X with none of the prior ideas?" = is X's dependency
  closure ⊆ accepted primitives = reachability; minset = sources of the condensation =
  rulegraph.ts on the design graph (self-referential dogfood).
- Datafun = monotonicity-in-types (dual-context ∆;Γ, hidden comonad, NO surface □; Lemma 4
  finite-height constructive fix, not general Knaster-Tarski). Flix = first-class Datalog
  constraint VALUES + true JoinLattice cross-row lub (dl's MaxBy/MinBy is row-SELECTION
  only, not ported to v6). Souffle = compiled parallel C++ batch, magic-sets (static
  adornment; dl's __req/__resp RHYMES but is effect-demand-scoped, NOT true magic sets).
  sprefa ALONE has: live retraction (delta plane/DRed) + effect edge. sprefa ALONE lacks:
  monotonicity type system, lattice facts, compiled perf.
- setState-in-effect loop = non-quiescing fixpoint; stratification = the compile-time
  termination proof React replaces with a runtime counter. Error is "Maximum update depth
  exceeded" (~50), not JS stack overflow.
