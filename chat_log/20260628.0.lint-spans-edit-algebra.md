## Key Insights
- **diag rel is column-name-driven** (Engine::diags reads col/end_col/end_line by
  name); a .dl program adds columns and to_diag renders sub-line spans — zero
  engine change beyond producing the columns.
- **arith head-binding (l+1) only works in DERIVED rules**, not source (scan/match).
- **gen(:mode) IS the edit algebra** — 4 byte-cursor modes + overlap-safe multi-
  edit, ported from v4 WriteCursorComponent. delete = :replace "". Writes disk on
  CLI tick (LSP drops gen rules). No verify-rollback gate yet (= #14).
- **dl `sg` op embeds ast-grep-core** (SupportLang, 11 langs); it's not "like"
  ast-grep, it IS ast-grep + a relational layer. Gap to full parity = metavar-
  templated rewrite (sg $A not exposed as dl var).
- **The differentiator**: every match is a relation row, joinable against call/
  type graph, git revs, cross-file/lang. Suppression anti-join was trivial b/c
  of this.
- LSP discovery merges `<root>/.dl/*.dl`; root is repo-PARENT; globs are `v5/src/**`.
