## Solution/Approach — the converged design (rulings PINNED in DECISIONS.md)
1. **Retention forms** (pinned): `rel(0)` event/Subject/scratch (rows live only in arrival tick, same-tick joins only), `rel(1)` state/BehaviorSubject (newest + readback), `rel` history/table (keep all). rel(N>1) NOT ruled in (window-join law needed first). No chan keyword. state/event = retention 0 vs 1, not a type distinction.
2. **Tick column shape (b)** (pinned): rel tables stay flat; one append-only `delta(rel, row_digest, tick, weight)` stamped per commit batch at the single write site; store-owned monotone tick counter in store_meta; retention = purge policy on log rows; reconcile changed_at becomes a real column. Shape (a) datomic-all-append-only NOT taken. Two axes stay separate: tick = engine commit counter (ANSI SYSTEM_TIME), rev = git coordinate via spine walk span->file->rev->repo (application-time).
3. **Time aggs**: `latest(x)` = argmax-by-tick (FIRST_VALUE ORDER BY tick DESC), `prev(x)` = LAG = the @next replacement, `earliest`, running folds = scan. All ordinary aggs whose ORDER BY is the implicit tick; legal in head AND body/value position; stratified-only.
4. **Nesting**: Lloyd-Topor lift — compiler mints one aux rel per nested group, columns = free variables. Covers disjunction, grouped negation, agg-with-body, latest(). Join-back becomes compiler's job. Heads stay flat forever.
5. **One neck** `<-` (Chris keeps his OG arrow): Bloom's 4 operators collapse — `<=` = the neck, `<+` = prev() in body (flip: head-at-t+1 ≡ body-reads-t-1), Bloom `<-` delete = Z-set retract engine-plane (no user syntax; imperative delete = ingest path), `<~` = host rel. `->` survives ONLY in host decls (sh fetch(...) -> (cols)).
6. **clock** = builtin host rel, rel(1)-shaped (current bucket, readback, no history — latest(clock) is a category error); `every(N)` = its rel(0) event twin (fires only AT boundary); demand law: unsubscribed clocks don't tick.
7. **rel(0) litmus**: replay-to-late-subscriber wrong or worthless => rel(0). Needed for: every(), inbound transport rows (http/LSP/ws — E6), commands, high-freq ephemera. Erases the queue-table+processed-flag kludge. gh-cache needs none.
8. **The whole shopping list**: (1) aggs in value position, (2) Lloyd-Topor nesting, (3) tick column + retention. Everything else dissolved.
9. JSON byte-for-byte (JSON5) as term literals: reserve `{`/`[` in term position, island lexer mode; no SWI quasi-quote bars needed. named-arg vs object disambiguated by brace.
10. ghcacher rewrite in the new surface (in chat, not yet a file): zero sigils, etag_state = rel(1) + latest(bucket) body read, change_log derives from keep-all resp history (accumulation IS retention — @next self-union dead), effect async because body probes host rel, digest = probe's bound args.
