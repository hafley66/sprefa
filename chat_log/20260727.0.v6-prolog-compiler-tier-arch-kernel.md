## Key Insights
- SWI incremental tabling invalidates at call-variant granularity: retract ~= full recompute (measured 1156ms vs sqlite 50ms @160k).
- Hand-written semi-naive in swipl beats swipl's own tabling 3x; our algorithm > host's general mechanism.
- Rust prolog (scryer) is slower than C (SWI); rust speed wins live in datalog engines (dd/dbsp/ascent), not prologs.
- A register IS latest-wins; max(bucket) chains exist only to simulate registers in set semantics.
- Absence is not primitive: absent(s,i) <- tick(i), not fired(s,i); needs a reference clock; events base, frames typed.
- The island's clock is program data: throttle/delay/laziness/demand all = "which stream is your clock"; delay = due rows (survives crashes).
- Kernel-4 + sugar/2 + term_expansion = the anti-non-compositional-feature discipline; ARCH.pl machine-checks it.
- swipl module gotchas: scryer directive whitelist rejects :- catch; '$cpu_now' resolves compile-time only; dict dot-access doesn't expand in fact args (use get_dict).
