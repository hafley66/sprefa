# Session: Partial Parsing for LSP Integration

## Goal
Enable the sprefa LSP to provide completions and hover even when the .sprf file has syntax errors, by implementing partial parsing in the core sprf crate.

## Current State
- LSP completions work for file patterns (fs, file, folder)
- LSP hover works for file patterns showing matching files
- Capture variable hover returns empty (needs extraction)
- Parser currently fails completely on first error (all-or-nothing)

## Problem/Context
The current parser uses `anyhow::Result<Program>` which fails fast. For LSP use cases, we need:
1. Parse as much as possible (partial AST)
2. Return errors alongside the AST
3. Allow completions/hover on valid portions
4. Single parser for LSP, CLI, and checker tools

## Solution/Approach
Implement error-recovering partial parser:

```rust
pub struct PartialProgram {
    pub stmts: Vec<Statement>,
    pub errors: Vec<ParseError>,
    pub is_valid: bool,
}

pub fn parse_program_partial(input: &str) -> PartialProgram
```

Error recovery strategy:
- Capture error with position
- Find recovery point (next `rule`, `check`, or `;`)
- Continue parsing from recovery point
- Return partial AST + all errors
