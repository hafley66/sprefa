## Key Insights
- Daemon accept loop must be off-main for macOS tray (CFRunLoop requires main thread). Moving it to dl-accept thread was the cleanest restructure.
- Mutex<Program> enabled both hot-reload AND dynamic discovery. A Program clone from the lock guard is how tick_full/tick_paths read it; reload swaps the value behind the Mutex.
- FSEvents delivers historical events; a 1s startup grace drain is essential for daemon startup resilience.
- tree-sitter grammar for .dl is feasible at ~400 lines. Hard parts: keyword clashes (def/gen/use) and missing-token recovery interfering with precedence. def_template deferred.
- The engine requires scan and extraction (match/sg) in the same rule body for `_source` tracking. Joining through intermediate rels fails with "missing scan" error.
- Dynamic discovery is incremental: reload_discovery() compares file sets, returns early if unchanged. No-op on every tick unless a new/removed file is detected.
