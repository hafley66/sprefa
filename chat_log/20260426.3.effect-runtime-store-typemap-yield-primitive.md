## Solution/Approach

### Layer choice — yields live in effect_runtime

Three candidate layers reviewed: op (`Op::pipe` PipeOutcome enum),
effect runtime (Yield as EffectKind), pipeline runner (side-channel).

Lock: **effect runtime**. Op stays stateless (yields cursors via stream,
awaits effect description). All suspension state in `SubjectRegistry`
reachable via the store TypeMap. Same redux-saga split that already
distinguishes `Op::pipe` from `Batcher`.

### TypeMap on RtCtx (sprefa-4d5, closed)

Parallel store registry alongside the existing effect-handler Registry.
Pattern: `axum::Extensions` / `bevy::World` resources.

```rust
pub trait Store: Any + Send + Sync + 'static {}
RtCtxBuilder::with_store::<S>(Arc<S>) -> Self
RtCtx::store::<S>() -> Option<Arc<S>>
RtCtx::bind_store::<S>(Arc<S>)   // atomic post-build replace
```

Implementation: `ArcSwap<HashMap<TypeId, Arc<dyn Any+Send+Sync>>>`. Stores
own their own internal sync (Mutex/DashMap/RwLock/watch). Runtime stays
sync-agnostic. Existing `PrintSink/WriteRangeSink/LspDiagSink` not
migrated — they live inside their batchers, work fine, churn unwarranted.
SubjectRegistry is the first real consumer.

### Yield primitive (sprefa-dmt, closed)

New file `effect_runtime/src/subjects.rs`. Vocabulary lock:

| Concept | Word | Lineage |
|---|---|---|
| Op suspend | **Yield** | JS generator |
| Outside resume | **Next** | RxJS `Subject.next(v)` |
| Outside cancel | **Unsubscribe** | RxJS unsubscribe |
| Keyed entry | **Subject** | RxJS Subject |
| Registry | **SubjectRegistry** | |
| ID | **SubjectKey** | |
| Cancel error | **Unsubscribed** | |

Effect kind:
```rust
pub struct Yield { pub key: SubjectKey, pub lineage: Option<Arc<dyn Any>> }
impl EffectKind for Yield { type Response = Result<NextValue, Unsubscribed>; }
```

`SubjectRegistry`: `fresh_key`, `next`, `unsubscribe`,
`unsubscribe_where(predicate)`, `unsubscribe_all`, `pending_count`.
Lineage opaque to runtime — consumers downcast in their own predicate.

`YieldBatcher`: oneshot per pending Yield, `select!` on
`(oneshot recv, cancel_token.cancelled())`. `YieldGuard` Drop GCs the
registry entry on future-drop, so spawned-then-aborted op tasks do not
leak entries. Five distinct cancellation paths all GC:
1. External `next(key, v)` → Ok(v)
2. External `unsubscribe(key)` → Err
3. `unsubscribe_where(predicate)` → Err
4. Runtime cancel_token / `cancel_all` → Err
5. Future drop (op task abort) → Err via Drop guard

### Op-author flow (locked shape)

```rust
async_stream::stream! {
    while let Some(input) = upstream.next().await {
        yield Arc::from([scan_so_far(input)]);   // checkpoint emit
        match cx.put(Yield { key, lineage }).await {
            Ok(value) => continue,               // outer Next'd us
            Err(Unsubscribed) => break,          // outer cut the line
        }
    }
}
```

Stream channel stays the only emission path. Yield is sequence-point
only — checkpoint `Some(Cursor)` flows via the normal stream pull
before the await, not as a payload field on Yield. Single channel,
easier invariants.

### Spike-Q locks (5/5 — sprefa-cg2 closed as superseded)

1. Primitive shape: effect-kind `Yield`, no `PipeOutcome` enum
2. GC: `SubjectRegistry` owns; drop on Next/Unsubscribe/cancel/lineage-retract/future-drop
3. Fork × Yield: independent `BoxStream`s per arm; one yielding does not block siblings
4. Tag as op name: lowerer-privileged, no grammar change
5. Lineage: capture-level; consumer-defined `CursorLineage`, opaque `Any` to runtime

### Synthetic 16ms baseline on ast-grep tests (commit 0798166)

`PausedAstParse` Batcher sleeps `SYNTHETIC_PAUSE = 16ms` then delegates
to `ast_parse`, with `select!` honoring runtime cancel token. Replaces
the synchronous `Passthrough` in the ast-grep test ctx.

Three tests pin load-bearing properties:

| Test | Bound | Catches |
|---|---|---|
| `synthetic_pause_is_paid_per_dispatch` | elapsed >= 15ms | accidental `Passthrough` regression bypassing the overhead |
| `synthetic_pause_is_cancellable_mid_flight` | elapsed < 8ms | `select!` lost cancel arm; cancel-token broken |
| `synthetic_pauses_parallelize_across_dispatches` | 8 dispatches < 64ms | batcher serialization regression; runtime starvation |

Bounds slack-tolerant. Single constant — retune by editing one line.

## Key Insights

1. **Yields collapse to effect-kind, not stream-payload.** Effect-kind
   keeps emission single-channel and aligns with redux-saga. Op author
   writes natural `yield cursor; cx.put(Yield).await` sequences.
2. **TypeMap is parallel to effect Registry, not unified.** Two
   registries, two roles. Effect Registry dispatches typed effect calls;
   store TypeMap holds mutable shared state that batchers + outside code
   reach into. Different lifecycle, different lookup pattern.
3. **Existing batcher-owned sinks stay batcher-owned.** TypeMap is for
   stores that batchers + ops + external code all need to reach. PrintSink
   et al. are owned by exactly one batcher each — migration would be
   noise.
4. **`Drop` guard inside the batcher future closes the future-drop hole.**
   Without it, op task aborts leak SubjectRegistry entries forever.
   Already-resolved entries make `unsubscribe` a no-op, so the guard is
   trivially correct in all paths.
5. **Synthetic pause is the test signal for load-bearing runtime
   properties.** A constant cost lets the tests assert lower (paid) and
   upper (cancel/parallelism work) bounds in one shot. Not perf
   measurement; correctness measurement using time as the observable.
6. **LSP-route writes bypass Yield, CLI-route writes park.** Same
   `WriteRangeEffect`, two sinks, builder-time policy. Filed sprefa-4x7.
7. **Live-coding overlay revives hand coding (sprefa-eji).** LSP-buffer
   reader as fourth source layer below blob/WT/buffer; sits above :wt
   mode. Engine-rips-fast lets sprf rules see live-typed code.
