## Solution/Approach
- closure() grammar marks a transitive-closure rule; reaches becomes a SQL VIEW
  over per-edge condensation tables scc_node_<edge>(name,comp,cyclic) +
  scc_edge_<edge>(comp_src,comp_dst). E6 finding: the recursive-CTE view CANNOT
  seed a point query (builds whole component closure then filters) -> 1.98s on
  kernel; the Rust seeded walk (reaches_from / reached_by) is 30us. So point
  queries route to Rust, view kept for full-scan/anti-join composition.
- resolved call graph: ast() gained optional end-line term; calls resolved by
  range join s<=l<=e (call-site inside caller body span). Megablob (1 SCC of 79)
  -> real structure (v4: 841 comps; kernel: 13378 comps max SCC 16).
- stratifier: predicate dependency graph, SCC it (reuse scc::tarjan), reject
  negative-edge-in-SCC, assign strata (neg edge => strictly higher), run one
  positive fixpoint per stratum. Fixes latent unsoundness (unused was only right
  because calls declared first). Same SCC pass now on THREE graphs: data call
  graph (reach), rule graph (strata), and none for indexing (a cover problem).
- auto-index: index every column a var reaches across >=2 body atoms (join key);
  Souffle-style (precise = min-chain-cover/Dilworth). kernel 30s->9.7s.

## Key Insights
- The SAME Tarjan/SCC pass runs on different graphs; knowing which graph is most of the understanding (data call graph=reach; rule dependency graph=stratification; indexing=NOT a cycle problem, a cover).
- Souffle's speed is tech stack (compiled C++, auto-indexed B-tree/Brie, integer interning, OpenMP), NOT a better closure algorithm -- it still builds V^2. Orthogonal to condensation. Evaluation speed vs representation are different lanes.
- Interning is a tier decision: transient in-memory (yes, we do String->u32 in SCC pass) vs persistent durable (no -- breaks retraction/cross-repo; the v4 trap).
- A recursive-CTE VIEW cannot be seeded; point queries must be a Rust walk over the condensation. Confirmed at kernel scale (1.98s vs 30us).
- Stratified negation makes a globally non-monotone program a stack of locally-monotone fixpoints; reject negation inside a recursive cycle.
