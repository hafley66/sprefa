- clock's design premise was "ticks are cheap"; when a tick costs 4MB WAL the rate-cap primitive becomes the cost. The fix stack: tick only on bucket flips (daemon), write only on change (engine mirror digest), keep time out of row identity (digest salt).

- An effect-free root owes exactly one settle-confirmation tick; any scheduler gate that can skip a root must preserve the obligation that flips settled.
