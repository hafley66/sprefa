## Problem/Context
The intra-proc lift had blanket arg->call edges (no position), Rust struct
literals / Expr::Field and Kotlin navigation fell into the `expr` catch-all
with NO base edge (flow holes), TS had no JSX handling, and TS destructured
params bound NOTHING (ts_binding_name None for patterns => React component
bodies had no param nodes). flow-interproc/taint's forward hop was
positional-blind (documented over-approximation).

Arc 1 (5ef8486): DataflowFacts gains args: Vec<(call, pos i64, arg)> +
fields: Vec<(id, field, value)>; new df_node kinds `new` (instantiation,
var = type name) + `member` (field read, var = name). Rust: Expr::Call w/
capitalized-last-segment ctor heuristic -> new, MethodCall receiver -1,

rewritten (navigation callee = receiver -1, named args -> df_field + source

navigation_expression member arm (skipped when parent==call_expression);
TS: CallExpression receiver -1 + df_arg, NewExpression, ObjectExpression
(props -> df_field, spread ".."), StaticMemberExpression var = property.
DATAFLOW_RELS 6->8 (df_arg(call,pos,arg), df_field(id,field,value) decls w/
group/doc); refresh_dataflow_rels dedups + writes both; compute_nests counts
`new` too. flow-interproc.dl + taint.dl hop: df_arg.pos = df_param.pos.

## Key Insights
- A closure rel CANNOT be read unpinned in a rule body (engine bails loudly);
  seed a plain recursive rule from the relevant frontier instead (from_new in
  flow-ctor.dl — the magic-set shape, cheaper anyway).
- call_name(sym, name) is the INDEXABLE "callee named X" handle — use it, not
  a replace() suffix test.
- e2e stdout parsing: an empty FIRST column (anonymous object-literal ty) is
  eaten by trim_start(); strip only the 2-space indent.
- df_arg receiver = -1 mirrors df_param skipping self, so pos aligns across
  df_arg/df_param/type_sig for all 3 langs.
- Kotlin named args keep their SOURCE index in df_arg (reorder misaligns);
  the df_field name row is the accurate one.
- oxc: JSXExpression::as_expression() via inherit_variants; lowercase host
  element = JSXElementName::Identifier vs component = IdentifierReference.
- Microservice value flow = pure DL: bench/flow/flow_scip.dl operationId seam
  + multi-repo scan("*") + scip_want merged load; runtime-only topology needs
  a user-asserted convention rel (the rev_cmp_want pattern).
