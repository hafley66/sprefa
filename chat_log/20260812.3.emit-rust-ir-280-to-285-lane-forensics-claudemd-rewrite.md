## Key Insights

- **`emit_rust.pl` is a serializer, not a code generator.** 315 lines against
  `emit_ts.pl`'s 2814. It writes one JSON document wrapped in a Rust string
  literal. `sprefa-engine-rs` (3601 lines, identical for every program) reads the
  `.rs` **as text**, rebuilds `GenProgram` at `v6/sprefa-engine-rs/src/program.rs:45`, and `run_tick` at
  `:81` walks it issuing SQL. **The interpreter tier already shipped.**
- **`run_tick` ran 6 of the 15 phases `emit_ts.pl:2518-2571` emits.** That was
  the entire cause of the 171 diffs. Nothing was wrong with the plan.
- **The "171 are all missing output" claim was FALSE and I propagated it.** It
  came from `diff -u | awk '/^[+-]/ {print; exit}'`, which stops at the first `-`
  and never reads the `+`. Real split: 108 mixed, 49 wrong-only, 14 missing-only.
- **"unsupported" is the compiler deliberately refusing**, `sweep.pl:168`
  `classify_error(unsupported_construct(What), unsupported, What)`. Anything else
  is `crash`. Of the 104, **75 assert `throws(W)`** in their own expectations, so
  the stop IS the test. **The real coverage gap is 27**, each with a throw site.
  `edge_body_needs_json_destructure` at `analyze.pl:1065` is 9 of the 27, and
  `ARCH.pl:828` already records its own stated reason as stale.
- **For all 104, manifest reason and graded.tsv reason agree stem for stem, 0
  mismatches.** emit_rust stops exactly where emit_ts stops. No Rust-side gap
  remains.
- **exec_shootout existed the whole time and I priced the reload decision without
  reading it.** `mono` (compiler-emitted Rust, from
  `v6/prolog/labs/emit_rust_shootout/emit_rust.pl`) wins 8 of 9 cells. `interp`
  wins 0 and carries 5-11x the RSS. That is the Souffle shape and it already
  works.
- **The "cold build seconds 0.1" column was fake.** `v6/labs/exec_shootout/harness/src/main.rs:369-391`
  ran `cargo build --release` on an already-built crate. Real numbers now:
  cold 0.77-0.95s, warm rebuild 0.27-0.46s. **Generated Rust compiles from clean
  in under a second.**
- **The 64-table join limit counts REFERENCES, not distinct tables**, so it
  argues for neither monomorphization nor a tag column. `AS MATERIALIZED` escapes
  it. Widest join in the whole corpus is **5** across 2,237 FROM-lists.
- **Rust shipped Go's compromise as `-Zpolymorphize` and deleted it** (MCP #810,
  PR #133883), on phase ordering, not speed. Souffle flattens each `.init` into
  its own namespace, i.e. also monomorphization.
- **Untyped shared column, measured**: `v = 7` matches 2 rows, `v = '7'` matches
  1, `sum(v)` silently coerces text. That is the "no coercions" decision
  colliding with type erasure.
- **`type_name/2` is not injective.** `http_response` and `httpResponse` both
  render `HttpResponse`, and the second silently overwrote the first. User
  decided: **module prefix**, applied only to a computed collision set.
- **Two modules declaring the same rel collapsed to one catalog row** and lost a
  column set, rc=0. `lower.pl:1431-1436` keyed on name alone. `grep -rln 'use "'`
  returned **0 files**, so no fixture ever compiled two modules.
- **`rustc` REJECTED the large emitted file** at `color="#1d4ed8"`, a raw-string
  delimiter collision. `grade.sh` compiled one program of 392, so it was invisible.
- **`sprefa-extract` has `FamilyTag { Df, Call, Type, Module, Cst }`**, 17,126
  lines, five extractors. `DfEdgeKind` has only `Direct` (intra-procedural); the
  interprocedural `Flow` union is commented out, PENDING. `sources()` at
  `lang/mod.rs:36-45` has NO markdown, so no `.dl6` rail can read a `.md`.
- **SQLite WAL-reset bug** needs two connections on one file. v6 opens one, so
  nothing is broken today. Five crates bundled 3.46.0 (PR #225 bumps them).
- **The spend report counts flat-rate plans as money.** `cost_usd_recorded` is
  NULL for every `gpt-5.6-sol` and `claude-*` row. Real metered spend is $45.74
  on deepseek. The ~$21,978 notional total is what list rates would have cost.
