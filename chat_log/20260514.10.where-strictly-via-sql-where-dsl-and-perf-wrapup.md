## Solution/Approach
**Perf (3 commits):**
- `ThreadLocal<Mutex<HashMap>>` replaces `Mutex<HashMap>` for `pending_core` (v4/src/store.rs). Workers lock their own slot; flush() drains all slots.
- LO/HI in v2_ops.rs:925-926 changed from `set_at` (interns _strings+_where_bytes) to plain `set` (Term value only). Identical row counts in hits_facts; nothing else reads the dropped intern rows.

**SQL-where DSL refactor (4 phases):**
- Phase 1: WhereDef gains `dsl_body=DslShape::Plain` + `dsl_required=false`. Fuser classify_op reads from `op.dsl.raw` first, falls back to `op.args.first()`. `rewrite_where_sugar` updated to skip when next char after `where` is backtick.
- Phase 2: new `v4/src/cst/dsls/sql_where/mod.rs` (~430 LOC). Hand-rolled lexer, PREDICATE_KEYWORDS (AND/OR/NOT/IS/NULL/IN/EXISTS/LIKE/GLOB/REGEXP/BETWEEN/CASE), PREDICATE_FUNCTIONS (length/instr/substr/lower/upper/trim/abs/coalesce/ifnull/nullif/like/glob — non-aggregate only). SqlWhereLspCtx has captures only, no tables.
- Phase 3: SqlDsl imports PREDICATE_KEYWORDS/FUNCTIONS/predicate_keyword_hover from sibling sql_where. Completion list extended. is_keyword consults both lists. Hover falls through. Regression test `sqldsl_predicate_vocab_is_sourced_from_sql_where` pins it.
- Phase 4: removed `rewrite_where_sugar` (134 LOC) and `find_predicate_end` from compile/parse.rs. Dropped `paren_args` and WHERE_SPEC from WhereDef. Dropped fuser fallback. Fixed `record_dsl_reads` to accept ReadCtx so where's DSL reads register as Predicate not DslInterp. Migrated test fixtures + bench .sprf.

## Key Insights
- "Eliminate cross-core synchronization on the hot path" beats "make the synchronization faster." DashSet/StripedLru/SegQueue were tune-the-loop moves; per-thread buffer was the structural fix. 9.3× emit_stamp_summed reduction validated.
- `where`'s body was always SQLite predicate grammar with `${X}` host holes — paren form was hiding it. Backtick form is honest about the foreign-grammar embedding, same as ast/re/glob/json.
- "SqlWhereDsl is the leaf; SqlDsl composes it" — implemented at source level: SqlDsl imports vocab constants from sql_where, both surfaces yield same hover/completion for AND/OR/length/etc.
- Invariant-violation rules ("this rule should be empty") are already a one-line shipped pattern: `rule? > lsp_warn(:code)\`msg ${X}\``. No new vocab needed; `lsp_error/warn/info/hint` ops shipped, used in 7+ examples.
- LO/HI columns in <rule>_facts store raw byte position via Term.value, NOT the WhereBytesId. The `REFERENCES _where_bytes` declaration in the fuser is decorative. TypeLattice cleanup (LO/HI as IdKind::Int) is open hygiene work.
- macOS APFS read variance (105-869ms across runs of same 5000-file fixture) dominates wall on small benches; emit_stamp summed CPU is the cleaner signal for store-side perf work.
