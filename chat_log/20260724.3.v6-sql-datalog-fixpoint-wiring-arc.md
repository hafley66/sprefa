## Key Insights
- **v6/dl datalog was HALF-done, not un-done**: recursion + stratified negation already work IN MEMORY (lower.ts stratumFixpoint = a `while` in an rx `map`; equiJoin does anti-joins for notrel; rulegraph.stratify refuses negation-in-SCC). What was missing: SQL evaluation (scale + store use) and the DEFERRED cases (agg-in-recursion, non-lazy recursive members just throw RecursiveStratumDeferred and don't evaluate).
- **The store already had the SQL fixpoint pattern**: labs/fixpoint.ts `datalogSqlClosure` = `INSERT OR IGNORE ... SELECT ... JOIN` looped until `changes===0`. lowerSql generalizes it to arbitrary stratified programs with semi-naive deltas.
- **Stratified negation is safe because strata are topo-ordered**: by the time a rel with `!other(...)` evaluates, `other` is fully materialized in an earlier stratum, so `NOT EXISTS` is correct. rulegraph refuses negation whose target shares the reader's SCC (v5's forcing-edge check).
- **Interning is transparent to join logic**: equality joins, negation, comparison all work identically on interned int ids. sum/min/max only apply to INT-typed columns (where the stored id IS the value); the type system keeps them off text columns, so the compiler needs zero interning-awareness. This is why lowerSql is reusable for both the text-column test and the interned dl tables.
- **Datalog = half graph algorithms** (user): the reach namespace (reaches_from/reached_by/scc_labels/count_pairs) IS the query half of datalog; the fixpoint eval is the derivation half. An IDatalog interface should span both.
- Class-34 defense pattern that WORKED: differential test SQL-eval vs an independently-written in-memory eval on the same programs. A wrong incremental eval passes a pinned snapshot but diverges from a second real evaluator.
- Semi-naive delta compilation: override keyed by rule.body INDEX (not a module global — first draft had a broken `_setRecursiveMembers` global hack; rewrote to pass body-position overrides explicitly). Each recursive body position reads its delta while others read full; union over positions; EXCEPT full = genuinely new.
