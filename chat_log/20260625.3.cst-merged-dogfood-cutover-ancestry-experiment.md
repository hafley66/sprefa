## Key Insights
- ANCESTRY (measured, corrects prior guess): interval/nested-set span predicate wins for
  POINT/innermost-containment (the LSP query; free, no SCC) but LOSES to closure(child) for
  FULL anc materialization (91ms vs 484ms; unindexed node×node self-join is O(n²), hangs at
  136K). closure earns its keep; complementary, not retired. Browser analogy: hit-testing =
  1D innermost-containment; compareDocumentPosition = nested-set pre/post numbering.
  verify-don't-assert paid off — the naive "range-join always wins" was wrong.
- CST = forest + acyclic + nested spans. closure() ALWAYS SCC-condenses (engine.rs dedup_edges)
  — wasted on acyclic child, hence the 0.82s.
- perf: "16s" was DEBUG (always profile node/child in RELEASE). path-scoped refresh_node_rels_
  delta + `_node_path(id,path)` side table (node rel stays 6 public cols) -> incremental
  2.8s->0.82s; structural guard `last_node_files_walked==1` test (machine-independent);
  `DL_TICK_LOG_MS` surfaces slow ticks. _where_bytes 1.3s insert = 4-way index maintenance
  (PK+string_id+file_span+path), NOT batching (4000 rows/stmt, ~34 stmts/1 txn).
