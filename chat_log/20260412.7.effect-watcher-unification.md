# Session: effect-watcher-unification

## Goal
Concretely unify the effect saga architecture with sprefa's existing refactor watcher code loop. Research how `Change` → `Edit` flow can become `Change` → `Effect` → (approval) → `Edit` with full durability.

## Current State
Existing watcher loop (`crates/watch/src/watcher.rs`):

```
notify events → debounce (100ms) → classify_batch() → Vec<Change>
                                                        ↓
                                            plan_rewrites() → (Vec<Edit>, Vec<RustRewrite>)
                                                        ↓
                                            rewrite::apply() → filesystem mutations
```

Current `Change` enum (`crates/watch/src/change.rs`):
- `FsChange::Move { file_id, old_path, new_path }`
- `FsChange::Delete { file_id, path }`
- `FsChange::Create { path }`
- `FsChange::ContentChange { file_id, path }`
- `DeclChange::Rename { file_id, kind, old_name, new_name, ... }`
- `DeclChange::Added/Removed`

Current `Edit` struct (`crates/watch/src/plan.rs`):
- `file_path, span_start, span_end, new_value, reason`

Current Store trait (`crates/cache/src/store.rs`):
- `flush_batch()` - writes extraction results
- `rename_files()`, `delete_files()` - FS metadata updates
- `run_check()`, `list_violations()` - check block support
- No effect storage yet

### Phase 3: Unified Effect Loop

Replace direct apply with effect-driven flow:

```rust
// crates/watch/src/effect_loop.rs

/// The unified effect processing loop.
/// 
/// Replaces: watcher → plan → apply (immediate)
/// With:     watcher → effect_producer → effect_bus → effect_consumer → apply (gated)
pub async fn run_effect_loop(
    config: WatchConfig,
    pool: SqlitePool,
    extractors: Arc<Vec<Box<dyn Extractor>>>,
    rewriters: Arc<Vec<Box<dyn PathRewriter>>>,
) -> Result<()> {
    // 1. Start the watcher (produces raw changes)
    let change_rx = watcher::watch(config, pool.clone(), extractors).await?;
    
    // 2. Start the effect bus (channels)
    let (effect_tx, effect_rx) = tokio::sync::mpsc::channel::<Effect>(256);
    let (approval_tx, approval_rx) = tokio::sync::mpsc::channel::<EffectId>(64);
    
    // 3. Spawn effect producer (Change → Effect)
    let producer_pool = pool.clone();
    tokio::spawn(async move {
        effect_producer(change_rx, effect_tx, producer_pool, rewriters).await;
    });
    
    // 4. Spawn effect consumer (Effect → Apply)
    let consumer_pool = pool.clone();
    tokio::spawn(async move {
        effect_consumer(effect_rx, approval_rx, consumer_pool).await;
    });
    
    Ok(())
}

/// Producer: Convert Changes into Effects, persist to DB
async fn effect_producer(
    mut change_rx: mpsc::Receiver<Vec<Change>>,
    effect_tx: mpsc::Sender<Effect>,
    pool: SqlitePool,
    rewriters: Arc<Vec<Box<dyn PathRewriter>>>,
) {
    while let Some(changes) = change_rx.recv().await {
        // Plan rewrites first to know the full impact
        let (edits, rust_rewrites) = plan::plan_rewrites(&pool, &changes, &rewriters).await
            .unwrap_or_default();
        
        // Group edits by cause (Move vs Rename)
        for change in &changes {
            let effect = change_to_effect(change, &edits, &pool).await;
            
            // Persist before broadcasting
            if let Ok(id) = insert_effect(&pool, &effect).await {
                // Auto-approve pure effects
                if is_auto_approve(&effect) {
                    approve_effect(&pool, &id, ApprovalSource::Auto).await.ok();
                }
                
                effect_tx.send(effect).await.ok();
            }
        }
    }
}

/// Consumer: Execute approved effects
async fn effect_consumer(
    mut effect_rx: mpsc::Receiver<Effect>,
    mut approval_rx: mpsc::Receiver<EffectId>,
    pool: SqlitePool,
) {
    let mut pending: HashMap<EffectId, Effect> = HashMap::new();
    
    loop {
        tokio::select! {
            Some(effect) = effect_rx.recv() => {
                // Check if already approved
                match check_approval(&pool, &effect.id).await {
                    Ok(true) => execute_effect(&pool, &effect).await,
                    Ok(false) => { pending.insert(effect.id.clone(), effect); }
                    Err(e) => tracing::error!("approval check failed: {}", e),
                }
            }
            Some(id) = approval_rx.recv() => {
                if let Some(effect) = pending.remove(&id) {
                    approve_effect(&pool, &id, ApprovalSource::User).await.ok();
                    execute_effect(&pool, &effect).await;
                }
            }
        }
    }
}

async fn execute_effect(pool: &SqlitePool, effect: &Effect) {
    update_effect_status(pool, &effect.id, EffectStatus::Running).await.ok();
    
    let result = match effect {
        Effect::RefactorMove { downstream_edits, .. } => {
            apply_edits(downstream_edits)
        }
        Effect::RefactorRename { downstream_edits, .. } => {
            apply_edits(downstream_edits)
        }
        Effect::RefactorFix { proposed_edit, .. } => {
            apply_edit(proposed_edit)
        }
        // ... shell, codegen effects
    };
    
    let status = match result {
        Ok(_) => EffectStatus::Completed,
        Err(e) => EffectStatus::Failed(e.to_string()),
    };
    
    update_effect_status(pool, &effect.id, status).await.ok();
}
```

### Phase 5: Safety Levels & Circuit Breakers

```rust
// crates/watch/src/safety.rs

pub enum SafetyLevel {
    Pure,        // Reordering imports, whitespace
    Reversible,  // Renames (can undo)
    Destructive, // May lose info (inline, remove)
}

pub struct CircuitBreaker {
    max_effects_per_minute: usize,
    max_files_per_batch: usize,
    max_destructive_per_hour: usize,
    require_tests_pass: bool,
}

impl CircuitBreaker {
    pub async fn check(&self, effect: &Effect, pool: &SqlitePool) -> Result<bool> {
        // Check rate limits
        let recent_count = count_recent_effects(pool, Duration::from_secs(60)).await?;
        if recent_count > self.max_effects_per_minute {
            return Ok(false);
        }
        
        // Check destructive limits
        if effect.safety() == SafetyLevel::Destructive {
            let destructive_count = count_destructive_effects(pool, Duration::from_secs(3600)).await?;
            if destructive_count > self.max_destructive_per_hour {
                return Ok(false);
            }
        }
        
        // Run tests if configured
        if self.require_tests_pass {
            return run_tests().await.is_ok();
        }
        
        Ok(true)
    }
}
```

## Migration Path

1. **Phase 1**: Add effect tables to DB, no code changes
2. **Phase 2**: Add effect producer alongside existing flow (dual write)
3. **Phase 3**: Add CLI for viewing effects (read-only)
4. **Phase 4**: Add approval flow, make effects gate apply
5. **Phase 5**: Remove direct apply path, everything goes through effects
6. **Phase 6**: Add shell/codegen effects, complete saga

## Key Insights

1. **Change is the producer**: Existing watcher `Change` classification stays, just produces Effects
2. **Plan runs eagerly**: We still plan rewrites immediately to know full impact
3. **Effect = intent + discovered impact**: Effect stores both the trigger (Move/Rename) and planned edits
4. **Approval can be retroactive**: Effects can be auto-approved if safety permits
5. **Circuit breakers are global**: Across all effect types, not per-effect
6. **LSP sees effects as code actions**: Natural UX for IDE integration

## Open Questions

3. Should check violations auto-create RefactorFix effects?
