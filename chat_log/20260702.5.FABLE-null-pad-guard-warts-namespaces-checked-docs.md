## Problem/Context
v0.4.0's named-arg heads made NULL-padded heads writable on ANY rel, and the
lower.rs "sink use only" comment was an unenforced assumption. Beyond that:
the user asked for a wart inventory, whether namespaces/types are due, and how
to get "checked docs" that yell (git hook / CI) when a doc or .dl annotation
points at something missing — including cross-repo on main, and a "repo is a
type pointing at repos" reconstruction with enum (closed-set) tightness.

## Solution/Approach
Proof by delegated repro, then guard at the two standard layers. Namespaces
judged ready (evidence: flat .dl/ merge namespace collisions, 65 builtins
already prefix-grouped in ~22 groups via RelDecl.group, use-module global rel
space). Types-with-instances HELD (types-in-value-space ruling stands; no
current wart is caused by their absence). Checked docs = checked-notes.dl
generalized to doc-resident annotations + anti-join rails + --check in a hook.
Repo-enum = repo() config as the closed variant set, repo_dep + doc mentions
as observed pointers, unknown-variant/dead-variant rails, optional gen
materialization into a host-language union type.

## Key Insights
- NULL divergence is now MEASURED: 2^24 rows / one doubling per fixpoint
  iteration; NULL != NULL under INSERT OR IGNORE means delta never hits 0.
- House pattern for engine invariants = two layers: typecheck diag
  (--check/LSP, e.g. not-stratified) + engine bail (runtime defense, e.g.
  stratify's "unstratifiable"). recursive-null-pad follows it exactly.
- Plain `dl prog.dl` gates on typecheck errors BEFORE ticking (lib.rs ~326),
  so the rebuild_derived bail is defense-in-depth, not the primary surface.
- `count(_)` puts Wild in a head slot legitimately — head_null_pads must
  exclude aggregate slots via r.aggs, or agg rules false-flag.
- Delegating repro to Sonnet 5 worked well: precise prompt (claim, exact .dl
  programs, timeout technique, honesty clause, mechanism proof via row
  counts) returned a confirmed 2^24 measurement. Note macOS has no `timeout`
  builtin (perl alarm trick); `rel n(a, b)` bare decls REJECTED (need
  `a: text` + trailing period) — trips every fresh program author.
- Namespace evidence is concrete and 3-sourced (merge collisions, RelDecl
  groups, use-modules); types-with-instances has zero wart-evidence and a
  standing value-space ruling. Namespaces first loses nothing on types.
- Enum tightness = which anti-joins you enable; exhaustiveness both ways is
  match-exhaustiveness for the org graph.
- Live wart list (data, README Papercuts + this session): daemon 5s stall
  (P2), ? under --check (P3), scan rev_out `_` (P3), agent_* false green
  (P3), bare col decls (P3), no float / no substr / no regex-over-bound,
  closure literal-seeded in mixed bodies + unpinned-read ban, split-and-union
  tax on mixed rel kinds, reserved names grow with every builtin, no
  per-language symbol literal.
