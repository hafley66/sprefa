## Solution/Approach
Decisions/recommendations given (Chris deferred all to "fine for now"):
- @yield: recommend a NEW Temporal::Yield variant, not overloading @stream. @stream
  is inbound + STORED (drain_streams appends); @yield is outbound + TRANSIENT
  (select->push->DELETE). tick.rs already branches per-variant, so additive.
- recv/send should be AMBIENT built-in reserved rels (fixed schema, like ref/type_edge/
  scip_def), NOT declared per file. recv(id,method,params) = EDB via inject_recv;
  send(id,result) = @yield sink. They DON'T fit RelKind (whose contract is whole-set
  git refresh(eng)->bool, src/rels/mod.rs:60-84); they're the "()-return always-driven"
  flavor named at rels/mod.rs:32-34. A tiny src/rels/mcp.rs const decl pair + reserved-
  name guard, gated like doc_text_rels_used.
- Keep `route` (the lattice dispatch rel) USER-declared: it's handler logic, not transport.
- Completion signal: ship (c) channel-level only for the vertical slice (MCP 1->1 =
  every response closes); defer (a)sentinel/(b)quiescence until SSE/WS 1->N exists.
- Go-channel map: recv/@stream = <-chan receive; send/@yield = chan<- send; tick loop =
  for range; long-lived rule = goroutine; lattice merge(MaxBy) = select. WebSocket =
  duplex = recv @stream + send @yield keyed by conn.
- Vertical slice (rung 1, a weekend, NO @yield needed): Channel trait + StdioChannel +
  inject_recv + mcp loop + --mcp flag + examples/mcp-echo.dl. send is ordinary IDB the
  loop reads+clears; @yield is later sugar.
- One risk flagged, unverified: existing effect drain runs under the daemon lock; the
  MCP loop is a different driver (blocking stdin), so confirm Engine::tick() is callable
  standalone outside the daemon before building the loop.

Types-in-dl guidance (the last substantive thread):
- "Nice types like Rust" = 5 things. Drop lifetimes (no memory to borrow). Skip generics/
  traits (λ-branch, fights the base). Native soil = ADTs (sum-of-products) + nominal
  newtypes + exhaustiveness. Relational algebra IS the same sum-of-products algebra as
  Rust ADTs, so dl already sits in it (kind columns ARE informal tagged unions).
- Prior art to steal: Souffle (typed Datalog + subtype lattice + ADTs, the direct
  template), Datafun (Datalog + typed lattice λ, tracks monotonicity = ties to merge/
  MaxBy), Mercury (HM over logic + modes/determinism).
- Roadmap cheapest-first: (1) nominal newtype columns (generalize repo/rev typed cols in
  typecheck.rs), (2) declared sum types + exhaustiveness over kind columns, (3) named
  row/schema types (also kills the per-file boilerplate), (4) local inference. Stop before
  generics/traits.

## Key Insights
- Two theories of computation: λ (reduction, Church 1936) vs logic (deduction/fixpoint).
  sprefa is entirely on the logic branch; that's why it welds to SQL (applied relational logic).
- BOTH branches bottom out in Tarski's fixed-point theorem: monotone f on a complete
  lattice has a least fixed point reached by iterating from bottom. Datalog's tick() IS
  that staircase. merge(MaxBy) didn't add a feature, it handed the engine a RICHER LATTICE
  than plain-set ⊆. Chris is standing on the 1955 math.
- Language power primitives (non-string-trick): Prolog=unification+backtracking search;
  Datalog=terminating lfp over sets; Mercury=modes+determinism as a type discipline
  (recovers Kowalski's "Control" statically); Haskell=purity+HM inference+typeclasses;
  Lisp/Clojure=homoiconicity; ML=ADTs+pattern match+inference.
- What it'd take to extend dl: MORE LOGIC (richer lattices, DCG parsing, aggregation) =
  cheap/native soil; homoiconicity (dl-emits-dl) = cheap, already halfway (gen-reference.dl);
  Mercury modes/determinism = medium (?-binding is proto-modes); FULL Prolog (function
  symbols/unbound vars) = medium but leaves the decidability cliff (lose termination);
  λ-power (higher-order/laziness/HM) = expensive, fights the foundation.
- Curry-Howard: propositions=types, proofs=programs; logic prog SEARCHES for the proof,
  functional prog IS the proof written down. Same object, two verbs.
- DCG (Definite Clause Grammar, Pereira & Warren ~1980): grammar-as-logic-program via a
  difference list (S0,S) = "string minus tail not consumed." That threaded state IS a
  recursive self-join over sequence positions. In dl it's rule chains over ref-spine
  byte-spans (lo,hi) -- the difference list is already there, called a byte-span. Run a
  DCG backward = generator. Highest power-per-effort dl extension, native.
- Self-hosting: sprefa can fully self-DESCRIBE + self-LINT today (dl_diag lints dl,
  gen-reference.dl, anim-self.dl), can plausibly self-PARSE via DCG-in-dl, cannot
  self-EXECUTE without the Rust floor (something must BE the SQL weld/lower/tick). Classic
  bootstrap: seed compiler in another language.
- Timeline: Codd relational model + algebra + calculus 1970 -> Prolog 1972 -> SQL(SEQUEL)
  1974. SQL is youngest. Codd's theorem (1972): algebra = calculus (relational
  completeness) -- the declarative(calculus)/operational(algebra) fork Chris ground in
  college is the SAME fork as λ/logic and Curry-Howard. Datalog = relational calculus +
  recursion; SQL only got recursion (CTEs) in SQL:1999, ~25yr after Prolog. sprefa lowers
  that recursion BACK onto SQL.
- Mercury merges logic+functional at the ENGINEERING level (both predicate + function
  syntax, one object), glued by modes+determinism -- NOT the deep Curry-Howard/proofs-
  as-programs merge (that's Agda/Coq/Idris/Lean, dependent types).
- Rust types for a QUERY language = ADTs + nominal newtypes + exhaustiveness (native,
  relational algebra is the same sum-of-products algebra; kind columns are informal sum
  types). Drop lifetimes; skip generics/traits.
- Chris's paradigm anchors: understands Go channels via RxJS (switchMap etc.), NOT redux;
  actively hates redux ("so much more after redux"). Rich Hickey's state/identity/value
  talks named as the anti-redux cure.
