## Key Insights
- sem schema is 3 tables (files, entities, edges), zero indexes beyond PK, zero views, zero UDFs. Everything loads into memory, all filtering in Rust.
- sem entity ID format: "{file_path}::{entity_type}::{name}"
- sem invalidation: full nuke on any mtime change. No incremental per-file.
- sprf_directives (auto-watch comments) needs zero new machinery: comment() + line(re:) + check() already compose into it
