## Solution/Approach
- inject_main.js (MAIN world, document_start, all claude.ai/*) wraps fetch/XHR; on a "usage" response it
  (a) stashes JSON on documentElement[data-le-usage] and (b) window.postMessages it.
- relay.js (ISOLATED world) forwards the postMessage to the SW -> handleCapture parses via meterPaths,
  POSTs record source:"api-passive" (5s throttle). => passive capture from ANY tab, no specific page/driven tab.
- Driven path: chrome.alarms (1min) reloads a dedicated bg tab to targetUrl, injected scrapeUsage reads the
  stash (+DOM fallback: role=progressbar > money-row(2$+%) > "% used" text), POSTs source:"api".
- Extraction config-driven via meterPaths (lodash dot-paths + scale + enabled), getByPath/metersFromConfig.
  NO eval (MV3/page CSP). Ships WORKING DEFAULT meterPaths (five_hour/seven_day/extra_usage) -- user OK'd
  field names public; overridable in Options.
- CONFIG SOURCE OF TRUTH = server config.conf. Server GET /config returns config.conf as JSON (zero-dep
  json_str/config_json). Extension getConfig() fetches {serverBase}/config each tick and uses
  target_url/server_url/interval_minutes from it (fixes stale-storage-wins bug); falls back when server down.
  serverUrl + meterPaths stay extension-side bootstrap.
- Reset-to-defaults: button in extension Options (set storage=DEFAULTS) AND viewer Config pane (Config::default
  -> save_config rewrites config.conf).
- Server: zero-dep std Rust, lib.rs (serve/handle/append/respond/read_conf/config_json) + main.rs bin; viewer
  embeds server on a thread (one cargo run). CORS *, OPTIONS, GET /config + GET / (data file) + POST append.
- Viewer (eframe 0.29 + chrono): claude-dark, 3-col aligned meters (LABEL_W/VALUE_W uniform bar),
  usage_bar_c(fill,track), relative "updated ago" (1st hr then clock), reset countdowns scale d/h/m
  (167h37m->6d23h via resets_compact + resets_in), ext-health status, Open-usage-page button, 2 extra-usage
  toggles, color pickers (mini_bg/bar/text/track labeled), MINI MODE: borderless always-on-top, MinInnerSize
  lowered (560x44), no-wrap Extend, per-meter 2-line div (bar + secondary: percent->reset, money->"% used"),
  vertical separators, horizontal ScrollArea (drag_to_scroll false, scrollbar AlwaysHidden) so it scrolls,
  × exit pinned OUTSIDE scroll area always visible, drag strip to move / double-click to exit.
