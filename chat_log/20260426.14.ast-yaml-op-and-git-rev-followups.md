## Solution/Approach
**ast_yaml lower path (final shape):**
1. Parse bracket → SupportLang (rust/rs/typescript/ts/c)
2. Read paren body raw bytes
3. `rewrite_carveouts(raw)` — `${X?}` -> `$X`, `$$${X?}` -> `$$$X`, `?` suffix stripped
4. `collect_carveout_names_and_positions(raw)` — names + body-relative token spans
5. Lift positions to absolute via `body_origin = paren.byte_range().start + 1`
6. `serde_yaml::from_str::<serde_yaml::Value>(rewritten)` then `wrap_under_rule_if_bare(value)` — checks for envelope keys (rule/constraints/utils/transform/fix); if none present, wraps the value under `rule:`
7. `serde_yaml::from_value::<SerializableRuleCore>(core_value)`
8. `core.get_matcher(DeserializeEnv::new(lang))` -> `RuleCore<SupportLang>`
9. Build `bound_caps` as union of user_caps (source order) + `rule_core.defined_vars()` (catches native `$X` in YAML strings)

**ast_yaml runtime path:**
- pipe(): `per_cursor` -> `ensure_content_loaded` -> `AstParseEffect` -> `grep.root().find_all(&*self.rule_core)` -> for each NodeMatch, walk bound_caps, extract via `env.get_match(name)` (single) falling back to `env.get_multiple_matches(name)` (multi joined with " "), emit cursors.
- cache_key: `(name, lang, _src)` triple hashed.

**DiskFileSource fix:**
- Dropped `if rev != self.rev { return ...; }` in both files() and file_bytes(). Cache still partitions on (repo, rev) keys; disk source serves worktree bytes for any cursor rev label until GitFileSource lands. Docstring rewritten to match.

## Key Insights
- ast-grep RuleConfig is fully compositional (inside/has/follows/precedes/not/all/any over patterns + kind + regex constraints). Single YAML escape hatch covers what would otherwise need bracket-DSL predicates + brace-fan-out + nested ops.
- `;` in sprf brace = Fork (per-arm cursor identity preserved); ast-grep `any` collapses to "some sub-rule matched" without arm tag. Two different lowerings — denormalize to N rule applications when arm identity matters.
- Capture-scope split: bracket predicates share metavar scope with main pattern (ast-grep unifies); brace arms isolate. Document at lower-time so users don't assume `ast(impl ${T?}) { > ast(fn ${T?}()) }` unifies.
- DiskFileSource was contradicting its own docstring — claimed to short-circuit all revs to worktree but gated on rev == self.rev. The gate predated the multi-source plan.
- LSP hover relies on Op::term_positions() to recognize cursor inside a `${X?}` carveout. Any new pattern op MUST populate term_positions for hover focus to light up captures.
- Stale LSP binary in VS Code is invisible at the editor level — `just vscode-install-release` rebuild + reload window is the recovery path.

## Open Questions
- GitFileSource: gix vs git2-rs final pick. Recommendation already locked in — gix (pure rust, ghcacher precedent). Confirm before adding the Cargo dep.
- Tag fanout surface: `rev(:tags)` vs `rev(:tags, glob("v*"))` vs `rev(${T?}, :tags)`. Spike before lowering.
- Sub-token captures in ast_yaml: per-Value walk of YAML strings vs whole-body adjacency-aware rewrite. Per-Value is more correct; whole-body is one-line cheaper. Decide when sprefa-5qb second pass starts.
- LSP buffer overlay: snapshot DocSession on each hover/diag call, or cache+invalidate on didChange? Snapshot is simpler; cache reduces alloc.
