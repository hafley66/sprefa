## Key Insights
- empty-body rule decl is the link primitive — fact = sugar for "seed cursor + sink rule"; under wide-row schema model, both fact and rule write into <name>_facts
- ${pipe} carveouts compose via host pre-pass already; only the lowerer + render path need to know about op-shape vs term-shape
- chain_pos is the right discriminator for "decl vs sink" in v4 (flow is the [...] bracket override, not upstream-presence indicator)
- glob is regex-with-glob-syntax, not a filesystem walker — the WalkBuilder in old GlobComponent was a wart from incremental porting
- v4 fs cursor.value carries the path; read flips it to bytes — uniform contract WT branch and rev branch
- universal carveout ${X?}/${X} sigils work everywhere a backtick DSL body appears; per-DSL scanners (like glob's old <NAME>) are residue
- $$$ prefix on a capture is the multi-segment greedy modifier — 3 dollars consumed in walk, ${X?} body translates to (?P<X>.*)
