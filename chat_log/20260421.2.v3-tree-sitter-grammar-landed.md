## Solution/Approach

The grammar is flat and rule-based, no external scanner. Carveouts are
first-class nodes (`carveout_expr`), not a pre-pass. Sub-grammar
consumers will walk the tree and pull carveout byte ranges directly
instead of invoking a strip_carveouts helper.

Key grammar rules landed:

```
source_file  = stmt*
stmt         = pipe `;`?
pipe         = pipe_step (`>` pipe_step)*
pipe_step    = op_invocation | cursor_ref | xref | capture_write
             | ans_ref | deprecated_scan_sigil

op_invocation = IDENT bracket_slot* paren_slot? brace_slot?

bracket_slot = `[` _slot_body `]`
paren_slot   = `(` _slot_body `)`
brace_slot   = `{` _slot_body `}`

_slot_atom   = carveout_expr | shell_literal | string | raw_string
             | atom_literal | term_ref | ans_ref | deprecated_scan_sigil
             | xref | identifier | number | _slot_punct
             | `{` _slot_body `}` | `(` _slot_body `)` | `[` _slot_body `]`

carveout_expr = `${` pipe `}`   |   `&{` pipe `}`
shell_literal = `${{` opaque_until_}} `}}`

term_ref               = token(`$` IDENT)
ans_ref                = token(`$$`)
deprecated_scan_sigil  = token(`$$` IDENT)      # longest-match wins
xref                   = IDENT `.` term_ref
cursor_ref             = `&` (`.` IDENT | `.` term_ref)+
atom_literal           = token(`:` IDENT)
```

## Design locks confirmed this session

1. `$$` vs `$$IDENT` disambiguation is token-longest-match. No `prec`
   overrides. Bare `$$` (ans slot) only fires if nothing alphanumeric
   follows.
2. `_slot_punct` raises `>` to a slot-body atom so `{ echo > $VAR }`
   doesn't confuse the outer pipe separator.
3. Tree-sitter error recovery replaces the hand-rolled `synth_fragment_op`
   path. LSP tolerant mode becomes "tree-sitter's built-in recovery +
   walk ERROR / MISSING nodes."
4. Shell literal body is intentionally opaque. `${{...}}` scans to
   first `}}`. Writing literal `}` inside is user error (use shell
   escape / single-dollar spelling if needed).

### Zoom 3 sketch of the parse.rs replacement body

```rust
pub fn host_parse(src: &str, file: Arc<Path>)
    -> Result<Vec<Pipe>, Vec<ParseError>>
{
    let mut parser = tree_sitter::Parser::new();
    parser.set_language(&tree_sitter_sprefa::LANGUAGE.into()).unwrap();
    let tree = parser.parse(src, None).ok_or_else(|| vec![ParseError {
        message: Arc::from("tree-sitter produced no tree"),
        offset:  0,
    }])?;
    let root = tree.root_node();

    let mut errs = Vec::new();
    collect_errors(root, src, &mut errs);
    if !errs.is_empty() { return Err(errs); }

    let mut pipes = Vec::new();
    let mut child_ix = 0u16;
    let mut cursor = root.walk();
    for stmt in root.children(&mut cursor) {
        if stmt.kind() != "pipe" { continue; }
        pipes.push(lower_pipe(stmt, src, &file, &[], child_ix));
        child_ix += 1;
    }
    Ok(pipes)
}

fn lower_pipe(node: Node, src: &str, file: &Arc<Path>,
              parent_path: &[ParseSeg], pipe_ix: u16) -> Pipe
{
    let mut ops = Vec::new();
    let mut step_ix = 0u16;
    let mut c = node.walk();
    for step in node.named_children(&mut c) {
        match step.kind() {
            "op_invocation"         => ops.push(op_from_node(step, src, file, parent_path, step_ix)),
            "cursor_ref"            => ops.push(cursor_ref_from_node(step, src, file, parent_path, step_ix)),
            "xref"                  => ops.push(xref_from_node(step, src, file, parent_path, step_ix)),
            "capture_write"         => ops.push(capture_write_from_node(step, src, file, parent_path, step_ix)),
            "ans_ref"               => ops.push(ans_ref_from_node(step, src, file, parent_path, step_ix)),
            "deprecated_scan_sigil" => ops.push(deprecated_sigil_from_node(step, src, file, parent_path, step_ix)),
            _ => continue,
        }
        step_ix += 1;
    }
    Pipe { ops }
}

fn op_from_node(node: Node, src: &str, file: &Arc<Path>,
                parent_path: &[ParseSeg], step_ix: u16) -> OpInvocation
{
    let name_node = node.child_by_field_name("name").unwrap();
    let name      = Arc::<str>::from(&src[name_node.byte_range()]);

    let mut brackets  = Vec::new();
    let mut paren_src = None;
    let mut brace_src = None;
    let mut c = node.walk();
    for f in node.children_by_field_name("bracket", &mut c) {
        brackets.push(BracketSlot { src: body_arc(f, src), byte_range: body_range(f) });
    }
    if let Some(p) = node.child_by_field_name("paren") {
        paren_src = Some(ParenSlot { src: body_arc(p, src), byte_range: body_range(p) });
    }
    if let Some(b) = node.child_by_field_name("brace") {
        brace_src = Some(BraceSlot { src: body_arc(b, src), byte_range: body_range(b) });
    }

    let parse_site = Arc::new(ParseSite {
        file:       file.clone(),
        path:       Arc::from(attach_seg(parent_path, ParseSeg::Top { index: step_ix })),
        byte_range: node.byte_range(),
    });

    let crossrefs = collect_xrefs_under(node, src);

    OpInvocation { name, brackets, paren_src, brace_src, parse_site, crossrefs }
}

fn collect_xrefs_under(node: Node, src: &str) -> Vec<CrossRefOccurrence> {
    let mut out = Vec::new();
    walk_descendants(node, |n| {
        if n.kind() == "xref" {
            let rule_n = n.child_by_field_name("rule").unwrap();
            let var_n  = n.child_by_field_name("var").unwrap();
            let var_txt = &src[var_n.byte_range()];            // `$NAME`
            let var     = Arc::<str>::from(var_txt.trim_start_matches('$'));
            out.push(CrossRefOccurrence {
                rule:       Arc::from(&src[rule_n.byte_range()]),
                var,
                byte_range: n.byte_range(),
            });
        }
    });
    out
}

fn collect_errors(root: Node, src: &str, out: &mut Vec<ParseError>) {
    walk_descendants(root, |n| {
        if n.is_error() {
            out.push(ParseError {
                message: Arc::from("syntax error"),
                offset:  n.start_byte(),
            });
        } else if n.is_missing() {
            out.push(ParseError {
                message: Arc::from(format!("missing `{}`", n.kind())),
                offset:  n.start_byte(),
            });
        }
    });
}
```

## Key Insights

1. Tree-sitter-cli required on dev boxes; installed to `~/.cargo/bin`
   via `cargo install tree-sitter-cli`. Parser.c is regenerated from
   grammar.js via `tree-sitter generate` run in the crate dir.
2. ABI 14 vs 15 — current cli warns about no `tree-sitter.json`; ABI 14
   output works with `tree-sitter = 0.24` in consumer crates. Do not
   upgrade to 0.25 yet — sprefa already pins 0.24 and the `links =
   "tree-sitter"` rule means one version across the workspace.
3. Carveouts are first-class CST nodes. Sub-grammar hookup becomes
   "walk your slot body, collect `carveout_expr` ranges, pass their
   complement to `set_included_ranges`." The `scan_carveouts` pre-pass
   and `strip_carveouts` helper are retired in favor of tree walks.
4. Longest-match on `$$` vs `$$IDENT` works cleanly without prec; both
   as plain `token(...)`. This is the same resolution pattern tree-
   sitter uses for `<` vs `<=` in most grammars.
5. The old `scan_slot_crossrefs` / `scan_slot_scan_pointers` walks over
   slot-body strings are now a `walk_descendants(slot_body_node)` that
   picks up `xref` / `deprecated_scan_sigil` nodes directly.
6. Error recovery comes for free. Old `synth_fragment_op` +
   `synth_empty_fragment` branches are replaced by tree-sitter's
   built-in ERROR / MISSING nodes. `host_parse_tolerant` becomes "same
   entry point, accept errors" rather than a parallel code path.

## Open Questions

1. Should tree-sitter generate live at CI / commit time, or be a
   `cargo build` prereq? Current state: generate once, check in
   `src/parser.c` + `src/grammar.json` + `src/node-types.json` +
   `src/tree_sitter/parser.h`. `cargo build` just compiles parser.c.
2. Where does the `_slot_body` re-parse contract for ops live? Each op
   currently receives `ParenSlot { src, byte_range }`. With tree-sitter,
   we could instead hand ops the `tree_sitter::Node` for their slot and
   let them walk it. Migration path: keep `src: Arc<str>` for now, add
   a `node_id: Option<u32>` later if/when ops need CST-level access.
3. `ParseSite::path` semantics — the old `ParseSeg::Top { index }` and
   friends came from the hand-rolled child-index counter. Tree-sitter
   gives us byte ranges directly; the ParseSeg path might simplify to
   just "index within parent" walked from the root. Decide at rewrite
   time.
4. `CrossRefOccurrence` — currently op-level, scanned from slot body
   text. With xref as a CST node, we have both structured form and
   raw byte range. Keep the struct stable for now; later add a
   `cst_node_id` if tooling benefits.
5. v2 carryover in `sprefa` crate (1313-line op.rs etc.) — sweep after
   ops_core lands. Not blocking.
