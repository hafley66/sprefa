## Key Insights
- references is cross-lang FOR FREE via content-addressed ref-spine string id.
  The codegen rhythm (operationId interned once) ties generated files together.
- definition/diag/def_target = the convention-relation pattern: LSP reads
  user-declared rels by column name. Generalize to impl_target, hover_section,
  inject -> "LSP control from a dl page" (user loves this).
- call_edge now cross-lang (Rust+Kotlin+TS). Kotlin extract_calls keyed on
  function_declaration/call_expression; TS on FunctionDeclaration/MethodDefinition
  /arrow-const + whole-program CallExpression. caller_sym=None (engine fills).
- Same-repo ambiguous callee name -> 0 call_edge (name-unique resolver declines);
  per-repo resolves. This is axis-4 resolution fidelity (SCIP disambiguates).
- type_edge(implementor, interface, "impl"); iface supertypes = "generic".
  Singleton smell = interface w/ exactly 1 impl (v5: IngestLang=1, TypeLang=3).
- gen file form: one rule per file (two bail). match named captures (?P<x>) bind
  as dl vars. autodoc self-match gotcha: prose example markers get transcluded.
- USER PREF (critical): wants ENFORCEMENT IN DL, not Claude Code settings hooks.
  Self-policing word avoidance is unreliable across sessions -> needs external
  deterministic dl rule. This is an end goal, not just a nicety.
