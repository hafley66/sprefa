## Key Insights
- **Everything is a Pipe**. Strings, op invocations, sub-chains. Value enum has TWO variants: Atom + Pipe. No Pattern, no Capture. DSL bodies use `${X}` interpolation that the DSL parser handles per-op.
- **`[]` is source/flow override**, defaults to `&.value`. `[ast]` for source override is no more (lang goes in parens). RxJS pipe shape: every op takes one source pipe + N parametric args.
- **Diags turnkey**: ArgSpec is declarative. `validate_call(def, flow, args, block, dsl, spans) -> Vec<Diag>`. LSP reads it for free; arg-kind/arity/slot-presence diagnostics emit before lower runs.
- **First-col-is-key convention is gone.** Every fact row carries `_id = blake3(table || sorted-fields-canonical)` (content-addressed, dedup-friendly). FactStore.commit publishes uniform `Dirty { domain: "row", key: H(_id) }`.
- **Term = cursor.mapTo() in RxJS**. Read pulls term into &.value (with diag on unbound). Bind pushes &.value into term. No braces, no carveouts.
- **Backtick `` ` `` for DSL bodies**. Markdown-fence rule for embedded backticks. Bare backtick = string literal (no tag = str DSL).
- **Anti-join**: FactRead::anti(...) drops cursor on match, passes on empty. `fact?(:r, :A, :B)` exists-check negation.
- **MutationStore is dead**. FactStore<R: Row> in effect_runtime/v2 is the canonical state surface.
- **Park/wake serializability**: A subscriber waiting for `next?(:chan)` is a queue ROW with Wake::Key. With SqliteQueue<N: Codec> + SqliteFactStore, full pipeline state is durable across restart.
- **"tag" is forbidden** — saved to feedback memory. Always "fact" / "fact_<name>?".
- **One smoke test** rule — saved to feedback memory. No granular per-op test sprawl.
- **No "substrate" word** — saved to feedback memory. Use v2 / Component / expand.
- **No reset** in git workflow per user — use `git restore --staged` for unstaging.
