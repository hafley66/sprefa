# Session: lsp-folder-fs-completions

## Goal
Fix LSP completion double-pump issue and add star pattern preservation for file/folder completions.

## Current State

- ✅ Folder completions: indented children (↳), breadcrumb detail
- ✅ File completions: star preservation (shows `crates/*/Cargo.toml` with breadcrumb `crates/cache`)
- ✅ E2E tests pass (8/8)
- ✅ Committed: 3e24640

## Problem/Context
Completions were appending instead of replacing partial text. User wanted star patterns preserved so `fs(crates/*/)` suggests `crates/*/Cargo.toml` not `crates/cache/Cargo.toml`.

## Solution/Approach
1. Added `replace_range` parameter to `complete_dirs()` and `complete_files()`
2. Set `text_edit` on all completion items to replace range with new text
3. For glob patterns: extract prefix, build pattern label, breadcrumb shows concrete match

- Breadcrumb detail shows concrete path while label preserves star pattern
