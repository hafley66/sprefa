# sprefa-server / sprefa-lsp / sprefa split

One long-lived HTTP server. Two thin shells. Prototype, breaking changes fine.

## Binaries

```
sprefa-server   HTTP server. Owns tokio runtime, ServerState, SQLite, ResultStore,
                LSP layer, workspaces, watcher (later), auto-run rules (later).
                Listens: HTTP over unix socket + TCP; WebSocket at /lsp.
                Writes: $XDG_RUNTIME_DIR/sprefa/server.json on startup.
                Logs: $XDG_STATE_HOME/sprefa/server.log (append; also stderr when foreground).

sprefa-lsp      Thin stdio↔WebSocket proxy. Editor speaks LSP over stdio;
                this shell forwards every frame to /lsp on the server.
                ~80 LOC. Auto-spawns server if server.json missing.

sprefa          Thin HTTP CLI. Hits /run, /query, /status, /rules, /events.
                Auto-spawns server if server.json missing.
```

## Invariants (do not break)

- Ops own everything.
- Reads are pipe ops; writes are deferred effects. CLI runs always `AutoApprove`. Prompt routing is LSP-only (see decision 2 below).
- Reparse discipline preserved: `cancel.cancel()` → TaskGuard drop → handler abort. Per-run child token from `state.cancel_root`.
- Content contract unchanged. Shared `BufferOverlay` inside each `WorkspaceCtx`.
- `DocSession` sync surface preserved (`block_in_place` bridge).
- Server runtime is `#[tokio::main(flavor = "multi_thread")]`; `block_in_place` requires it.

## Decisions (locked)

1. **`BufferOverlay` API.** Already interior-mutable via `set_buffer(BufferKey, Bytes)` / `clear_buffer(&BufferKey)` on `&self`. Zero API change. `LspLayer` writes to it on `did_open`/`did_change`; runs read through it transparently.

2. **`ResultStore` keying.** One global `ResultStore` on `ServerState`. Rows keyed by `(scanner_hash, expr_name)`. `scanner_hash` already composes source + config + repo-rev set. Workspaces are LSP-layer-only; nothing under `run_pipeline` knows the concept.

3. **CLI runs always `AutoApprove`.** `MutationPrompt` routing is LSP-only. The prompt follows the DocSession's originating WebSocket connection. Writes from CLI are blocked on S5 write-ops anyway.

4. **No idle shutdown.** Server is an always-on supervisor. Watches repos, keeps SQLite current, runs registered rules on change, emits violation notifications. Stopping via `sprefa stop` or process manager.

5. **TCP default 7417.** Binds `127.0.0.1:7417` unless `--http-tcp HOST:PORT` overrides. `SPREFA_HTTP_PORT` env override. Unix socket always preferred by clients when present.

6. **Logging.** `$XDG_STATE_HOME/sprefa/server.log` (fallback `~/.local/state/sprefa/server.log`). Append; rotate on startup if > 10 MB. Foreground run mirrors to stderr via `tracing_subscriber`.

7. **Multi-client LSP fan-out.** `LspLayer` holds `subscribers: HashMap<Url, Vec<mpsc::Sender<LspFrame>>>`. Each `LspAdapter` registers a sender per opened URI; `did_close` drains it. `publish_diagnostics` iterates senders, prunes dead ones on send-error.

        let store: Arc<dyn Store> = match &opts.store_path {
            Some(p) => SqliteStore::open(p).await?,
            None    => SqliteStore::open_memory().await?,
        };
        Ok(Self {
            runtime_cfg:  Arc::new(RuntimeConfig::test_default()),
            store,
            results:      Arc::new(ResultStore::default()),
            registry:     Arc::new(default_registry()),
            workspaces:   Arc::new(RwLock::new(WorkspaceRegistry::default())),
            lsp:          Arc::new(LspLayer::default()),
            cancel_root:  CancellationToken::new(),
            info_path:    default_info_path(),

        self.cancel_root.cancel();
        let _ = std::fs::remove_file(&self.info_path);

### `server/_4_transport_lsp.rs`

```rust
pub struct LspAdapter {
    state:    Arc<ServerState>,
    outbound: mpsc::Sender<LspOutbound>,            // per-connection fan-in
    owned_uris: Mutex<HashSet<Url>>,                // for cleanup on disconnect
}

// Two ways LspAdapter is wired:
//
// A. Direct tower-lsp Server on a duplex stream constructed from the WebSocket.
//    Each WS connection spawns one LspService<LspAdapter>.
//
// B. Hand-rolled JSON-RPC frame dispatch into LspAdapter methods. Simpler, no
//    Socket conversion. Ships in D3.

pub async fn serve_lsp_ws(
    state: Arc<ServerState>,
    ws: WebSocket,
) {
    let (tx_out, rx_out) = mpsc::channel(64);
    let adapter = LspAdapter { state: state.clone(), outbound: tx_out, owned_uris: Mutex::new(HashSet::new()) };
    // split ws; read loop dispatches JSON-RPC to adapter methods;
    // write loop drains rx_out + adapter response futures, frames them to ws.
    // On disconnect: drain owned_uris, call state.lsp.close for each;
    // unregister subscriber senders.
}
```

### `server/_5_transport_http.rs`

```rust
pub async fn serve_http(state: Arc<ServerState>, opts: HttpOpts) -> Result<()> {
    let app = Router::new()
        .route("/status",  get(status_handler))
        .route("/run",     post(run_handler))            // SSE
        .route("/query",   post(query_handler))          // D3+
        .route("/rules",   get(list_rules).post(add_rule).delete(remove_rule))  // D8
        .route("/events",  get(events_handler))          // SSE; violations, auto-run results (D8)
        .route("/lsp",     get(lsp_ws_upgrade))          // WebSocket
        .route("/shutdown", post(shutdown_handler))
        .with_state(state.clone());

    let mut joins = Vec::new();
    if let Some(sock) = opts.unix {
        let _ = std::fs::remove_file(&sock);
        if let Some(parent) = sock.parent() { std::fs::create_dir_all(parent)?; }
        let listener = UnixListener::bind(&sock)?;
        joins.push(tokio::spawn(axum::serve(listener, app.clone()).into_future()));
    }
    if let Some(addr) = opts.tcp {
        let listener = TcpListener::bind(addr).await?;
        joins.push(tokio::spawn(axum::serve(listener, app.clone()).into_future()));
    }
    futures::future::try_join_all(joins).await?;
    Ok(())
}
```

## `sprefa-server` main (Z3)

```rust
#[tokio::main(flavor = "multi_thread")]
async fn main() -> Result<()> {
    let opts = ServerOpts::parse();
    init_tracing(&opts);

    let state = Arc::new(ServerState::new(&opts).await?);

    // Write server.json now so shells auto-spawning us can find us.
    let info = build_info(&state, &opts);
    ServerInfo::write_atomic(&state.info_path, &info)?;

    let http = serve_http(state.clone(), HttpOpts { unix: opts.http_unix.clone(), tcp: opts.http_tcp });

    tokio::select! {
        res = http => { res?; }
        _ = tokio::signal::ctrl_c() => {}
        _ = state.cancel_root.cancelled() => {}
    }

    state.shutdown().await;
    Ok(())
}
```

## `sprefa-lsp` (Z3)

```rust
#[tokio::main]
async fn main() -> Result<()> {
    let info = ensure_server_up().await?;                       // reads/creates server.json
    let ws_url = build_ws_url(&info, "/lsp")?;                  // ws+unix:// or ws://127.0.0.1:...
    let (ws, _) = tokio_tungstenite::connect_async(ws_url).await?;
    let (mut ws_tx, mut ws_rx) = ws.split();

    let mut stdin  = FramedRead::new(tokio::io::stdin(),  LspCodec::default());
    let mut stdout = FramedWrite::new(tokio::io::stdout(), LspCodec::default());

    let up = async {
        while let Some(frame) = stdin.next().await {
            ws_tx.send(Message::Binary(frame?.to_vec())).await?;
        }
        Ok::<_, anyhow::Error>(())
    };
    let down = async {
        while let Some(msg) = ws_rx.next().await {
            if let Message::Binary(b) = msg? { stdout.send(b.into()).await?; }
        }
        Ok(())
    };
    tokio::try_join!(up, down)?;
    Ok(())
}
```

## `sprefa` CLI (Z3)

```rust
#[tokio::main]
async fn main() -> Result<()> {
    let cli  = ClientCli::parse();
    let info = ensure_server_up().await?;
    let http = HttpClient::connect(&info).await?;

    match cli.cmd {
        ClientCmd::Run { file, root } => {
            let body = RunRequestDto {
                source: std::fs::read_to_string(&file)?,
                source_path: Some(file),
                workspace_hint: root,
            };
            let mut sse = http.post_sse("/run", &body).await?;
            let mut cursors_by_expr: HashMap<Arc<str>, Vec<Cursor>> = HashMap::new();
            while let Some(ev) = sse.next().await {
                match ev? {
                    RunEvent::Cursor { expr_name, cursor } => {
                        cursors_by_expr.entry(expr_name.unwrap_or_else(|| Arc::from("")))
                            .or_default().push(cursor);
                    }
                    RunEvent::Diag { diag } => eprintln!("diag [{}]", diag.code()),
                    RunEvent::Done          => break,
                    _ => {}
                }
            }
            print_cursors_grouped(&cursors_by_expr);
        }
        ClientCmd::Status => println!("{:#?}", http.get_json::<StatusDto>("/status").await?),
        ClientCmd::Stop   => http.post::<_, ()>("/shutdown", &()).await?,
        ClientCmd::Rules(sub) => handle_rules(&http, sub).await?,    // D8
        ClientCmd::Tail       => stream_events(&http).await?,        // D8
    }
    Ok(())
}

async fn ensure_server_up() -> Result<ServerInfo> {
    let path = default_info_path();
    if let Ok(info) = ServerInfo::read(&path) {
        if pid_alive(info.pid) && probe(&info).await.is_ok() { return Ok(info); }
        let _ = std::fs::remove_file(&path);
    }
    spawn_detached("sprefa-server", &[])?;
    for _ in 0..30 {
        if let Ok(info) = ServerInfo::read(&path) {
            if probe(&info).await.is_ok() { return Ok(info); }
        }
        tokio::time::sleep(Duration::from_millis(100)).await;
    }
    bail!("sprefa-server failed to come up; check {}", default_log_path().display());
}
```

## Slicing

### D1 — Server skeleton under current LSP

Ship `v2/src/server/{mod,_0_state,_1_workspace,_2_lsp_layer}.rs` as types + stubs. Port `resolve_reader` / `walk_up_*` into `_1_workspace.rs`. Existing `sprefa_v2_lsp.rs` keeps working unchanged (ignores the new module). No behavior change, no new binaries. Compiles, tests pass.

### D2 — `sprefa_server` binary + HTTP skeleton + `/status`

Add `bin/sprefa_server.rs`, `server/_5_transport_http.rs` with `/status` only. `ServerInfo` write/read helpers. Server.json atomic write. Delete `sprefa_v2.rs`. Temporary: LSP still stdio via old binary.

### D3 — `/run` SSE + `sprefa` CLI + WebSocket `/lsp`

`server/_3_run.rs::run_pipeline`. `/run` SSE handler. `server/_4_transport_lsp.rs` WebSocket adapter with full LSP method dispatch. `bin/sprefa.rs` client. `bin/sprefa_lsp.rs` shell. Delete `sprefa_v2_lsp.rs`. Editor configs migrate to `sprefa-lsp`.

### D4 — Shared `ResultStore` cache-warm proof

Integration test: two `sprefa run` calls against the same pipeline hit the store warm on the second call. Scanner_hash skip-set observable.

### D5 — Auto-spawn + pidfile + server.json atomic

Harden `ensure_server_up`. Stale-lock reclaim. `sprefa stop` ends gracefully.

### D6 — Watcher

`server/_6_watcher.rs` on `.git/objects/pack/**`. Pack arrivals bump scanner_hash invalidation for affected `(repo, rev)`.

### D7 — Windows named pipe

`HttpBind::NamedPipe` in `serve_http` via `tokio::net::windows::named_pipe`. `sprefa-lsp` and `sprefa` both probe named pipe on Windows.

### D8 — Auto-run rules + `/events` SSE (the supervisor purpose)

`server/_7_auto_run.rs`. SQLite table `registered_rules(workspace_root, sprf_path, enabled, last_scanner_hash)`. Watcher event → recompute scanner_hash → re-run affected rules → diff against prior rows → emit `ViolationEvent` on `/events` SSE and to all connected LSP subscribers as `window/showMessage`. CLI: `sprefa rules add PATH`, `sprefa rules list`, `sprefa tail`.

## Known footguns

- `DocSession.run_sync` uses `block_in_place`; requires multi-thread runtime. `sprefa-server` must use `#[tokio::main(flavor = "multi_thread")]`.
- `SqliteStore` has a single writer. Serialize writes across concurrent `run_pipeline` calls via the store's internal mutex; add a `tokio::sync::Semaphore(1)` if contention is observed.
- Unix socket cleanup on crash: `remove_file` before bind. `Drop` on listener tries graceful unlink.
- `MutationPrompt`'s `oneshot::Sender<Approval>` is not `Clone`. LspPromptBridge ownership is single-connection; prompts only delivered to the DocSession's owning LSP WS. If that connection drops mid-prompt, treat as Deny.
- Tracing target conflict: foreground mode writes to both file and stderr; detached mode writes to file only; LSP binary must never emit tracing to stdout (corrupts LSP frames).
