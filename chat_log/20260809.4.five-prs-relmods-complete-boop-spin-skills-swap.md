- Rels-as-true-types confirmed: every non-scalar RHS type is a rel; column =
  scalar inline OR integer ref. Scalars = deliberate exception (atoms refs are
  made of; int(X) = infinite type predicate).
- Capture fork RESOLVED: implicit parent-ref column (surrogate id), NOT raw
  column distribution — reconciles ruling 609 with surrogate-keys law.
- No curried scopes: refs by identity never instance; static resolution.
- Parent instantiation: each parent row = one instance of child scopes;
  partitions open empty; no forced child rows; module = one-implicit-row case.
- Mount design: use 'x' as y = __mount catalog row + compiler grafts target
  __rel subtree under alias; mount fact is data, compile is engine's job.
- Comptime: type IS a row of __rel; instance-of = membership check; no new
  machinery (gel-demo + catalog_probe receipts).
- Unification ledger delivered: unified (namespace/module/class=rel tree;
  struct/FK/capture=ref; enum/option=RHS mint; type=catalog row; imports=dead)
  vs principled exceptions (scalars, dot grammar slots, <-/<+, currying)
  vs debt (kind:module should die F-C; h_id ignores parent edge so reparent
  invisible to HMR; named args catalog rels; option spelling loss).
