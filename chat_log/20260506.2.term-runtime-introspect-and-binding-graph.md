## Locked design (cumulative — supersedes 20260506.1 host syntax table)

### Host syntax (final-for-now)

| concept                  | syntax                                                   |
|--------------------------|----------------------------------------------------------|
| string                   | `` `text` ``                                             |
| template interpolation   | `` `text ${X}` `` (backtick-interior only)               |
| atom                     | `:foo`                                                   |
| bareword (term ref)      | `NAME` (CAPS) → `term(:NAME)` sub-pipe                   |
| bareword (term bind)     | `NAME?` (CAPS+`?`) → `term_bind(:NAME)` sub-pipe         |
| bareword (atom)          | `lower_case` → `Value::Atom("lower_case")`               |
| op call                  | `op` `?`? `[flow]`? `(args)`? `` `dsl` ``? `{ block }`?  |
| slot adjacency           | no whitespace before `?` / `[` / `(` / `` ` ``           |
| block slot               | `{ … }` may follow whitespace                            |
| pipe                     | `step > step > step`                                     |
| stmt terminator          | `;` (top-level only; sub-pipes in `()` / `{}` omit it)   |
| host parens              | `( pipe )` — flattens inner steps into outer at parse    |
| comment                  | `# …` to EOL                                             |

### Component trait (effect_runtime, sprf-blind)

```rust
pub trait Component: Send + Sync + 'static {
    type Next: Next;
    fn render(...) -> Node<Self::Next>;
    fn render_batch(...) -> Vec<Node<Self::Next>> { … default }
    fn dispatch(...) { … default }
    fn batch_hint(&self) -> Option<usize> { None }

    // introspection (default-empty; sprf descriptors are v4-side)
    fn kind(&self) -> &'static str { type_name::<Self>() }
    fn purity(&self) -> Purity { Purity::Pure }
    fn cache_key(&self, &mut dyn Hasher) -> bool { false }
    fn describe(&self) -> Option<&dyn Any> { None }
}

pub enum Purity { Pure, Read, Effectful }
```

## Author preferences reinforced

- Sprf-specific term/cursor analysis stays v4-side. effect_runtime
  knows nothing about TERMs.
- Component introspection is sata, not closures. `describe() -> &dyn Any`
  matches saga effect descriptors / react devtools `_debugHookType`.
- Compile-time binding-graph diagnostics arrive BEFORE lower-time
  diagnostics in walk_program — the LSP shows both in one pass.
- DSL-internal binders are op-declared, not hardcoded in the analyzer.
  `re`/`glob`/`ast` each scan their own grammar.
