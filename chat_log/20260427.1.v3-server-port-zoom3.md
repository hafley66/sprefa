# v3 server port — zoom 3

Bring back the v2-solved daemon shape. Long-lived `sprefa-server` owns
all runtime state. `sprefa-lsp` collapses to a stdio↔WS proxy. CLI
talks HTTP. Hover gets switchMap-style cancel-and-restart. AstParseEffect
batcher is hoisted to server state so the rayon pool is built once.

Reference shape lives in `v2/src/server/_0..5_*.rs` and
`v2/src/bin/{sprefa_server,sprefa_lsp,sprefa}.rs`. The mechanical port
is below.

## Why

1. v3 hover rebuilds an 8-thread rayon ThreadPool per call inside
   `BoundedWorkSteal::new` (`v3/crates/effect_runtime/src/batchers/bounded_work_steal.rs:44`).
   Drop joins synchronously. After ast/ast_yaml on 413 .rs files, the
   timeout drops the future, the synchronous Drop blocks the tokio
   worker, subsequent hovers stall.
2. Cancellation is not threaded. `pool.spawn(move || f(req))` is
   fire-and-forget on rayon. `Batcher::run` ignores its
   `CancellationToken` arg.
3. No buffer overlay. `DiskFileSource::file_bytes` reads disk only.
   Edits-in-flight are invisible until save.
4. Two LSP processes on the same workspace = two OpCaches, two watcher
   trees, two parses of every file. CLI shares nothing.
5. Architecture for all four points was solved in v2 and lives at
   `v2/src/server/`. The fix is a port, not a redesign.

## Topology after port

```
[ editor ]                          [ shell ]
   │ stdio                              │
   ▼                                    ▼
sprefa-lsp (≈100 LoC dumb proxy)    sprefa-run (HTTP client)
   │ WS                                 │ POST /run, stream SSE
   └──────────► sprefa-server ◄─────────┘
                  │
                  ├── ServerState (one Arc, one runtime, one cache)
                  ├── WorkspaceRegistry (root → WorkspaceCtx)
                  ├── OpCache (long-lived L1)
                  ├── BoundedWorkSteal<AstParseEffect> (ONE pool, 8 threads, lifetime = server)
                  ├── ChangeSubject + watchers
                  └── cancel_root (root token)
```

Discovery file: `$XDG_RUNTIME_DIR/sprefa/server.json` (fallback
`~/.cache/sprefa/server.json`) carrying `{pid, version, http: {unix, tcp}, store_path, log_path}`.

```rust
use std::path::PathBuf;
use std::sync::Arc;
use std::net::SocketAddr;

use tokio::sync::RwLock;
use tokio_util::sync::CancellationToken;
use serde::{Serialize, Deserialize};

use effect_runtime::batchers::BoundedWorkSteal;
use pipeline::effects::{ast_parse, AstParseEffect};
use pipeline::registry::Registry;
use pipeline::{ChangeSubject, OpCache, FsWatcherGuard};

use crate::workspace::WorkspaceRegistry;

pub struct ServerState {
    pub cache:        Arc<OpCache>,
    pub registry:     Registry,
    pub workspaces:   Arc<RwLock<WorkspaceRegistry>>,
    pub subject:      ChangeSubject,
    pub watchers:     Arc<tokio::sync::Mutex<HashMap<(Arc<str>, PathBuf), FsWatcherGuard>>>,

    /// One rayon pool for the life of the process. Lifted out of
    /// per-hover RtCtxBuilder so we stop spinning up 8 OS threads on
    /// every keystroke. `Arc` so RtCtxBuilder::register can take a
    /// `Clone` of the batcher.
    pub ast_parse_batcher: Arc<BoundedWorkSteal<AstParseEffect>>,

    /// Root cancel for shutdown. Per-doc tokens are children.
    pub cancel_root:  CancellationToken,

    /// Drain task draining ChangeSubject → cache.evict_paths.
    pub _drain:       tokio::task::JoinHandle<()>,

    pub info_path:    PathBuf,
}

impl ServerState {
    pub async fn new(opts: &ServerOpts) -> anyhow::Result<Arc<Self>> {
        let cache   = Arc::new(OpCache::new(true));
        let subject = ChangeSubject::new();
        let drain   = pipeline::spawn_invalidator(cache.clone(), &subject);
        let ast_parse_batcher = Arc::new(
            BoundedWorkSteal::<AstParseEffect>::new(256, 8, ast_parse)
        );
        Ok(Arc::new(Self {
            cache,
            registry:    Registry::with_stdlib(),
            workspaces:  Arc::new(RwLock::new(WorkspaceRegistry::default())),
            subject,
            watchers:    Arc::new(tokio::sync::Mutex::new(HashMap::new())),
            ast_parse_batcher,
            cancel_root: CancellationToken::new(),
            _drain:      drain,
            info_path:   opts.info_path.clone().unwrap_or_else(default_info_path),
        }))
    }

    pub async fn shutdown(&self) {
        self.cancel_root.cancel();
        let _ = std::fs::remove_file(&self.info_path);
        self._drain.abort();
    }

    pub async fn ensure_watcher(&self, slug: Arc<str>, root: PathBuf) {
        let canonical = std::fs::canonicalize(&root).unwrap_or(root);
        let key = (slug.clone(), canonical.clone());
        let mut g = self.watchers.lock().await;
        if g.contains_key(&key) { return; }
        if let Ok(w) = pipeline::spawn_fs_watcher(
            slug, canonical.clone(), self.subject.sender(), WATCHER_DEBOUNCE,
        ) {
            g.insert(key, w);
        }
    }
}

    pub info_path: Option<PathBuf>,

    pub fn write_atomic(path: &Path, info: &ServerInfo) -> anyhow::Result<()> {
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        let tmp = path.with_extension("json.tmp");
        std::fs::write(&tmp, serde_json::to_vec_pretty(info)?)?;
        std::fs::rename(&tmp, path)?;
        Ok(())
    }
    pub fn read(path: &Path) -> anyhow::Result<ServerInfo> {
        let bytes = std::fs::read(path)?;
        Ok(serde_json::from_slice(&bytes)?)
    }
}

    if let Ok(p) = std::env::var("SPREFA_SERVER_INFO") { return PathBuf::from(p); }

        return PathBuf::from(h).join(".cache").join("sprefa").join("server.json");
    }
    PathBuf::from("/tmp/sprefa-server.json")
}
```

### workspace.rs

```rust
use std::collections::HashMap;
use std::path::{Path, PathBuf};
use std::sync::Arc;

use pipeline::readers::{DiskFileSource, FileSource};
use crate::buffer_overlay::BufferOverlay;
use crate::config::Config;

pub struct WorkspaceCtx {
    pub root:    PathBuf,
    pub config:  Arc<Config>,
    /// Editor-buffer-aware reader. Same Arc handed to every pipe drain
    /// running under this workspace. Mutated by LSP did_change.
    pub source:  Arc<BufferOverlay<DiskFileSource>>,
    /// Per-workspace cancel; child of ServerState.cancel_root. Tripped
    /// on .sprefa.toml change to invalidate all derived state.
    pub cancel:  tokio_util::sync::CancellationToken,
}

#[derive(Default)]
pub struct WorkspaceRegistry {
    by_root: HashMap<PathBuf, Arc<WorkspaceCtx>>,
}

impl WorkspaceRegistry {
    pub async fn resolve(&mut self, hint: &Path, parent_cancel: &tokio_util::sync::CancellationToken)
        -> Arc<WorkspaceCtx>
    {
        let root = resolve_root(hint);
        if let Some(c) = self.by_root.get(&root) { return c.clone(); }
        let ctx = build_workspace_ctx(&root, parent_cancel.child_token()).await;
        self.by_root.insert(root, ctx.clone());
        ctx
    }
}

fn resolve_root(hint: &Path) -> PathBuf {
    // Walk up looking for `.sprefa.toml` then `.git`. Fall back to hint.
    let mut p = if hint.is_file() { hint.parent().unwrap_or(hint).to_path_buf() } else { hint.to_path_buf() };
    loop {
        if p.join(".sprefa.toml").exists() || p.join(".git").exists() {
            return p;
        }
        match p.parent() { Some(par) => p = par.to_path_buf(), None => return hint.to_path_buf() }
    }
}

async fn build_workspace_ctx(
    root: &Path,
    cancel: tokio_util::sync::CancellationToken,
) -> Arc<WorkspaceCtx> {
    let config = Arc::new(Config::load_from(root).unwrap_or_default());
    let inner: Arc<dyn FileSource> = Arc::new(
        DiskFileSource::new(root.to_path_buf(), Arc::from("wt"))
    );
    let source = Arc::new(BufferOverlay::new(inner));
    Arc::new(WorkspaceCtx { root: root.to_path_buf(), config, source, cancel })
}
```

### buffer_overlay.rs (in `crates/pipeline/src/readers/`)

```rust
use std::collections::HashMap;
use std::path::Path;
use std::sync::{Arc, RwLock};

use crate::readers::FileSource;

/// Wraps any inner FileSource with an in-memory buffer overlay keyed
/// by repo-relative path. LSP did_change populates it; pipes scanning
/// the same paths see the editor buffer instead of disk bytes.
///
/// content_hash is recomputed on overlay write (blake3 of new bytes)
/// so OpCache batch_fingerprint distinguishes overlay from disk
/// without separate keying.
pub struct BufferOverlay<R: FileSource> {
    inner:    Arc<R>,
    overlays: RwLock<HashMap<PathBuf, (Arc<[u8]>, Arc<[u8; 32]>)>>,
}

impl<R: FileSource> BufferOverlay<R> {
    pub fn new(inner: Arc<R>) -> Self {
        Self { inner, overlays: RwLock::new(HashMap::new()) }
    }
    pub fn set(&self, path: PathBuf, bytes: Arc<[u8]>) {
        let hash = Arc::new(*blake3::hash(&bytes).as_bytes());
        self.overlays.write().unwrap().insert(path, (bytes, hash));
    }
    pub fn clear(&self, path: &Path) {
        self.overlays.write().unwrap().remove(path);
    }
}

impl<R: FileSource> FileSource for BufferOverlay<R> {
    fn files(&self, repo: &str, rev: &str) -> Vec<Arc<Path>> {
        // Listing comes from inner; overlays do not invent new paths.
        self.inner.files(repo, rev)
    }
    fn file_bytes(&self, repo: &str, rev: &str, path: &Path) -> Option<Arc<[u8]>> {
        if let Some((b, _)) = self.overlays.read().unwrap().get(path) { return Some(b.clone()); }
        self.inner.file_bytes(repo, rev, path)
    }
    fn file_bytes_with_hash(
        &self, repo: &str, rev: &str, path: &Path,
    ) -> Option<(Arc<[u8]>, Option<Arc<[u8; 32]>>)> {
        if let Some((b, h)) = self.overlays.read().unwrap().get(path) {
            return Some((b.clone(), Some(h.clone())));
        }
        self.inner.file_bytes_with_hash(repo, rev, path)
    }
}
```

### run.rs — the shared primitive

```rust
use std::path::PathBuf;
use std::sync::Arc;

use futures::stream::{self, BoxStream, StreamExt};
use tokio_util::sync::CancellationToken;

use effect_runtime::{RtCtxBuilder, SubjectRegistry, Yield, YieldBatcher};
use pipeline::{Pipeline, _0_cursor::Cursor};
use pipeline::effects::*;
use pipeline::relation_store::{RelationStore, RelationWake, WriteBatcher, WriteEffect};

use crate::state::ServerState;
use crate::workspace::WorkspaceCtx;

pub struct RunRequest {
    pub source:        String,
    pub source_path:   Option<PathBuf>,
    pub workspace_hint: Option<PathBuf>,
    /// Per-request cancel. Drop or trip to abort. For LSP hover, this
    /// is the per-(uri, position) token populated by switchMap.
    pub cancel:        CancellationToken,
}

pub enum RunEvent {
    Meta       { rule_names: Vec<Arc<str>> },
    Cursor     { expr_name: Option<Arc<str>>, cursor: Cursor },
    ExprDone   { expr_name: Option<Arc<str>> },
    Diag       { code: String, severity: Severity, message: String },
    Done,
}

pub struct RunStart {
    pub rule_names: Vec<Arc<str>>,
    pub stream:     BoxStream<'static, RunEvent>,
}

pub async fn run_pipeline(state: Arc<ServerState>, req: RunRequest) -> RunStart {
    // 1. Resolve workspace.
    let hint = req.workspace_hint
        .clone()
        .or_else(|| req.source_path.as_ref().and_then(|p| p.parent().map(|p| p.to_path_buf())))
        .unwrap_or_else(|| std::env::current_dir().unwrap_or_default());
    let ws = state.workspaces.write().await.resolve(&hint, &state.cancel_root).await;

    // 2. Lower .sprf.
    let parsed = sprefa_parse::parse(&req.source);
    let lowered = state.registry.lower_pipes(&parsed);
    let rule_names: Vec<Arc<str>> = lowered.rule_names();

    // 3. Build RtCtx ONCE with the long-lived AstParseEffect batcher.
    //    No rayon pool spin-up here.
    let rel = Arc::new(RelationStore::new());
    let reg = Arc::new(SubjectRegistry::<RelationWake>::new());
    let ctx = RtCtxBuilder::new()
        .with_cancel(req.cancel.clone())              // per-request cancel
        .with_store(rel.clone())
        .with_store(reg.clone())
        .with_store(state.cache.clone())              // long-lived cache
        .register_pure::<FsListFilesEffect, _>(256, FsListFilesBatcher::new(ws.source.clone()))
        .register_pure::<ReadBytesEffect, _>(256, ReadBytesBatcher::new(ws.source.clone()))
        .register::<ReadBytesBatchEffect, _>(ReadBytesBatchBatcher::new(ws.source.clone()))
        // SHARED batcher; clones an Arc, does NOT build a new pool.
        .register_arc::<AstParseEffect, _>(state.ast_parse_batcher.clone())
        .register::<PrintEffect, _>(PrintBatcher::buffer().0)
        .register::<Yield<RelationWake>, _>(YieldBatcher::new(reg.clone()))
        .register::<WriteEffect, _>(WriteBatcher::new(rel, reg.clone()))
        .build();

    // 4. Watchers per seed (lazy, no-op if already running).
    for seed in &ws.config.seeds {
        state.ensure_watcher(Arc::from(seed.slug.as_str()), seed.root.clone()).await;
    }

    // 5. Drain the pipeline into a RunEvent stream.
    let pipeline = Pipeline::Seq(lowered.into_pipelines());
    let upstream = stream::iter(seed_cursors(&ws.config));
    let cursor_stream = pipeline.run(&ctx, Box::pin(upstream));

    let cancel_for_stream = req.cancel.clone();
    let stream: BoxStream<'static, RunEvent> = Box::pin(async_stream::stream! {
        let mut s = cursor_stream;
        loop {
            tokio::select! {
                _ = cancel_for_stream.cancelled() => {
                    yield RunEvent::Done;
                    break;
                }
                next = s.next() => match next {
                    Some(batch) => {
                        for c in batch.iter() {
                            yield RunEvent::Cursor {
                                expr_name: c.path.first_rule_name(),
                                cursor: c.clone(),
                            };
                        }
                    }
                    None => { yield RunEvent::Done; break; }
                }
            }
        }
    });

    RunStart { rule_names, stream }
}

fn seed_cursors(cfg: &Config) -> Vec<Arc<[Cursor]>> { /* one cursor per seed */ }
```

### transport_lsp.rs — WS bridge + Backend

```rust
use std::collections::HashMap;
use std::sync::Arc;

use axum::extract::ws::{Message, WebSocket, WebSocketUpgrade};
use axum::extract::State;
use axum::response::Response;
use futures_util::{SinkExt, StreamExt};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::sync::Mutex;
use tokio_util::sync::CancellationToken;
use tower_lsp::jsonrpc::Result as RpcResult;
use tower_lsp::lsp_types::*;
use tower_lsp::{Client, LanguageServer, LspService, Server};

use crate::session::DocSession;
use crate::state::ServerState;
use crate::run::{run_pipeline, RunRequest, RunEvent};

pub async fn lsp_ws_handler(
    State(state): State<Arc<ServerState>>,
    ws: WebSocketUpgrade,
) -> Response {
    ws.on_upgrade(move |socket| handle_ws(state, socket))
}

async fn handle_ws(state: Arc<ServerState>, ws: WebSocket) {
    let (mut ws_tx, mut ws_rx) = ws.split();
    let (server_io, proxy_io) = tokio::io::duplex(1 << 16);
    let (server_rd, server_wr) = tokio::io::split(server_io);
    let (mut proxy_rd, mut proxy_wr) = tokio::io::split(proxy_io);

    let inbound = tokio::spawn(async move {
        while let Some(Ok(msg)) = ws_rx.next().await {
            let bytes = match msg {
                Message::Binary(b) => b.to_vec(),
                Message::Text(t)   => t.as_bytes().to_vec(),
                Message::Close(_)  => break,
                _ => continue,
            };
            if proxy_wr.write_all(&bytes).await.is_err() { break; }
        }
        let _ = proxy_wr.shutdown().await;
    });
    let outbound = tokio::spawn(async move {
        let mut buf = vec![0u8; 16 << 10];
        loop {
            let n = match proxy_rd.read(&mut buf).await {
                Ok(0) | Err(_) => break,
                Ok(n) => n,
            };
            if ws_tx.send(Message::Binary(buf[..n].to_vec().into())).await.is_err() { break; }
        }
    });

    let (service, socket) = LspService::new(|client| Backend::new(client, state.clone()));
    Server::new(server_rd, server_wr, socket).serve(service).await;
    inbound.abort();
    outbound.abort();
}

struct Backend {
    client:        Client,
    state:         Arc<ServerState>,
    sessions:      Arc<Mutex<HashMap<Url, SessionEntry>>>,
}

struct SessionEntry {
    session:        DocSession,
    workspace_root: Option<PathBuf>,
    /// switchMap: per-(uri, last-position) cancel. Stored under uri so
    /// the next hover on the same doc aborts the previous one.
    in_flight:      HashMap<&'static str, CancellationToken>,
}

impl Backend {
    fn new(client: Client, state: Arc<ServerState>) -> Self {
        Self { client, state, sessions: Arc::new(Mutex::new(HashMap::new())) }
    }
}

#[tower_lsp::async_trait]
impl LanguageServer for Backend {
    async fn initialize(&self, _: InitializeParams) -> RpcResult<InitializeResult> {
        Ok(InitializeResult {
            capabilities: ServerCapabilities {
                text_document_sync: Some(TextDocumentSyncCapability::Kind(TextDocumentSyncKind::FULL)),
                hover_provider:     Some(HoverProviderCapability::Simple(true)),
                completion_provider: Some(CompletionOptions::default()),
                ..Default::default()
            },
            ..Default::default()
        })
    }

    async fn did_open(&self, p: DidOpenTextDocumentParams) {
        let uri = p.text_document.uri.clone();
        self.open_or_replace(&uri, p.text_document.text).await;
        self.publish(&uri).await;
    }

    async fn did_change(&self, p: DidChangeTextDocumentParams) {
        let uri = p.text_document.uri.clone();
        if let Some(change) = p.content_changes.into_iter().last() {
            // Cancel all in-flight requests for this doc; reparse.
            let mut g = self.sessions.lock().await;
            if let Some(entry) = g.get_mut(&uri) {
                for (_, tok) in entry.in_flight.drain() { tok.cancel(); }
            }
            drop(g);

            // Push edit into BufferOverlay so subsequent pipes see new bytes.
            if let Some(path) = uri.to_file_path().ok() {
                let mut ws = self.state.workspaces.write().await;
                let ctx = ws.resolve(&path, &self.state.cancel_root).await;
                ctx.source.set(path.clone(), Arc::from(change.text.clone().into_bytes()));
            }

            self.open_or_replace(&uri, change.text).await;
            self.publish(&uri).await;
        }
    }

    async fn hover(&self, p: HoverParams) -> RpcResult<Option<Hover>> {
        let uri = p.text_document_position_params.text_document.uri;
        let pos = p.text_document_position_params.position;

        // switchMap: cancel previous hover for this URI, install new token.
        let cancel = self.state.cancel_root.child_token();
        {
            let mut g = self.sessions.lock().await;
            let Some(entry) = g.get_mut(&uri) else { return Ok(None); };
            if let Some(prev) = entry.in_flight.remove("hover") {
                prev.cancel();
            }
            entry.in_flight.insert("hover", cancel.clone());
        }

        // Snapshot what we need.
        let snap = {
            let g = self.sessions.lock().await;
            let Some(entry) = g.get(&uri) else { return Ok(None); };
            entry.session.hover_snapshot(pos)
        };

        // Render via shared run primitive (or hover-specific draining
        // primitive that uses the same RtCtx pattern).
        let body = render_enriched_hover_v2(self.state.clone(), snap, cancel.clone()).await;

        // Settle: drop the token slot if still ours.
        {
            let mut g = self.sessions.lock().await;
            if let Some(entry) = g.get_mut(&uri) {
                if entry.in_flight.get("hover").map(|t| t.is_cancelled()).unwrap_or(true) {
                    // We were cancelled mid-flight; let the newer hover own the slot.
                } else {
                    entry.in_flight.remove("hover");
                }
            }
        }

        Ok(body.map(|value| Hover {
            contents: HoverContents::Markup(MarkupContent { kind: MarkupKind::Markdown, value }),
            range: None,
        }))
    }

    // completion / did_save / shutdown unchanged shape
}
```

```rust
use std::convert::Infallible;
use std::sync::Arc;

use axum::{routing::{get, post}, Json, Router};
use axum::extract::State;
use axum::response::sse::{Event, KeepAlive, Sse};
use futures_core::stream::Stream;
use futures_util::StreamExt;
use serde::{Deserialize, Serialize};
use tokio_util::sync::CancellationToken;

use crate::state::ServerState;
use crate::run::{run_pipeline, RunRequest, RunEvent};

pub fn build_router(state: Arc<ServerState>) -> Router {
    Router::new()
        .route("/status",   get(status_handler))
        .route("/run",      post(run_handler))
        .route("/lsp",      get(crate::transport_lsp::lsp_ws_handler))
        .route("/shutdown", post(shutdown_handler))
        .with_state(state)
}

#[derive(Deserialize)]
struct RunDto {
    source:         String,
    source_path:    Option<PathBuf>,
    workspace_hint: Option<PathBuf>,
}

#[derive(Serialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
enum RunFrame {
    Meta     { rule_names: Vec<String> },
    Cursor   { expr_name: Option<String>, cursor: CursorDto },
    ExprDone { expr_name: Option<String> },
    Diag     { code: String, severity: String, message: String },
    Done,
}

async fn run_handler(
    State(state): State<Arc<ServerState>>,
    Json(req):    Json<RunDto>,
) -> Sse<impl Stream<Item = Result<Event, Infallible>>> {
    let cancel = state.cancel_root.child_token();
    let start = run_pipeline(state.clone(), RunRequest {
        source: req.source, source_path: req.source_path,
        workspace_hint: req.workspace_hint, cancel,
    }).await;

    let head = futures_util::stream::once(async move {
        RunFrame::Meta { rule_names: start.rule_names.iter().map(|s| s.to_string()).collect() }
    });
    let body = start.stream.map(run_event_to_frame);
```

```rust
    let cli = Cli::parse();
    init_tracing(&cli);
    let opts = ServerOpts {
        http_unix: if cli.no_unix { None } else { Some(cli.http_unix.unwrap_or_else(default_unix_socket_path)) },
        http_tcp:  if cli.no_tcp  { None } else { Some(cli.http_tcp.unwrap_or_else(|| "127.0.0.1:7417".parse().unwrap())) },
        log_path:  cli.log_path.or_else(|| Some(default_log_path())),
        info_path: cli.info_path.or_else(|| Some(default_info_path())),
        foreground: cli.foreground,
    };
    let state = ServerState::new(&opts).await?;
    let info = ServerInfo {
        pid: std::process::id(),
        version: env!("CARGO_PKG_VERSION").into(),
        started_at: chrono::Utc::now().to_rfc3339(),
        http: HttpInfo { unix: opts.http_unix.clone(), tcp: opts.http_tcp.map(|a| a.to_string()) },
        log_path: opts.log_path.clone(),
    };
    ServerInfo::write_atomic(&state.info_path, &info)?;
```

### bin/sprefa-lsp.rs (rewrite, ~100 LoC)

```rust
use anyhow::{anyhow, Context, Result};
use clap::Parser;
use futures_util::{SinkExt, StreamExt};

use tokio::net::{TcpStream, UnixStream};
use tokio_tungstenite::tungstenite::handshake::client::generate_key;
use tokio_tungstenite::tungstenite::http::Request;
use tokio_tungstenite::tungstenite::protocol::Message;

use server::state::{default_info_path, ServerInfo};

#[derive(Parser)] struct Cli { #[arg(long)] info_path: Option<PathBuf> }

#[tokio::main(flavor = "multi_thread")]
async fn main() -> Result<()> {
    let cli  = Cli::parse();
    let info = ServerInfo::read(&cli.info_path.unwrap_or_else(default_info_path))
        .or_else(|_| {
            // Auto-spawn the daemon if missing.
            spawn_daemon_and_wait()
        })?;

    let req = Request::builder()
        .method("GET").uri("ws://sprefa/lsp")
        .header("host", "sprefa")
        .header("upgrade", "websocket")
        .header("connection", "Upgrade")
        .header("sec-websocket-version", "13")
        .header("sec-websocket-key", generate_key())
        .body(())?;

    let stream: Box<dyn AsyncIo> = if let Some(sock) = &info.http.unix {
        match UnixStream::connect(sock).await {
            Ok(s)  => Box::new(s),
            Err(_) => Box::new(TcpStream::connect(info.http.tcp.as_ref().ok_or_else(|| anyhow!("no tcp"))?).await?),
        }
    } else {
        Box::new(TcpStream::connect(info.http.tcp.as_ref().unwrap()).await?)
    };

    let (ws, _) = tokio_tungstenite::client_async(req, stream).await?;
    let (mut tx, mut rx) = ws.split();

    let inbound = tokio::spawn(async move {
        let mut stdin = tokio::io::stdin();
        let mut buf = vec![0u8; 16 << 10];
        loop {
            let n = match stdin.read(&mut buf).await { Ok(0) | Err(_) => break, Ok(n) => n };
            if tx.send(Message::Binary(buf[..n].to_vec().into())).await.is_err() { break; }
        }
    });
    let mut stdout = tokio::io::stdout();
    while let Some(Ok(msg)) = rx.next().await {
        match msg {
            Message::Binary(b) => { stdout.write_all(&b).await?; stdout.flush().await?; }
            Message::Text(t)   => { stdout.write_all(t.as_bytes()).await?; stdout.flush().await?; }
            Message::Close(_)  => break,
            _ => {}
        }
    }
    inbound.abort();
    Ok(())
}
```

## Cancellation thread (the switchMap part)

```
state.cancel_root  ─┬─►  ws.cancel             (per-workspace; tripped on .sprefa.toml change)
                    ├─►  per-doc tokens         (tripped on did_change)
                    └─►  per-request tokens     (tripped by switchMap on next hover)

RunRequest.cancel  ─►  ctx.cancel (RtCtx)  ─►  Batcher::run(req, cancel_token)
                                              └─►  tokio::select! { f(req), cancel.cancelled() }
```

`BoundedWorkSteal::run` must be patched to honour the cancel token it
already takes:

```rust
impl<E: EffectKind> Batcher<E> for BoundedWorkSteal<E> {
    fn run(&self, req: E, cancel: CancellationToken) -> BoxFuture<'static, E::Response> {
        let tx = self.tx.clone();
        let (rtx, rrx) = oneshot::channel();
        Box::pin(async move {
            tokio::select! {
                _ = cancel.cancelled() => E::Response::default_cancelled(),
                send = tx.send((req, rtx)) => {
                    send.expect("drainer gone");
                    tokio::select! {
                        _ = cancel.cancelled() => E::Response::default_cancelled(),
                        r = rrx => r.expect("reply dropped"),
                    }
                }
            }
        })
    }
}
```

The rayon side cooperates by checking `cancel.is_cancelled()` at the
top of the work closure. AstParseEffect already returns `Option<_>`, so
None is the cancelled value:

```rust
pool_for_drainer.spawn(move || {
    let out = if cancel_clone.is_cancelled() { None } else { Some(f(req)) };
    let _ = reply.send(out.unwrap_or_default());
```

## OpCache + buffer overlay coherence

`batch_fingerprint` already hashes `c.content_hash`. BufferOverlay
returns a fresh blake3 hash on `set`, so cursors flowing through pipes
that read overlaid bytes get a different content_hash than disk-read
cursors. Cache key composes that fingerprint with `op.cache_key` →
overlay edits and disk reads are distinct cache entries automatically.
Watcher invalidation continues to evict by `(repo, rev, path)`; on
`did_save` the overlay is cleared (LSP client sends `didSave`) and
disk read resumes.

## Migration order (single PR or 4 small PRs)

1. **Add `BufferOverlay` to `crates/pipeline/src/readers/`** + tests.
2. **Add `state.rs`, `workspace.rs`, `run.rs`** to `crates/server/`. No
   transports yet. Backend keeps stdio path but uses ServerState.
3. **Lift `BoundedWorkSteal<AstParseEffect>` onto ServerState.**
   `RtCtxBuilder::register_arc` (new) takes `Arc<B: Batcher>` instead
   of moving an owned `B`. Hover stops spinning up the pool per call.
   Standalone fix; ships even before transports land.
4. **Add `transport_lsp.rs` + `transport_http.rs` + `bin/sprefa-server.rs`.**
   Daemon now serves WS + SSE + status + shutdown.
5. **Rewrite `bin/sprefa-lsp.rs` as the WS proxy.** stdio → daemon WS.
6. **Rewrite `bin/sprefa-run.rs` as the HTTP client.** Auto-spawn daemon.
7. **Wire switchMap on hover.** Per-(uri, "hover") cancel token in
   SessionEntry.in_flight; new hover cancels prior; threaded into
   RunRequest.cancel.

Step 3 alone removes the symptom the user saw (post-ast hover hang).
Steps 1, 4-6 deliver the architecture promise. Step 7 polishes UX.
