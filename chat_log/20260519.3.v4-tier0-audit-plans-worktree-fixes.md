## Solution/Approach
Item 1 fix (already applied in worktree):
- Threaded `reg: &Registry` into `record_binders` (`binding_graph.rs:901`) and `build_body_graph` (`binding_graph.rs:779`).
- Replaced the hardcoded `op_cursor_binds(name)` helper call with `reg.get(op.name.as_ref()).map(|d| d.cursor_binds()...)`.
- Deleted `op_cursor_binds` helper function.
- Kept `cursor_bind_lattice` (small enough not to be worth lifting onto OperatorDef in this PR) but removed the dead `("ast","FILE") => FileId` arm and added a TODO comment.

Item 4 plan (next): change `cursor_codec::decode` at lines 130-133 from silent `terms.insert(0, Term::focal())` to `return Err("focal term missing")`. All callers already handle Err (`.ok()?` or pre-existing `expect`). The pre-existing `expect("valid cursor codec bytes")` in `runtime_bridge.rs:30` is a separate Tier-1 panic not in scope here.

Item 2 plan: `v3/effect_runtime/src/v2/fact_store.rs:1118-1156` multi-row `INSERT OR IGNORE` extends `accepted` with ALL chunk ids when `changed > 0`. Fix: either insert one-by-one in a tx, or use `INSERT OR IGNORE ... RETURNING id` (rusqlite supports it on bundled sqlite ≥ 3.35), or pre-check existence per row.

Item 3 plan: surgical fix swaps `OnceLock<SourceIndex>` for `DashMap<PathBuf, Arc<SourceIndex>>` keyed by `git rev-parse --show-toplevel`. See `plans/2026-05-19-clock-seam-invariants-plan.md` §8 for details. Bigger than items 1/2/4.

Item 5 plan: make `stratify::stratify` return `StratifyResult { strata, recursive_rules: BTreeSet<Arc<str>> }`; fuser at `:689-693` consumes `recursive_rules.contains(rule_name)` instead of `joined_tables.contains(self_facts)`. Stratify currently runs only when `!rec.is_empty()` at `app.rs:1771`; needs to run before fuser for the new oracle.
