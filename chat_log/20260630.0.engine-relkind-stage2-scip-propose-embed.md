## Solution/Approach
- Added ONE defaulted trait method `dirty(&self, changed: &HashSet<String>) -> bool`
  (default true). ScipKind overrides to `changed.contains("index.scip")` so a
  source edit never forces a full SCIP index reload. Full tick ignores dirty()
  (always reloads). tick_paths registry loop became
  `if k.used(prog) && k.dirty(&seen) && k.refresh(self)?`. `seen` is the set of
  repo-relative changed paths already built in the tick_paths change loop.
- DECISION: RelCtx borrow-struct DEFERRED. The proposal recommended a RelCtx seam,
  but it's encapsulation tightening, not needed for the line move. Kept the
  existing `refresh(&self, eng: &Engine)` shape (consistent w/ Stages 0/1) and
  widened 5 helpers to pub(crate): repo_roots, node_file_set, read_content,
  knn_rows, scip_descriptor_name. RelCtx folds into Stage 3/4.
- Moved 4 refresh bodies + refresh_similar_rel helper whole into relkind.rs as
  ScipKind/ProposeExtractKind/ProposeCloneKind/EmbedKind (s/self/eng/, free fns
  qualified crate::engine::X). Added them to rel_kinds() registry (appended after
  Catalog). knn_rows STAYS in engine.rs (node2vec also uses it) as pub(crate).
- Removed from engine.rs: SCIP_RELS/EMBED_RELS/PROPOSE_*_RELS consts, 4
  *_rel_decls fns, 4 *_rels_used gates, the 4 refresh methods + refresh_similar_rel,
  tick/tick_paths dispatch lines, all_builtin_decls/declare_builtins chains,
  reserved-name-guard branches.

## Key Insights
- A full `tick` refreshes every used family unconditionally; `dirty()` is consulted
  ONLY by incremental `tick_paths`. That split is why scip's reload-gate is one
  defaulted method, not a signature change.
- `seen` (the changed-path set in tick_paths) was already built for dedup; reused
  it for dirty() — no new plumbing, just pass &seen.
- RelCtx is NOT a prerequisite for moving bodies out: the existing impls already
  reach db/root/refresh_rel (pub(crate)); 5 more pub(crate) helpers finished the
  job. RelCtx = bounding the surface, a Stage 3/4 nicety.
- coupling-metrics.dl needs `--root .` from v5/ (its scan path is "src/engine.rs");
  without it, 0 files parse. Gauge reads the source file, so you can stash changes
  and re-run with the SAME binary to get a clean before/after (no rebuild).
- N+1 invariant held: every refresh stays collect-then-flush via refresh_rel /
  insert_rows. Auto-doc rail (rel_catalog/fn_catalog undocumented_* tests) green.
