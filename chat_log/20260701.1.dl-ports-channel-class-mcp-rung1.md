## Solution/Approach
FINAL DESIGN (Chris sold):
- Ports = user-named rels with decl qualifiers `@in(class)` / `@out(class)`,
  riding the key(...)/merge(...) decl-qualifier seam from the lattice commit.
- class = the contract the port ABIDES BY, transport NEVER in .dl:
  rpc (Promise: @in envelope id/method/params, @out id/result, one reply per id
  closes), stream (Observable: many rows per id, needs complete sentinel),
  duplex (WS, later). Class checks envelope at declare time; codec encodes a
  class; wire moves bytes.
- Binding = CLI profile: --mcp = rpc ports -> stdio x jsonrpc. Later
  --bind rpc=http:jsonrpc. Named instances @in(rpc: api) DEFERRED until a
  program needs two wires of one class. Bail loudly on ambiguity.
- Drain law 1 for rung 1: every answered @in row is retired (consumption);
  law 2 (digest sent-log generalizing pending_effect) later — additive.
- Completion: (b) quiescence KILLED (Rx never infers completion from silence);
  (a) producer-complete sentinel and (c) consumer-gone are DISTINCT signals,
  both eventually needed; rpc rung needs only (c). Errors = payload convention
  for rpc; named divergence for stream rungs.
- Mercury conflict dissolved: dl's mode surface is the ?-family (sigils), never
  in/out words; port-@in vs mode-in even point opposite directions — modes stay
  in ?, noted in doc.
- VecDeque in-proc wire = permanent test transport, first artifact.

## Key Insights
- Axis 1 = monotone lattice fixpoint within a tick (key/merge, closure, strata);
  axis 2 = boundary between ticks where ALL non-monotone ops live (inject,
  drain, carry, retract). SIGIL LAW: @ marks axis 2, bare decl qualifiers mark
  axis 1. Semantics-doc chapter structure = lattice / boundary / types / self.
- @next/@async ARE Dedalus's two primitives (proven sufficient, CALM). dl =
  single-node projection of Dedalus + code-facts front end + SECOND CLOCK (rev,
  git history — Dedalus has one) + lattices + effects + incremental + one-binary
  SQLite deployment. Distribution = the missing Dedalus half; address column
  reserves the seat. Positioning: "Dedalus timing, applied to code, made
  incremental, welded to SQLite."
- @async = @out compose @in with pending_effect as the heap-allocated coroutine
  frame (JS: yield+promise+magic === async/await, built roof-first). Suspension
  is a rel because there is no stack.
- Resend trap: an @out rel derived from PERSISTENT state re-fires after every
  rebuild (rebuild_derived recomputes; drain deletes). Law 1 = consumption ties
  @out to retired @in rows; law 2 = digest sent-log. Transient retention is
  where a future type system says it.
- RWS frame: @in=Reader, @out=Writer, @next=State over tx (tighter than Elm
  Cmd/Sub — Elm lacks the State leg).
- Innovation seats (vs "just Dedalus in Rust"): (1) TYPE THE BOUNDARY — gradual
  Blazes: monotone / crosses-stage / needs-idempotence as checked qualifiers
  (the engine's 6 scattered bails + recompute rail ARE this system, dynamic);
  (2) two-clock bitemporal typing (rel varies along tx vs rev vs both).
- Types plan: Soufflé column floor (ADTs/newtypes/exhaustiveness) + Datafun
  monotonicity mortar + Mercury modes/determinism grafted on ? (key() already
  = det per key) + Flix's rule-sets-as-first-class-values for mounting typed
  handlers on ports. Refuse HM/typeclasses/laziness.
- Lisp lens: modifiers = combinators, idioms = macros; @ = quasiquote over time
  (pending_effect.args_json is literally a quoted call as data). Stealable:
  internal IR as shift-compose-address-compose-retain algebra so new surface
  forms are lowerings, not new Temporal variants; doc defines @in/@out AS
  expansions.
