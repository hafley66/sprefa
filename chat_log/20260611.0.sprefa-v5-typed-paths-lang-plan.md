## Solution/Approach
THE DESIGN (settled across turns):

1. Typed literals `scheme:body`, one escape rule (`${` only, v4 dsl_body rule). Anchors per scheme at top of file (`anchor ~ = fs:repo(v5)/src`), Nix parse-site resolution.
2. ONE value type: Vec<Desc>, Desc{text, kind}, DescKind = Namespace|Type|Term|Method|Param|Index(u64)|Dir|File|Hole(Named|Star|Globstar). SCIP-compatible descriptor grammar (name/ name# name. name(). (name) [name] name: name!) + dl extensions (Index, Dir/File, Hole). Zero holes = value; holes = pattern; pattern match = unification = join. Generalizes =~ and ~~ (ac92530).
3. Path-like schemes = data-driven SchemeSpec table rows (sep/idx/hole syntax), ONE generic lexer: rs, dot, fs, url, pkg, sql. Matchers (re, sg, css) stay opaque matcher ops with real parsers -- NOT paths.
4. xlate hub-and-spoke: renderings (parse_a -> Vec<Desc> -> render_b, pure, free) vs resolvers (fs<->rs needs crate roots = rspath.rs; pkg<->fs = modgraph TS resolver). Only 2 resolvers, both already written. --move gets a spec: rewrite refs whose rs-rendering crosses the fs move.
5. at(EdgeRel, Start, PathPattern, End) = LOWERING not engine: dot:a.b.c -> self-joins; glob:** -> closure() (SCC-cached). `**` walk-binding = SIMPLE PATHS: trail caps itself on revisiting its own nodes (user's call). Loud row counter (N+1-screamer style) when at() materializes >N rows, never silent truncate.
6. Access paths vs walks: generated walk (potential, from at()) vs extracted access fact (actual, one row per a.b.c expression in source, finite by construction, no cycle problem). Both land in dot: space -> join: step(a,b) from access chains; phantom(f,t) <- type_edge ∧ !step; cold(x) <- at(**) ∧ !step.
7. Storage: canonical rendered text in SQLite + brand/scheme in RelMeta. No migration. SCIP-canonical text means native facts ⋈ scip_def/scip_ref/scip_edge directly (RA oracle becomes runtime join). Tax: extension segments need stripping on SCIP export.
8. Agg: head-position fan_out(f, count(t)) <- ..., lowers to GROUP BY; Count/Sum->Int, Min/Max->arg type; stratify() over existing dep graph (agg/neg edge inside SCC = TypeDiag).
9. Type checking at lower time: check_rule_types unifies var types across atoms; brand mismatch = error; TypeDiag -> diag publish path (LSP squiggles for free). Extraction drops become diag rows (kills silent [checked-type] counter).
10. Spine lever (visible, not pulled): refresh_spine_rels_delta(Option<&SpineDelta>), SpineDelta{strings_added, spans_added, retracted_paths}; None = today's wholesale load (engine.rs:1449-1457 reads _strings whole -- the only RSS scaler). Staged vecs already exist per tick; lever = thread them. v4 saga collect-then-flush shape. Souffle's global RAM intern table = named anti-pattern.
