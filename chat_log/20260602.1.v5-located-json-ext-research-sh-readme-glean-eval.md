## Key Insights
- Located json() is the linchpin: json values were span-LESS (serde discards
  offsets); now they join ref so LSP can squiggle the exact info.version token and
  the edit sink can rewrite it. Without it the openapi-drift warning couldn't point
  at a line.
- "Version lives in git tags, not in source" is a NON-problem for sprefa: it keys on
  (repo,path,rev) + content-hash; rev IS the tag. Drift = content-hash/version
  cross-repo join. The chain (spec-ver -> N libs -> L lib-versions) dissolves.
- Two SEPARATE seams: backend (RelStore, model on Cozo's Storage trait, copy SHAPE
  not the crate) and incremental-retraction (stays hand-rolled over SQLite; DBSP is
  the only library with the math but loses SQLite spill = wrong at 500-repo scale).
  petgraph is an orthogonal small cleanup, not a seam.
- "LSP made easy" frameworks make it easy by TAKING THE LOOP AWAY (async) — exactly
  the labyrinth for sprefa. lsp-server gives the loop back (sync channels) = the
  genuinely-easy-for-sprefa answer. Already wired.
- The v4 lsp/http/cli splitter Chris liked = a Transport trait over ONE sync tick:
  insert request fact -> one inline tick -> read answer facts -> retract. HTTP/
  ghcache are just more Transport impls. NOT v4's async HTTP-event-parked-queue.
- DSL string ops are a modicum: ${} concat, = != < <= > >= =~ ~~, regex CAPTURE over
  FILES (match). GAPS: no string ops on a BOUND value (match only reads files); < is
  LEXICAL not semver (so detect DRIFT != , not DIRECTION/older); NO aggregation
  (count/sum/min/max) — the #1 general hole; Value=Text|Int (no float).
- Honest Glean eval: Glean (Meta, Haskell, Angle, RocksDB, BATCH snapshot-at-rev,
  compiler-grade indexers, billions of facts) STRICTLY beats sprefa on precision/
  scale/query-maturity/hardening. sprefa wins ONLY on reactivity+retraction, the
  located refactor spine, and laptop/tree-sitter cost — and Glean isn't trying to do
  those. Verdict: shouldn't have used Glean (wrong model) but should have ASSEMBLED
  (Cozo+SCIP+lsp-server) rather than hand-rolled everything — EXCEPT the reactive-
  retraction core, which no library provides and was worth hand-rolling.
