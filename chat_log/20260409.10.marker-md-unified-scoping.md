## Key Design Decisions

### md() patterns
| Pattern | Matches |
|---|---|
| md(# $TITLE) | h1 heading |
| md(## $TITLE) | h2 heading |
| md(```$LANG) | fenced code block open |
| md(```$LANG { $BODY }) | code block with content |
| md(- $ITEM) | unordered list item |
| md(> $TEXT) | blockquote |
| md([$TEXT]($URL)) | link |
| md(![$ALT]($URL)) | image |
| md(\|$ROW\|) | table row |

### md() scoping via headings
Headings are natural markers. md(## X) narrows byte range to that section (until next h2 or EOF). Heading depth controls nesting. Enables: `md(## Selector tags) > md(| `$TAG` |)` to extract table rows under a specific heading.

### Unified tag scoping architecture
Current: 4 separate output channels (SelectStep, AstSelector, LineMatcher, MarkerScope). Proposed: recursive chain evaluator where intermediate tags produce byte ranges and terminal tags produce captures. ~580 line refactor. json() stays special-cased (operates on parsed Value, not bytes).

### file() demand scanning
Parallel to repo()/rev() scanning. `json({ extends: file($BASE) })` marks $BASE as a file path scan annotation. Demand scanner resolves relative to source file, adds to scan queue. Enables recursive tsconfig chain discovery. ~30 lines in scan coordinator.

### Cross-ref as capture-time composition
For drift detection (OpenAPI specs across repos): rule A extracts canonical version, rule B cross-refs A and extracts local version. Both values land in same row at extraction time. Check just filters WHERE version != source_version. Already works with current syntax.
