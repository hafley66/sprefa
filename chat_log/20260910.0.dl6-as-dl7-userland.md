## Evidence and Corrections
- intern/3 yields ref(application(Constructor,Arguments)), no durable integer ID.
- Existing Option/Partial/Key use userland constructor rules; edge_snapshot reads
  owner/label/target/position. An Interned(text TYPE) annotation is the current aim.
- Key/composite_key metadata is not enforced and no output relation can mutate
  checked KeySets. Return conventions and fixed kernel keys provide those today.
- Existing storage_* rows describe fields/dictionaries/dependencies/projections
  and identity domains. Runtime allocation remains absent from this library.
- Scalar fallback can double-claim a new wrapper; exact one-row-per-field tests
  are required. Existing policy-wide text dictionaries must remain unchanged.
- Authored plain-label application target uses deferred expressions; compound
  Key label plus application target follows a different path. Named alias remedy
  is untested and needs an exact fixture; do not change lowerer speculatively.
- Compiler removes edge_snapshot/intern_snapshot before published closure.
  README describes an unsliced emitter problem and storage test uses a sliced
  runtime. However emit_compiled also seeds already-derived CompilerFacts, so
  reproduce exact behavior before declaring emission impossible.
- Logical occurrence : rows repeat body/argument labels, conflicting with : key
  (owner,label). Any graph/phase repair requires review, not a silent workaround.
