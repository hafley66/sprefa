## Design locks (from lockfile section 19)

- 6 concepts: Op, Rule, Pipeline, Cursor, Capture, Scalar
- 4 Pipeline cases: Op, Chain, Group, Fork
- 5 EntityRef cases: Scalar, Op, Pipeline, Rule, Capture
- 6 Cursor fields: path, content, byte_range, slots, captures, parent
- 3 sigils: `$`, `&`, carveouts `${...}` / `&{...}`
- 6 invariants: ops-own-everything, cursor-is-flow, content-contract,
  reads-pipe/writes-deferred, reparse-cancel, cursor-has-path
- 4 persistence tiers: capture, evidence, relations, violations
- 3 diagnostic phases: parse, lower, run
- 5 binding sources: param, walker-body, chain-stage, fork-arm,
  parametric-call
- 4 Pipeline run policies: Cold, Shared, Memo (+ op-local)
- 4 min-viable op trait slots: name, parse, pipe, capture-kind

## Design arc (summary of the session)

| topic | locked |
|---|---|
| `${...}` semantics | host-expr carveout, general expr hole; rename-in-carveout retired |
| capture bind | `> $NAME` chain station as ordinary op |
| xref / semijoin | filter-semijoin default for TermOp standalone |
| cross-rule ref | `rule.$V` as chain-startable op; `$$` scan sigils retired |
| registry access | op-mediated via parametric call with unbound (no `&&`) |
| rule = Pipeline | single keyword; zero-param = sourced, N-param = parametric reusable |
| no `op` keyword | parametric `rule(name, $T*)` covers |
| no shadowing | lock for now; cross-scope open |
| arg-mode dispatch | per op via `ArgSpec + TermMode + OpAction` |
| rule mode | derived from body ops' ArgSpec by default |
| term annotation grammar | reserved exploration lane (Section 14) |
| control flow | fork + filter + recursion + higher-order control ops |
| recursion | `@recursive(max_depth=N)` opt-in; Tarjan cycle detect |
| laziness | Cold by default; Shared for named rules; Memo explicit |
| mutations | four optional slots: preview, reversible, reverse, source_range |
| runtime | mergeByKey over (rule_path, term_path); differential-dataflow shape |
| dagging | StageDeps; evaluate-up-to-block; sprfpath completes when args bound |
| cursor shape | Shape C — content+byte_range struct fields; fs/repo/rev in slots |
| cursor path | always present, never Option; anon pipelines hash-named |
| prolog encroachment | shallow — mode + per-call dispatch only; no SLD, no backtrack |

## Decisions discarded (historical trail)

- `$$repo($R)` / `$$rev($T)` scan sigil class → tag-op family
- `&&.rules` registry sigil → op-mediated registry iteration
- separate `op` keyword → parametric `rule`
- `${rule.$V > $NEW}` rename via `>` inside carveout → capture-write station
- `$NAME` vs `${NAME}` duality → `$NAME` canonical, `${...}` is carveout
- separate Rule runtime → Rule is named Pipeline
- norm as syntax → `is_repo_norm(...)` tag-op
- bash-style `>&N` redirects → capture-write + prolog mode

## Min-prototype pivot — next session angle

Goal: exercise the core algorithm in the smallest possible Rust code
that runs a v3-shaped `.sprf` program end-to-end. No plugins, no op
registry ceremony, no LSP, no SQLite, no tag-ops, no link-ops, no
higher-order control ops, no mutations. Retrofit those into proper
plugin surface in a follow-up.

### What to include in the prototype

1. **Host parser** — tree-sitter-sprefa or a hand-rolled chumsky/pest
   parser for the outer grammar. Must parse: `rule(name, $T*)`, chain
   (`>`), fork (`{ ... }`), group `(...)`, op-call with `(args)` and
   `{ body }`, `$TERM`, `${...}`, `&.path`, `&{addr}`, atoms,
   strings, numbers.
2. **Sub-grammar injection driver** — one `Parser` instance, swap
   Language per op_call, `set_included_ranges` per slot range.
   Re-parse each slot. Carveout pre-pass (balanced `${...}`, `&{...}`).
3. **Env + resolver** — build scopes from rule decls (hoisting pass),
   walk tree resolving name references to `EntityRef`. Compute
   `BindingGraph` (statically-unresolvable check) and `StageDeps`
   (per-stage reads/writes).
4. **Four Pipeline cases** — Op, Chain, Group, Fork. One `.pipe(ctx,
   input) -> stream` implementation each.
5. **Cursor struct Shape C** — path, content, byte_range, slots,
   captures, parent.
6. **Two built-in ops minimum** — enough to exercise the plumbing:
    - `fs(glob)` — reads files, emits cursors with content + byte_range.
    - `re(pattern)` — regex match; emits cursor per match with
      captured groups bound.
7. **Third built-in op** — `rule` itself, as the declaration form.
   Registers the name; parametric form wires arg binding.
8. **Arg-mode dispatch harness** — resolve `TermMode` per arg on each
   cursor; pass `Vec<TermMode>` to op's dispatch callback.
9. **In-memory Store** — `HashMap<SprfPath, Vec<Row>>`. No SQLite.
   Each emitted cursor becomes a row keyed by sprfpath + captures.
10. **Subscriber** — `main()` runs a hardcoded .sprf, subscribes
    each top-level rule, drains output streams, prints rows.

### What to defer to retrofit phase

| deferred | why |
|---|---|
| Op registry via inventory + per-op folders | prototype hardcodes two ops inline |
| LSP | prototype has no editor surface; CLI only |
| SQLite persistence | in-memory HashMap is enough to validate algorithm |
| Tag-op + link-op families | prototype proves core pipe without relations tier |
| Higher-order control ops | demonstrate mechanism with hand-composed fork + filter |
| Mutation effects + approval | read-only prototype |
| `@recursive` attribute + Tarjan cycle detection | reject all self-refs in prototype |
| Term annotation grammar (Section 14) | prototype uses bare `$TERM` only |
| Evidence tables | prototype emits to stdout, not persistent |
| Subscribe policy Shared/Memo | Cold-only suffices for validation |
| Reparse + cancellation | run-to-completion only |
| `sh` op and its double-brace escape | no shell needed |
| Shadowing policy | reject duplicates bluntly |
| Anonymous pipeline hash-naming | use source position for now |
| Check / assert / witness | SQL-tier deferred |

### Prototype exit criteria

Run a small `.sprf` program with these features and produce correct
output:

```sprf
rule(files) > fs(r"examples/**/*.txt")

rule(todos, $LINE) > re(r"TODO: (.*)")

rule(audit) {
  > files
  > todos($TEXT)
}
```

Expected run:

1. `files` subscribes, emits one cursor per matching file.
2. `audit` subscribes, subscribes `files` first (chain stage 1 binds
   fs/byte_range), then calls `todos($TEXT)` with `$TEXT` unbound
   (producer mode).
3. `todos` runs regex per incoming file cursor, emits cursor per
   match with `$TEXT` bound.
4. Output: list of (file, line_match, TEXT) tuples.

Validates:
- tree-sitter host parse + sub-grammar injection
- carveout scanning (not used in this minimal example, but no
  parse errors)
- env build + resolver
- parametric rule call-site binding
- arg-mode dispatch (producer mode when term unbound)
- four Pipeline cases (Op, Chain — Fork/Group not in this example)
- Shape C cursor with content + byte_range narrowing
- in-memory Store

### Files the prototype creates (estimated)

One Rust crate, minimal layout:

```
v3/experiments/lang_prototype/
  Cargo.toml
  src/
    main.rs                  # entry + hardcoded .sprf runner
    parse.rs                 # tree-sitter host parse + sub-grammar injection
    resolve.rs               # env + resolver + BindingGraph + StageDeps
    lower.rs                 # AST → Pipeline
    runtime.rs               # Pipeline::pipe dispatch over cursor streams
    cursor.rs                # Cursor struct + SprfPath + captures
    ops/
      fs.rs                  # fs(glob) op
      re.rs                  # re(pattern) op
      rule.rs                # rule() declaration op
    store.rs                 # in-memory HashMap<SprfPath, Vec<Row>>
  tests/
    smoke.rs                 # exit-criteria program runs green
```

LoC target: under 1500. If it grows past 3000, something's wrong and a
concept is leaking from the deferred list into the prototype.

## Key insights

- **Six concepts, three sigils, six invariants.** Surface at its
  minimum. Further collapse not free (would fuse distinct concerns).
- **Rule is a named Pipeline with optional params.** `op` keyword
  redundant once parametric rules land. `rule(name, $T*)` covers
  everything the earlier `op(name, args)` proposal did.
- **Arg-mode dispatch derives from body.** Users rarely need to
  annotate modes. The derived constraint propagates to call sites,
  resolver diags on mismatch.
- **Term-annotation grammar is a real lane, reserved intentionally.**
  Not locked. When it lands, tag-op and link-op families may shrink.
- **Prolog encroachment is shallow.** Mode per arg + per-call dispatch.
  SLD, backtrack, cut, negation-as-failure not on the road.
- **Runtime is mergeByKey on (rule_path, term_path).** Differential
  dataflow vocabulary. rxjs intuition carries over directly.
- **Prototype strips plugins, keeps algorithm.** Chumsky + in-memory
  Store + two hardcoded ops + env/resolver/pipeline enum. Under
  1500 LoC target. Retrofit path is additive.
