## Key Insights
- BraceMode::Forbidden was a modeling mistake; all cursor-scoping ops (repo/rev/fs) legitimately accept braces as fork arms
- User picked V1 leading-`>` arm marker, TS-style discriminated union. `;` required to terminate each arm; intra-arm `>` remains Seq. Position-sensitive disambiguation (after `{` or `;` = arm-start, else = Seq).
- T6 produces Pipeline::Seq([Op(X), Fork(arms)]) wrapping. Any code that resolves paths through the pipeline tree must know this convention.
- Span builder's op_path appends (fork_idx, op_idx) per brace recursion level → path length = 2 + 2 * nesting_depth.
- Analysis span builder's brace recursion: try host_parse_arm_brace first; on Err, fall back to scan_paren_tokens for walker-DSL bodies. Never do both — duplicate Captures reroute hover to outer op.
- LSP hover dispatches via min-by-range smallest span, so duplicate spans at same range break routing silently.
