## Key Insights
- Discriminant = leading `sprf://` URI segment; path-pattern-match recovers it, no constructors/ADT needed.
- SQL "no explicit tables": rules ARE relations synthesized per body (`create_table_sql` fuser.rs:404), JOIN ON shared capture name (Datalog unification), name resolved via one `rule_decls` registry + scope table.
- owner = from_node, source = to_node on subscribe edge (`Subscribe::apply` runtime_graph.rs:344). Structural arrow from→to (owner depends on source); wake/dataflow flows to→from (opposite).
- owner = rule-body instantiation keyed by `owner_uri(ast_uri,parent_owner_uri,input_key,source_hash,mode)` (runtime_graph.rs:1338). source = `sprf://source/...` input. An owner's output table becomes the next owner's source → chains/fixpoint/recursion.
- bind = write/capture half; `?` marker (InterpMode::Bind op_def.rs:75); runtime writes CursorTerm; compile-time = CaptureInfo node. Shared bind name = JOIN key.
- CaptureInfo: binding_site (born), read_sites+ReadCtx (used where/how; Predicate→pushdown, RuleCall→join), value_lattice (TypeLattice tightens by join/meet → column type/FK), fanout (Dead→elim / Once / Many).
- Reactive loop: apply⊢rows; source change⊢dispatch_wake⊢DirtyOwner; DirtyOwner+TraversalOrder⊢sweep; sweep+RuntimeContinuation⊢re-run; re-run⊢VisibleDelta ∧ maybe more dirty; no dirty⊢quiescent else QuiescenceError::IterationCap.
- The naming rule that holds: name from role in the type signature, not a register-matched synonym.
