## Key Insights
- **All 171 emit_rust diffs are ONE failure.** 171/171 are the oracle's line
  MISSING from rust output; ZERO wrong lines, ZERO extra lines; 163/171 diverge
  at tick 1. The engine produces nothing, never a wrong answer. The previous
  lane's cause column records the raw line so all 171 are unique strings and
  nothing groups.
- **emit_rust went 103 -> 109 clean but 122 runtime-errors -> 0.** Every crash
  eliminated; only 6 became correct.
- **`.dl6` can already write its own emitter.** PROBED rc=0: `sh` host decl
  writes files, `concat([...])` builds strings, `group_concat(Line,"\n",Ord)`
  assembles a file body, and the alloy-js refkey problem is a 3-way join with
  `TargetFile != FromFile`. Missing: a split/substr primitive. Fixture
  `ordered_fragment_line_assembly.dl6` already exists.
- **`rel` is already overloaded 5 ways.** PROBED: `rel point(x:int,y:int).
  rel line(a: point, b: point).` compiles rc=0 and emits `"a" INTEGER, "b"
  INTEGER` - a rel used as a column type is a foreign key to `__id`,
  surrogate-key law applied automatically.
- **An enum is a closed sum declared at the type; an interface is the same graph
  declared from the other end.** Enum emits `body_tag`; an interface would emit
  `addressable_tag(id, which_rel)`. Same lowering, open variant set.
- **Conformance is a SECOND link kind.** `.dl6` has exactly one written
  rel-to-rel link today (has-a, a rel-typed column). `is-a` needs its own
  spelling; `<-` is the rule arrow.
- **Three levels**: L0 interface+conformance needs NO generics; L1 generic rels;
  L2 generic interfaces needs both. The user's chicken-and-egg dissolves because
  L0 is independent. There is NO impl block; that is a Rust habit.
- **Curry parses without lookahead**: the first paren group is type params only
  when a second follows, and the parser is at the closing paren when it decides.
- **Generics cost ~170-310 compiler lines + 180-320 test**, because
  `0_generic_expand.pl` already has the worklist, hashing, artifact order and
  declaration boundary.
- **SQLite limits, measured on 3.53.2 today**: 64 tables in a join (HARD error
  at 65), 500 compound-SELECT terms, 250,000 variables (83,333 rows x 3 cols
  OK, 83,334 fails), expr depth 1000, 2000 columns. 20,000 tables created in
  7.8s so table count is a NON-issue. The join limit is the real ceiling and it
  argues for the discriminator-column shape pass 2 rejected on comptime grounds.
- **Catalog already models modules**: `lower.pl:1389` emits a `module` row with
  name + hash; `rel_module_map/3` at `:1395`; both new renderers discard it.
- **SCIP's only measured unique value**: 9 edges reaching a declaration through
  an INFERRED TYPE with no import statement, which no syntactic resolver closes
  (`ARCH.pl:832`). Everything else costs 59.4MB per 204 docs; syntax_kind was 0
  in 123,655 of 123,655 rows.
- **pro4 vs flash4 cost**: pro's input is 5.4x and output 4.8x, but pro's CACHE
  READS ARE 4.4x CHEAPER ($0.0036/M vs $0.0160/M). 79% of flash's entire bill
  ($33.85 of $42.75) is cache reads. Long-context re-reading workloads may
  favour pro. `model_price` has 0 rows so boop cannot compute this itself.
- **boop-start**: copying the finished extractor binary from a warm tree is
  0.01s vs 24.04s cold vs 5.57s with a shared CARGO_TARGET_DIR (cargo
  fingerprints the worktree path and re-links 46MB). Second fresh worktree went
  27.6s -> 1.5s, 18x.
- **A TUI never exits**, so boop's exit detection is pane-body quiescence and a
  TUI lane's rc means "reached idle", not "succeeded". claude and codex keep a
  true verdict.
