# dd resident wall — G6 isolation (streaming generator)

Measurement: each engine runs HERMETICALLY in its own child under a **700 MB** memcap gun. The graph is produced by a STREAMING generator (rows/deps emitted on the fly, O(width) working memory), so no engine carries the shared in-RAM builder (benchgraph's `Vec<Vec>` parents matrix + row/edge Vecs). Only the engine itself is resident, and only the engine can blow the gun.
