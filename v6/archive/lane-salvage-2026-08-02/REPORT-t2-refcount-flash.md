## Law

Repo vocabulary law: "support" (datalog-paper jargon for the count of derivations
keeping a row alive) is banned; the concept is **refCount** (zero = teardown).
Prose already migrated; **SOURCE IDENTIFIERS** had not. This sweep renamed the
identifier class. Hard constraint respected: **no generated bytes that are
byte-golden-graded changed.** The P3 emitter (v6/prolog/lower.pl + emit_ts.pl)
had only its predicates/functors/variables renamed; every emitted string literal
(`"__support_count"`, `__support_next_<rel>`, the `supportSql` JSON key, and the
`// support-count reconciliation` header comment) was left byte-identical, so
`text-door` reports 196/196 byte-identical and `gen_emitted/` shows no git diff.
