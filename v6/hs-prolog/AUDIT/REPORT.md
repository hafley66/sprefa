## Ranked findings

F1. **demand probes grader has no exit-code teeth** (`demand/probes/app/Main.hs`,
   `exitFailure` count 0). Confirmed by sabotage: `FAIL tabling-fixpoint` printed,
   process still exited 0. Any CI telling PASS/FAIL from exit code is fooled. The
   known README defect, re-verified true. Evidence: `cabal run -v0 probes` after
   flipping Tabling `c1` -> prints FAIL, `echo $?` = 0.

F2. **interp grader is red at baseline, no report filed.** Default run (which
   includes the "if time" causality fixture) prints `fail broken_rejected` and
   exits 1. `broken_rejected` needs `\+ causal(Eqs)` to hold in causality.pl:28,
   i.e. the kernel must prove `reach(broken, x, x)`. The tabling fixpoint
   (Tabling.hs:43-58) derives ground facts by solving each tabled clause body
   with all variables free; `edge(Eqs,From,Dep) :- member(eq(From,Expr),Eqs),
   idep(Expr,Dep)` needs `Eqs` bound, so the fixpoint derives no reach facts.
   Result: `counter_ok` passes vacuously (reach empty) and `broken_rejected`
   fails. SWI passes both (verified). The required three fixtures
   (unify_hm, seminaive, magic_sets) do pass. Evidence: `cabal run -v0
   interp-grade` -> exit 1; `swipl -q -l causality.pl -g go -g halt` -> both PASS,
   exit 0.

F3. **`indegree` is O(V*E) on the toposort/cycle path** (graph/src/Graph.hs:112-115).
   Measured `graphHasCycle` on a chain: 0.43 s / 1.80 s / 7.50 s at 2000 / 4000 /
   8000 nodes (~4x per doubling). Latent: the grader's 11 small shapes never
   trigger it, but any larger graph pays it on every `graphTopologicalOrder` and
   `graphHasCycle`. Fix: single pass over edges. Evidence: `/tmp/audit_topo_bin`.

F4. **idioms starter test-suite is dead config** (idioms/starter/starter.cabal).
   `test-suite starter-test` points at nonexistent `test/Spec.hs` and depends on
   a nonexistent library `starter`. `cabal build starter-test` fails Cabal-7127;
   `cabal build all` silently skips it. idioms thus has no buildable grader.
   Evidence: both cabal commands above.

F5. **interp grader certifies "solved", not "correct"** (interp app/Main.hs:42,
   `ok = not (null solutions)`). Any goal with >=1 solution passes regardless of
   the answer value; the fixture's exact SWI expectations are not compared.

F6. **graph Timing unit mismatch** (app/Timing.hs:20,23) - seconds labelled "ms",
   1000x understatement of every "Numbers" figure in graph/REPORT.md. Known README
   defect, re-verified in code, holds.

F7. **BUY.md fgl premise false** (graph/BUY.md:33-39 vs `Data.Graph.Inductive.Query.DFS`).
   `DFS.scc`/`DFS.topsort` exist and compile on 5.8.3.1 (verified: `scc` of 3-cycle
   = `[[1,3,2]]`; `topsort` of cycle = `[1,2,3]`). Known README defect, re-verified
   true. The named modules `Query.SCC`/`Query.TopSort` do not exist, so the wording
   is half-wrong.
