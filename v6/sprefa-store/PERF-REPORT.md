# v6 store — retraction perf & completeness report

Rust rows are generated by `examples/perf_report.rs`; tsv2 rows are produced by `bench/engines/tsv2_retract.sh`. Every engine runs HERMETICALLY (one process each), memcap gun = **12288 MB**. Setup is untimed; the generated graph is dropped before the measured retract, so no metric counts corpus residence.

Columns: **ms** = measured retract wall time; **stmts** = SQL statements in the retract (0 for dd/oracle); **host_peak** = host heap high-water during the retract, measured by CappedAlloc for Rust and V8 `heapUsed` sampled per tick for TypeScript; **sqlite_hw** = SQLite C-heap high-water; **rss** = process resident high-water from `/usr/bin/time -l`; **db** = on-disk database size after the retract. `correct` = output hash equals the oracle's.

For the tsv2 rows, `sqlite_hw` is `N/A` because `@libsql/client` exposes neither a `sqlite3_memory_highwater` binding nor an allocator-status API through `Client` or `ResultSet`. The tsv2 `host_peak` value is the V8 heap high-water sampled during the measured tick. The Rust rows map the former `rust_peak` measurement to `host_peak` without changing the measured value. The common benchmark CSV extends the existing eight fields with `host_peak_mb,sqlite_hw_mb,db_mb`; `bench/run.sh` maps legacy eight-field reach runners to `N/A,N/A,N/A`.

## Breakpoint ramp — tight gun 700 MB

Same task, ramping nodes under a 700 MB memcap. dd is resident so it hits the wall on its arrangements. **Honest caveat:** the store engines keep retract state on disk (host_peak ~0.1 MB in the matrix), so when a store row below aborts it is the SHARED in-RAM graph BUILDER (benchgraph holds the whole `Vec<Vec>` + row/edge Vecs before inserting), NOT the retract. That builder ceiling hits all engines at the same scale and masks dd's true resident wall at extreme sizes. The `host_peak` column contains the per-engine memory data (dd climbs ~215 B/node; the store stays 0.09 MB flat). Isolating dd's wall past the builder ceiling needs a streaming graph generator (gap G6).
