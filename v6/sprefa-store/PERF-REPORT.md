## Breakpoint ramp — tight gun 700 MB

Same task, ramping nodes under a 700 MB memcap. dd is resident so it hits the wall on its arrangements. **Honest caveat:** the store engines keep retract state on disk (rust_live ~0.1 MB in the matrix), so when a store row below aborts it is the SHARED in-RAM graph BUILDER (benchgraph holds the whole `Vec<Vec>` + row/edge Vecs before inserting), NOT the retract. That builder ceiling hits all engines at the same scale and masks dd's true resident wall at extreme sizes — the real per-engine memory story is the `rust_live` column in the matrix (dd climbs ~215 B/node; the store stays 0.09 MB flat). Isolating dd's wall past the builder ceiling needs a streaming graph generator (gap G6).
