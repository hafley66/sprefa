HAVE the fixpoint kernel — reuse, don't rebuild

  • Z-set multiplicity = cx_row.weight — the exact thing the frp-lab oracle validated over 20k states
  • Recursion / transitive closure = the frontier→hits→next loop (semi-naive DRed), already written
  • On disk, measured: retract O(delta·log n), beats dd/dbsp past the RAM wall

GAP to a full recompute graph — the remaining work

  • Addition cascade — today only retract() exists (the hard direction); forward-add is easier, unwritten
  • Non-recursive derived rules — arbitrary joins across rels, not just reachability
  • The rule DAG orchestration — dirty-marking + stratified re-run (FamilyRouter)
  • Generalize schema — cx_* single-i64 key → arbitrary rels
