## The five views

ONE graph, five drawings. The node set, the edge set, the labels, the shapes and the longest-path highlight are derived once and shared, so the five `.dot` files differ only in `rankdir` and in which clusters the node lines are nested inside. `just atlas` asserts exactly that: the same node id set in all five files, every node in the two filesystem views inside the cluster chain its own path spells, and every `.dot` byte-stable across two runs. Canvas is what graphviz chose, read back out of the rendered SVG; clusters are counted from the fragments the program emitted. All five carry `ratio=0.4`, which is the one setting that gives them the same 2.5:1 page, so what differs between two views is the grouping and the direction rather than the lever (the five-setting measurement is in the program header).

The filesystem nesting is unrolled to four levels (`v6/prolog/compile/scripts` is the deepest directory the corpus reaches) because the natural spelling -- a directory folds its children, where a child may be another directory -- is a `group_concat` reading its own output, and a recursive aggregate has no stratification. A fifth level is a rail FAILURE via `fs_dir_too_deep`, never a silently dropped cluster. The directory split itself is done in the fact host: this language has no string split, and the probe that proved it found something worse than a refusal -- see the note above `file_dirs` in the program.
