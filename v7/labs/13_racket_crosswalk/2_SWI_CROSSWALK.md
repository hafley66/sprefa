# SWI to Racket Crosswalk

Research and source-check date: 2026-08-29.

Capability labels describe the shortest route available in the sources checked here:

- `native` means the Racket host supplies the relevant language or module boundary.
- `library` means a Racket package supplies the logic or solver mechanism.
- `adapter` means a bounded layer is required around a nearby package facility.
- `implement` means a new engine component is required in Racket.
- `external-runtime` means retaining or embedding SWI supplies the capability.
- `absent-from-probe` means the current package metadata was checked but no local execution was run.

The Datalog entries use the current [Racket Datalog manual](https://docs.racket-lang.org/datalog/), which describes function-free Horn clauses, safe heads, tabling of intermediate results, order-independent answer derivation, and terminating pure Datalog queries. The installed source provides a demand-driven subgoal table keyed by literal variants and propagates newly found facts to waiting clauses. That table is the package’s internal evaluator mechanism, while SWI’s general table directives, table modes, and table inspection API remain separate capabilities.

## Facility boundary

The shortest Racket route for a DL7 phase-0 compiler is a Racket reader and hygienic macro layer feeding a restricted `datalog` theory. Racklog covers Prolog-style unification and search when an answer stream is required. cKanren and hosted miniKanren are package candidates for relational constraints and optimized relational code, with local execution pending package selection. Rosette covers symbolic solver queries and verification conditions. General SWI tabled Prolog, CHR, CLP(Q/R), attributed variables, and incremental tabling remain implementation or external-runtime boundaries.

The runtime shootout supplies a measurement boundary rather than an equivalence claim. Its Racket 9.3 arm uses the `datalog` package, while the SBCL and SWI arms use different closure algorithms. The supplied results record correct counts at `N=48` for all three arms and Racket medians of 495.746 ms for the chain closure and 1966.985 ms for the ring closure.
